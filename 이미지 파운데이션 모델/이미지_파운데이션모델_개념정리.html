AI 파운데이션 모델(Foundation Model)이란?

1-1

AI 모델이란

  • 가장 단순한 관점: 함수 또는 프로그램
  • 입출력을 연결하는 함수 / 데이터로부터 그 형태가 결정되는 함수
  • 학습 때 보지 못했던 데이터에 대해서도 작동이 요구되는 함수
  • 예: 뉴럴넷 (입력 → 뉴럴넷 → 출력)

이상적인 AI 모델 vs 현실

  • 이상적: 세상 모든 데이터와 설명을 다 기억 → 검색엔진의 Nearest Neighbor Search와 유사한 발상
  • 그러나 데이터 확보·저장·탐색 비용이 크고 비현실적
  • 현실적: 데이터를 패턴화하여 압축(Representation Learning) → 비슷함/다름을 파악하고 새 데이터에 일반화

파운데이션 모델 정의

대규모 데이터로 사전학습(Pre-training)한 후, 다양한 문제·작업에 범용적으로 빠르게 적용(Adaptation)할 수 있는 기반 AI 모델. 2021년 스탠포드 대학 중심 AI연구소 보고서(Bommasani et al.)에서 새로운 범주로 처음 구분.

기존 vs 파운데이션 모델 패러다임
기존 딥러닝 개발파운데이션 모델
아기처럼 언어·시각·청각 등 기본부터 각각 배워나감거대 모델(커진 뇌) + 대규모 데이터 학습(많은 지식·경험) → 새로운 일도 처음부터 금방 배우고 잘함
개발 프로세스

Data Creation → Data Curation → Training → Adaptation → Deployment

파운데이션 모델의 3대 특징

  • ① 대규모 사전학습 — 트랜스포머 + 대규모 데이터 학습. 태스크와 무관한 비슷한 패턴들을 활용(주로 비지도학습으로 훈련된 모델도 많이 등장) → 쉬운 데이터 수집 + 대규모 + 사전학습
  • ② 적응성 — 높은 미세조정 성능(높은 태스크 적용성능). 하나의 믿을 수 있는 모델 → 다양한 목적에 적용. 활용 기법: 프롬프트(엔지니어링/튜닝), 전이학습, 적응(Adaptation)학습, 파인튜닝
  • ③ 범용성 — 다양한 작업, 한정되지 않은 출력 지원. 예) 기존: 룰렛/구조상 20여개 물체 구분으로 한정 / 파운데이션 모델: 만 개 이상 카테고리 판별 및 대상에 대한 인식 안됨도 상대 가능

적응(Adaptation) 활용 방법

방법내용
Zero-shot직접 분포 확장 학습 없이 바로 적용 — 모델 자체가 가진 배경지식 활용
Few-shot예제 몇 개만 보여주면 비슷하게 적용
Fine-tuning처음부터 배우지 않고 조금만 추가 튜닝 — 모델 가중치 자체가 변경됨

과거엔 매번 태스크별로 새로 학습했지만, 이제는 잘 학습된 모델을 얼마나 잘 "활용"하느냐가 더 중요해짐. 단, 파운데이션 모델 하나 확보에는 대규모 리소스(데이터·계산·전력)가 필요해 일부 기관만 가능.

AGI를 향해서 (섹션 도입 배경) — Human's Intelligence(cognition) = perception ∪ higher cognitive processes. 2022년 11월 이전에는 분야별 지능의 부분적 능력만 개별 모델링되었으나, ChatGPT 등장(2022.11) 이후 대규모 언어모델(LLM)이 높은 사고·추론 성능을 보이기 시작(다양한 인지능력 벤치마크에서 인간 수준 근접). 그러나 사고·언어 능력만으로는 현실 세계를 이해하기 충분하지 않음 → 시각(Perception) 능력이 필요 → Vision-Language Model 등장 배경.

CLIP (Contrastive Language-Image Pre-training, 2021, OpenAI)

1-2 ~ 1-4

시각언어모델 예시로 본 배경

GPT-4(2023): 텍스트뿐 아니라 이미지·문서·음성 등 멀티모달 데이터를 처리하는 모델. GPT-4V로 이미지 이상탐지, Sketch-to-web(손그림 → 실제 동작하는 HTML/CSS 웹페이지 생성) 등 응용. Claude Computer Use: 텍스트 지시만으로 컴퓨터 화면을 스스로 조작하는 agentic 서비스(고화질 인터페이스 상호작용엔 이미지 캡처 방식 선호 = 시각 이해가 필요한 이유).

1-1CLIP 핵심 아이디어

대조 학습(Contrastive Pre-training) 기반 언어-이미지 사전학습. 인터넷에서 수집한 4억 개의 이미지-텍스트 쌍으로 학습하여 지도학습(supervised learning)을 자연어 기반 시각 개념 학습으로 대체.

  • 수집: alt-text HTML 태그, 이미지 캡션, 제목 등을 기준으로 인터넷에서 이미지-텍스트 쌍 수집
  • 정제: 중복 이미지, 해상도 낮은 이미지, 짧은 텍스트 등 필터링
  • 텍스트 인코더: Transformer 기반 / 이미지 인코더: ViT-B (또는 ResNet50)

1-2텍스트 인코더

  • Transformer 기반 (Encoder+Decoder 구조 중 CLIP은 필요 부분만 사용)
  • 토큰 단위 입력, Attention으로 토큰 간 관계 파악
  • L 길이의 입력 토큰은 D차원 특징벡터(임베딩) 배열 (L × D)로 입력
  • 자연어: Sub-word 단위 임베딩 — vocabulary size 50,257 / small 768·medium 1024·large 1280·xtra large 1600 임베딩 사이즈

1-3이미지 인코더 (ViT)

  • 이미지를 작은 패치(16×16×3)로 나눔 → 각 패치를 1D로 Flatten
  • Learnable Position Embedding으로 패치별 위치정보 부여, 학습 과정에서 함께 학습됨
  • Transformer Encoder로 패치 처리 → MLP Head로 분류 작업 수행 (CLIP은 이 Head를 CLIP 학습법으로 대체)
  • 텍스트 인코더(자연어 입력): Sub-word 임베딩 / 이미지 인코더(이미지 입력): 패치 단위 임베딩 — ViT는 비전 분야에 트랜스포머를 최소 수정으로 적용한 모델

1-4학습 — 대조 학습(Contrastive Learning)

학습 기준: 목표 이미지(앵커)를 대응하는 텍스트(양성)와 가깝게, 일치하지 않는 여러 텍스트(음성)와는 멀게 → 의미에 따른 거리 감각을 학습하도록 유도 (예: 강아지 이미지 앵커 ↔ "강아지" 텍스트는 가깝게, "코끼리·자전거·컴퓨터"는 멀게)

Softmax with Temperature

로짓(logits)을 확률(probabilities)로 변환. Temperature T로 분포의 뾰족함을 조절 — T=1.00은 완만, T=7.00처럼 크면 더 뾰족한 분포.

대조 학습 손실함수 (수식)

sij = i번째 이미지와 j번째 텍스트 임베딩 간의 코사인 유사도

L_CLIP = -1/N · Σᵢ log( e^(s_ii/τ) / Σⱼ e^(s_ij/τ) ) // Image → Text Loss + -1/N · Σⱼ log( e^(s_ij/τ) / Σᵢ e^(s_ij/τ) ) // Text → Image Loss
Numpy-like pseudocode
# 각 모달리티에서 특징 추출 I_f = image_encoder(I) # [n, d_i] T_f = text_encoder(T) # [n, d_t] # 공동 멀티모달 임베딩 + L2 정규화 I_e = l2_normalize(np.dot(I_f, W_i), axis=1) T_e = l2_normalize(np.dot(T_f, W_t), axis=1) # 스케일링된 pairwise 코사인 유사도 logits = np.dot(I_e, T_e.T) * np.exp(t) # 대칭 손실함수 labels = np.arange(n) loss_i = cross_entropy_loss(logits, labels, axis=0) loss_t = cross_entropy_loss(logits, labels, axis=1) loss = (loss_i + loss_t) / 2

CLIP 간단 응용 — 제로샷 이미지 인식

  • 텍스트로 원하는 물체 카테고리 리스트 준비
  • 텍스트 기반 카테고리 리스트를 텍스트 임베딩으로 변환하여 Vector DB 준비
  • 쿼리 이미지와 비교해서 가장 높은 점수의 카테고리 반환

특징: 대규모 데이터로 사전학습된 범용 모델 / 하나의 모델로 다양한 태스크에 빠르게 적용 / 확장성·범용성 높은 성능 / 이미지-텍스트 쌍 데이터를 활용한 이미지-언어 연결

출처: Radford et al., "Learning transferable visual models from natural language supervision", ICML 2021

SigLIP & CLIP 심화 응용 — 멀티모달 정합

SigLIP(2023) / 멀티모달 Alignment

SigLIP (2023)

배경 — CLIP Softmax 대조학습의 한계: 이미 충분히 거리가 먼 음성(negative) 데이터 쌍에 대해서도 계속 거리를 벌리려 학습이 진행되어 비효율적.

해법: 일치하지 않는 음성 데이터에 제한된 영향만 받도록 손실함수를 Sigmoid 기반으로 디자인 고침 (SigCLIP과 달리).

L_SigLIP = -1/N² · Σᵢ Σⱼ log( 1 / (1 + e^(-z_ij·(t·x_i·y_j + b))) ) Label z = { -1 : 음성 페어(다른 의미) → 가까워지면 좋음X +1 : 양성 페어(같은 의미) → 가까워지면 좋음 } Sigmoid 함수: φ(s) = 1 / (1 + e^(-s))

Sigmoid 함수의 역할: 어느 정도 값이 커지면(멀어지면) 이후엔 그래디언트가 자연히 줄어들어 더 신경쓰지 않아도 됨.

성능: CLIP 대비 SigLIP이 압도적 성능, 특히 학습 데이터에 노이즈가 많아질수록 격차가 더 벌어짐. 최근 SigLIP2까지 공개되어 최신 VLM에 널리 활용 중.

출처: Zhai et al., "Sigmoid Loss for Language Image Pre-training", ICCV 2023

멀티모달 정합(Multi-modal Alignment)

정의: 둘 이상의 모달리티(예: 이미지-텍스트) 간 공통된 임베딩 벡터 공간을 구성하는 것 → 모달리티 간 유사도(연관성) 비교 가능

ImageBIND (Meta) — "One Embedding Space To Bind Them All": 이미지·비디오·텍스트·오디오·뎁스·열화상·IMU까지 여러 모달리티 공간을 공유하도록 학습. 응용: Cross-Modal Retrieval, Embedding-Space Arithmetic, Audio-to-Image Generation 등.

정합 활용 2가지 디자인
변환 (Translating)정렬 (Matching)
모달리티 A → 모달리티 B로 직접 변환두 모달리티를 정렬된 피처 공간(aligned feature space)에 매핑해 비교

멀티모달 정합 손실 함수 (Multi-modal Alignment Loss)

서로 다른 모달리티(예: 이미지-텍스트) 사이에 정렬된 정도를 측정하는 손실함수. 대표적인 텍스트-이미지 손실함수로 CLIP loss와 Score Distillation Sampling(SDS) loss 두 가지가 있음.

CLIP loss [Radford, 2021]SDS loss [Poole, 2023]
활용 모델사전학습된 CLIP 활용사전학습된 text-to-image diffusion model(예: Imagen) 활용
방식텍스트 임베딩(T₁~T_N)과 이미지 임베딩(I₁~I_N)의 코사인 유사도 행렬을 직접 비교노이즈 z_t ~ U(0,1)를 diffusion U-Net으로 예측(x̂_φ(z_t│y;t))하며, 예측이 목표 텍스트 프롬프트(예: "a DSLR photo of a peacock on a surfboard")에 가까워지도록 그래디언트 전달

정합(Matching)을 통한 크로스모달 변환 — CLIP loss 활용

단일 데이터에 대해서만 학습 = 최적화(Optimization)이지 모델 자체의 재학습은 아님. Text encoder와 Image encoder는 고정(freeze)한 채, backpropagation으로 유사도가 최대화되도록 대상(파라미터화된 이미지 등)만 업데이트.

  • 이미지 캡셔닝(Image-to-text) / 텍스트 입력을 통한 이미지 스타일 변환
  • Text-to-Image, Text-to-motion, Text-to-3D 생성
  • 텍스트 입력을 통한 이미지·비디오 검색 (지난 4년간 약 4만 번 이상 인용된 핵심 개념)

Vision-Language Model (VLM)

LLaVA · Qwen-VL · 도메인 특화 VLM

LLaVA (Large Language and Vision Assistant, 2023)

Vision과 Language 모델을 결합한 VLM으로 텍스트-이미지를 동시에 이해. 특징: 이미지 인식+텍스트 생성 결합, 이미지-명령(instruction)-답변 데이터셋으로 Instruction Tuning 학습, 이미지 기반 질답·설명·시각적 대화에 응용.

구조: Vision Encoder(Z_v) → Projection W → H_v(이미지 특징) + H_q(언어 지시 X_q) → Language Model(f_φ) → Language Response(X_a)

2단계 학습
Step목표효율화 포인트
Step1
사전학습		이미지 특징을 선형 레이어(Projection layer)로 텍스트와 공통 표현으로 정렬전체 모델을 재훈련하지 않고 작은 Projection layer만 학습 → 자원·시간 절약
Step2
파인튜닝		특정 작업에 맞춰 [선형 레이어] + [언어모델 등] 필요한 부분만 미세조정FP16 등 정밀도 최적화 + 저비용 학습기법으로 적은 메모리·사용량으로 학습

학습 데이터: GPT를 이용해 캡션·물체좌표(bounding box) 라벨로부터 상세 설명(detailed description)·복잡한 추론(complex reasoning) 등 visual instruction data를 자동 생성.

Qwen-VL / Qwen2-VL (Alibaba)

상용 VLM에 맞서는 오픈소스 VLM. 대형 언어모델(LLM)에 시각처리 능력을 부여해 이미지와 텍스트를 동시에 이해. 여러 이미지 입력, 번역, 텍스트 읽기, 위치찾기(물체탐지), 인식·이해 능력 보유.

  • Agent 응용 지원, Code/Math 추론, Video 분석, Live chat 기능 강화
M-RoPE (Multimodal Rotary Position Embedding)

1D 텍스트, 2D 시각, 3D 비디오 위치 정보를 함께 부여할 수 있는 위치 임베딩 확장.

기존 PE: Positioned Token = Token + PE (처음 한번만 더함) 기존 RoPE: Query q_i, Key k_j 에 대해 q'_i = R(i)q_i , k'_j = R(j)k_j ⇒ q'_i · k'_j = q_i^T R(j-i) k_j (상대적 위치차이만 반영)

등장 배경

VLM은 유용하지만 서버 비용이 비쌈 → 개인 PC·스마트폰에서 실행되는 경량 모델 필요. sLLM(경량 대규모 언어모델)에서 이루어진 경량화 시도들이 VLM에도 이어짐: sLLM(규모 언어모델 경량화) → sVLM(멀티모달 데이터를 처리하기 위한 효율적인 소형 VLM 개발)

SmolVLM (Hugging Face)

구조: Vision Encoder(SigLIP) → Modality Projection + Pooling → LLM (Llama 3.1 8B → SmolLM2 1.7B로 경량화)

이미지 생성 파운데이션 모델

생성 모델링의 목표

모르는 것: 실제 데이터 분포 pdata(x)의 형태 (신만 알고 있음)  |  아는 것: 실제 데이터셋 {x}

생성모델 학습 = 주어진 {x}로부터 유사모델 pmodel(x)를 학습 → 목표: pdata(x) ≈ pmodel(x)로 근사

설계도가 정교할수록 실제 데이터 분포에 가까워짐(생성 품질↑) → 핵심 질문: pmodel(x)의 모델 구조는? 학습 방법은?

생성 모델의 응용
  • 실제 데이터와 유사한 이미지 생성 / 학습데이터 생성·데이터 증강(augmentation)
  • 이미지 화질 개선 / 이미지 편집·스타일 변경

Diffusion Model

대표적 영상 생성 모델. 점진적으로 노이즈를 제거하며 이미지를 구체화하는 생성 방식.

  • Forward: 가우시안 노이즈(정규분포)를 점점 더해가는 과정
  • Backward: 노이즈를 제거해가는 과정 — 노이즈를 예측하는 문제를 반복 학습

Latent Diffusion Model (LDM)

Stable Diffusion(2022)에서 소개. 고차원 픽셀 대신 저차원 latent 임베딩(압축된 특징)으로 변환한 후 diffusion 연산 수행 → 연산 효율 + 생성 품질 동시 향상.

구조: 1단계 Text Representation Generation(텍스트 임베딩) → 2단계 Image Representation Refiner(이미지를 점차 개선해 고품질 이미지 생성)

파운데이션 모델 + Fine-tuning

Gradient Descent · Learning Rate

Fine-tuning이 필요한 이유

파운데이션 모델은 방대한 데이터로 학습된 초대형 딥러닝 모델로 다양한 문제에 범용적으로 빠르게 적용 가능하지만, 최근 정보나 특정 작업·도메인에는 최적화되어 있지 않아 즉시 활용이 어려운 경우가 반드시 있음.

Fine-tuning: 추가 학습을 통해 이미 학습된 모델을 조금만 튜닝하는 것. 적은 데이터로 학습 가능 / 학습 리소스·시간 절약 / 특정 작업에 대한 우수한 성능.

Pretraining(대규모 데이터) → Fine-tuning(소규모 데이터): Base Model → Fine-tuned Model

프롬프팅(Fine-tuning의 넓은 범주로도 볼 수 있음): 프롬프트에 넣는 예제보다 훨씬 많은 예제로 학습 가능, 프롬프트 길이 감소로 토큰 절약, 응답 latency 단축.

Gradient Descent (GD)

손실함수(Loss)의 미분을 통해 구한 기울기(gradient)로 파라미터를 반영 비율(learning rate)만큼 업데이트하는 최적화 방법.

하이퍼파라미터 — Learning Rate

손실함수 값을 미세하게 조정하기 어려우므로 뉴럴넷 모델에 작은 비율로 반영. Learning rate = 반영할 비율. 적절한 값은 모델·데이터마다 달라 실험으로 구함 (예: 0.005(5e-3), 0.0003(3e-4)).

상황결과
너무 낮은 LR
(예: 1e-8)		local minimum에 빠져 global minimum 도달 가능성이 낮아짐
너무 높은 LR마구 점프하다 global minimum으로 딱 맞춰가기 어려움

미세조정(Fine-tuning)에서는 이미 좋은 시작점(사전학습된 가중치)에서 출발하므로 작은 learning rate부터 보수적으로 시작해야 함.

Parameter-Efficient Fine-Tuning (PEFT)

전체 파라미터 재학습의 대안

배경 — AI 모델 크기의 폭발적 증가

AlexNet 60M(2012) → VGG-19 144M(2014) → AmoebaNet-A 469M(2018) → ResNeXt-101 829M(2018) → BiT-M 928M(2019) → ViT-G/14 1,843M(2021) → ViT-MoE-15E 14,700M(2021)

하드웨어 발전·대규모 데이터 축적·모델 발전으로 파라미터 수가 기하급수적으로 증가 → 전체 파라미터를 재학습하는 Full fine-tuning은 비용이 매우 높아짐 → PEFT(일부 파라미터만 효율적으로 조정) 필요성 대두.

프롬프트 디자인 (Prompt Design)

언어모델에서 주로 활용. 모델이 원하는 레벨의 결과를 출력하도록 입력 텍스트를 변형하는 방법.

장점단점
추가 학습 없이 사전학습된 모델의 예측 성능을 끌어올릴 수 있음프롬프트를 사람이 직접 설계해야 하는 부담, 성능 향상이 제한적

예시(Text-to-Image): "강아지 사진 그려줘"(단순 프롬프트, 부족한 결과) → "캐논 EOS1D로 찍은듯한 강아지 사진을 생성해줘"(구체화된 프롬프트, 더 좋은 결과)

프롬프트 튜닝 (Prompt Tuning, 2021)

학습 가능한 프롬프트로서 가상 토큰(virtual token)을 입력에 추가하는 기법. 역전파를 통해 오직 가상 토큰에 대한 임베딩만 학습하고 나머지 모델(파운데이션 모델 본체)은 고정(freeze).

장점
  • 사람의 디자인 없이 스스로 프롬프트를 학습할 수 있음
  • 사전학습된 모델을 고정할 수 있음 (지식 손실 X — 일반 파인튜닝은 지식 손실 발생 가능)
  • 적은 비용으로 새로운 데이터셋의 모델을 학습할 수 있음
  • 단, 학습된 프롬프트 자체는 해석 불가(그저 숫자 벡터 나열일 뿐)
3가지 튜닝 방식 비교
모델 튜닝(미세조정)프롬프트 튜닝프롬프트 디자인
파운데이션 모델🔥 추가 학습(가중치 변경)❄️ 고정❄️ 고정
입력입력 텍스트학습 가능한 프롬프트 + 입력 텍스트입력 텍스트(사람이 직접 설계)
성향← 높은 성능높은 효율 →

출처: Lester et al., "The Power of Scale for Parameter-Efficient Prompt Tuning", EMNLP 2021

Adapter 모듈 추가 학습

학습 가능한 작은 모듈(Adapter)을 레이어마다 삽입하여 일부 파라미터만 학습하는 기법. 기존 모델 블럭(Layer 1~4)은 그대로 두고, 각 레이어 사이에 학습가능한 파라미터(Adapter)를 추가로 삽입 — 전체 재학습보다 훨씬 적은 파라미터만 업데이트.

1-5. 개인화 모델 예시 — DreamBooth

프롬프트 튜닝 응용 사례. 영상 생성 모델을 개인화하는 방법으로, 학습 가능한 토큰(Unique identifier, 예: "[V]")과 모델을 함께 Fine-tuning.

단계내용
Fine-Tuning입력: 소수(약 3~5장)의 피사체 이미지 + class name(예: "dog") → DreamBooth 학습 → 출력: Unique identifier "[V]" + Personalized Text-to-Image 모델
Inference"A [V] dog in the beach", "A [V] dog walking on a colorful carpet"처럼 프롬프트에 [V]를 넣으면, 학습된 피사체가 새로운 배경·자세로 재현됨
응용 결과 예시
  • Input images(같은 개 사진 여러 장) → 화가 스타일 재현: Van Gogh, Michelangelo, Rembrandt, Vermeer, Renoir, da Vinci 화풍으로 그려진 동일 피사체
  • Color modification: "A [color] [V] car" → 같은 차를 purple / red / yellow / blue / pink로 색상만 변경
  • Hybrids: "A cross of a [V] dog and a [target species]" → 같은 개의 정체성을 유지한 채 Bear / Panda / Koala / Lion / Hippo와 합성한 하이브리드 생성

출처: Ruiz et al., "DreamBooth: Fine Tuning Text-to-Image Diffusion Models for Subject-Driven Generation", CVPR 2023

합성 데이터(Synthetic Data) 활용법

데이터 효율화를 위한 합성 데이터 사용 — Knowledge Distillation · InstructPix2Pix · 활용 시 유의사항

2-1합성데이터 활용법 1 — Knowledge Distillation (Teacher-Student 학습)

사전학습된 고성능 모델의 지식을 작은 모델에 압축해서 빠르고 효율적으로 만들 수 없을까? 지금까지 배운 미세조정과 같은 전이학습(Transfer Learning)은 사전학습된 모델과 새로 학습할 모델(타겟 모델)의 구조가 동일한 경우를 가정하고 있었음 — Knowledge Distillation은 이 가정을 깨는 방법.

지식증류(Knowledge Distillation): 높은 성능의 무거운 모델(선생님, Teacher)을 모방하도록 가벼운 모델(학생, Student)을 학습하는 방법. 또는, 크기가 작은 모델(Student)만으로 충분히 학습하기 어려운 데이터 특징을 학습하기 위해, 비교적 무겁고 성능 높은 모델(Teacher)의 도움을 받는 기법으로도 볼 수 있음.

  • 선생님 모델이 예측한 soft-label 값과 학생 모델의 예측 값이 가까워지도록 학습 유도
  • Soft-label: [0, 1] 사이의 모델 예측을 가짜 라벨(정답)로 사용
Teacher Model(Pre-trained) ──┐ ├─ Predictions ──(Distillation Loss)──┐ Student Model(to be trained)─┘ │ ↑ │ Training Data ──────────────────────────────────────────────────┘ └─ Ground Truth ── Student Model Predictions와도 비교 목표 데이터(소규모) → [Teacher: 사전학습된 고성능 모델] ──지식(Knowledge)──▶ [Student: 타겟 모델] ── 높은 성능↑ 사전학습된 모델 출력(가짜 정답) ⟷ Distillation Loss ⟷ 타겟 모델 출력

출처: Knowledge Distillation 개념도 재구성 (Teacher-Student 학습)

2-2InstructPix2Pix (2023) — 명령 기반 이미지 편집

파운데이션 모델들을 툴로 활용하는 방법. 명령(instruction)에 따라 이미지 편집을 수행하는 모델.

기존 방식본 방법
입력 이미지와 출력 이미지에 대한 상세 설명 필요 (입력-정답 쌍 필요)입/출력 이미지 상세 설명 없이 명령만으로 편집 수행
합성데이터 생성 파이프라인 (3단계)
  1. 사람이 작성한 소규모 데이터셋(~700 edits)으로 Fine-tuning된 GPT-3가 지시사항+이미지 설명(caption) 쌍을 450,000개 생성
  2. 생성된 텍스트 데이터셋을 기반으로 Stable Diffusion + Prompt2Prompt로 (편집 전/후) 이미지 쌍 생성
  3. 이 이미지 쌍으로 최종 InstructPix2Pix 모델을 학습(fine-tuning) → 추론 시 사람이 작성한 지시사항만으로 실제 이미지를 편집

결과 예시: "Swap sunflowers with roses", "Add fireworks to the sky", "Replace the fruits with cake", "What would it look like if it were snowing?", "Turn it into a still from a western", "Make his jacket out of leather" 등 텍스트 명령만으로 자연스러운 이미지 편집.

2-3합성데이터 활용법 3 — 정의와 필요성

실제 데이터를 모방하거나 새로 생성한 인공 데이터(예: 가상의 이미지·텍스트·소리를 알고리즘으로 생성). 실제 데이터를 수집·사용하기 어려운 경우 대체 가능 — 데이터 부족 문제를 해결하고 모델 성능을 개선하는 데 사용.

특히 데이터 취득이 어려운 문제에서 더 유용: 촬영하기 어려운 움직임·환경을 시뮬레이션해 다양성 높은 데이터 생성 가능. 예) 모션 증폭(Motion Magnification) — 심박수 변화, 건물의 미세 진동 등을 합성데이터로 학습.

합성데이터 활용 시 유의사항

문제내용개선방안
라벨 품질 불일치
(Label Inconsistency)		합성 데이터를 만들 때 사용하는 VLM/LLM 라벨러가 항상 일관된 기준으로 라벨을 생성하지는 않음. 같은 객체도 프롬프트 방식·모델버전·컨텍스트에 따라 표현이 다를 수 있음
예) "기타(guitar)" → "electric guitar" / "guitar player" / "acoustic instrument"		라벨 정규화, 클래스 사전, 교차모델 검증, 휴먼 검수
할루시네이션
(Hallucination)		생성 모델이 실제 존재하지 않는 객체·특징·관계를 마음대로 만들어내는 현상. 실제 세계와 다른 패턴을 학습해 오류·편향 강화
예) 손가락 6개 이미지, 물리적으로 불가능한 그림자 지속 생성		정교한 프롬프트, 후처리 Refiner, 사실성 검증 모델, 실데이터 혼합

응용 사례 — 영상 기반 추론 (Natural Language Visual Reasoning)

두 장(LEFT/RIGHT)의 카누 사진을 놓고 "The left and right image contains a total of six people and two boats."라는 진술을 검증하는 예시. VQA 툴로 각 이미지의 사람 수·보트 수를 각각 질의한 뒤(ANSWER0~3), Eval로 합산 조건을 논리 평가(ANSWER4)해 참/거짓(Prediction: False)을 판정 — 여러 이미지에 걸친 정량적 진술도 툴 조합만으로 단계적으로 검증 가능함을 보여줌.

Statement: The left and right image contains a total of six people and two boats. Program: ANSWER0=Vqa(image=LEFT, question='How many people are in the image?') ANSWER1=Vqa(image=RIGHT, question='How many people are in the image?') ANSWER2=Vqa(image=LEFT, question='How many boats are in the image?') ANSWER3=Vqa(image=RIGHT, question='How many boats are in the image?') ANSWER4=Eval('{ANSWER0} + {ANSWER1} == 6 and {ANSWER2} + {ANSWER3} == 2') RESULT=ANSWER4 // Prediction: False

Hugging Face

AI 관련 오픈소스 모델과 데이터셋을 공유하는 플랫폼. 사전학습 모델 가중치 제공, 모델 학습을 위한 다양한 데이터셋 제공. 응용분야: NLP, 컴퓨터비전(CV), 음성인식(Speech) 등.

Hugging Face Inference API: 별도 서버 구축 없이 REST API만으로 모델을 바로 사용 가능. 연구·테스트 목적으로 Request 수 제한 있음(무료/유료 버전).

from huggingface_hub import InferenceClient client = InferenceClient(provider="hf-inference", api_key="hf_...") messages = [{"role": "user", "content": "What is the capital of France?"}] completion = client.chat.completions.create( model="deepseek-ai/DeepSeek-R1-Distill-Qwen-32B", messages=messages, max_tokens=500) print(completion.choices[0].message)

모바일 모델 서빙

MediaPipe, MLC LLM을 통해 스마트폰에서 sLLM 모델 손쉽게 실행. 개인정보 보안 문제 완화 + 인터넷 연결이 끊긴 상태에서도 사용 가능한 장점.

예: 안드로이드 MLCChat 앱으로 Qwen2-1.5B, Llama3.1-8B, Phi3-mini 등 다운로드 실행 / Gemma1은 MediaPipe로, Gemma2는 MLC LLM으로 실행

Gradio

머신러닝 모델을 웹 인터페이스로 쉽게 배포하도록 도와주는 오픈소스 라이브러리. 코딩 지식이 없어도 몇 줄의 코드로 모델과 상호작용하는 환경 제공. HuggingFace와 통합되어 Gradio 데모를 쉽게 생성·배포 가능. 다양한 입력(이미지/텍스트/오디오 등)·출력 지원.

import gradio as gr interface = gr.Interface( fn=predict_image, inputs=gr.Image(shape=(28, 28), image_mode='L', invert_colors=True), outputs="label", live=True) interface.launch()

실습 마무리 — 이미지 생성 및 평가와 모델 학습

  • 생성형 파운데이션 모델을 활용해 이미지 생성 가능 (Stable Diffusion 기반 Text-to-Image)
  • 멀티모달 모델을 이용해 이미지를 평가할 수 있음 — CLIP을 활용해 이미지 생성 입력 텍스트와 결과물 내용을 자동 비교
  • 합성 데이터를 활용하여 전이 학습(Transfer Learning) 수행 가능
전이 학습 (Transfer Learning)

특징적은 데이터로도 학습 가능 / 학습 시간·비용 절감 / 기존 모델의 일반화 능력 활용

각 차시 마지막 "강의 정리" 슬라이드 취합

🔹 1차시 — AI 파운데이션 모델 & CLIP

  • CLIP의 학습 디자인 한계를 간파한 SigLIP
  • VLM = Vision-Language Encoder(예: CLIP/SigLIP) + Language Model
  • 기존 언어모델은 텍스트만, CV모델은 이미지만 처리 → 이를 융합하면 수많은 문제를 하나의 모델로 해결 가능: 이미지 인식, 탐지, 캡션, Visual QA, 추론, 글자인식(OCR), 번역 등
  • 도메인 특화 VLM 사례들 (의료 · 제조업 · 3D)

🔹 2차시 — Small VLM & 다양한 파운데이션 모델

  • 모바일 환경에서도 실행 가능한 sVLM들, 한국어 sVLM
  • 다양한 이미지·영상 파운데이션 모델들:
    • Segment Anything — 범용 객체 분할
    • Grounding SAM — 텍스트와 연결된 객체 탐지·분할
    • Stable Diffusion, FLUX — 텍스트 기반 이미지 생성
    • Depth Anything, Sapiens — 2D 이미지에서 3D 변환
    • Wan2.2 — X-to-Video 생성 모델

🔹 3·4차시 — Fine-tuning & 합성데이터 & 실습

  • 파인튜닝은 모델을 특정 도메인·사용자에 맞게 효율적으로 적용할 수 있는 매우 실용적 기술
  • 합성데이터 활용법은 학습·평가 데이터 취득이 어려울 때 매우 실용적인 방법론 — 생각보다 간단한 데이터가 활용성이 좋을 수 있음
  • 이미지 파운데이션 모델의 개발 동향: 이미지+언어모델의 성공 사례 ⇒ 멀티모달 언어모델로 확장
  • 실습: HuggingFace는 다양한 모델이 공유되어 활용 가능한 플랫폼, Gradio로 모델을 손쉽게 서빙할 수 있음
