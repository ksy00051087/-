# AI Lunch Time — AI Agent ① 에이전트란 무엇인가 (실습 코드)

## 사전 준비
* Python 3.10 이상 (강의는 Windows 환경 기준)
* OpenAI API key

## 설치 (Windows, Git Bash 기준)
```bash
# 2. (선택) 가상환경 생성
python -m venv .venv
source .venv/Scripts/activate

# 3. 패키지 설치
pip install -r requirements.txt

# 4. 환경변수 파일 만들기
cp .env.example .env
# .env 파일을 열어 OpenAI API Key 값을 실제 발급받은 키로 채워넣기
```
