개념설명
AI / ML / DL인공지능(AI)은 기계가 지능적으로 행동하도록 만드는 기술, 머신러닝(ML)은 데이터로부터 패턴을 학습하는 AI의 한 방법, 딥러닝(DL)은 신경망을 활용한 ML의 특수 기법

EDA데이터 분포, 중앙값·사분위수·상관관계 등을 시각화를 통해 탐색하는 기법

이상치 탐지·제거IQR(사분위 범위) 등 통계적 방법으로 극단값을 식별하고 처리
StandardScaler피처별 평균을 0, 분산을 1로 표준화하여 학습을 안정화하는 전처리
선형 회귀입력과 출력의 선형 관계를 모델링하여 연속형 값을 예측하는 지도학습
회귀 평가 지표RMSE(평균 제곱근 오차), MAE(평균 절대 오차), $R^2$(결정계수)

1. 머신러닝 기초 개념

1-1. AI / ML / DL

AI (인공지능)
기계가 지능적으로 행동하도록 만드는 가장 넓은 개념. 규칙 기반 시스템도 포함.
ML (머신러닝)
데이터로부터 패턴을 학습하는 AI의 한 방법. 규칙을 사람이 짜지 않고 데이터가 정한다.
DL (딥러닝)
신경망(특히 층이 깊은)을 활용한 ML의 특수 기법. 이미지·음성·언어처럼 특징 추출이 어려운 데이터에 강함.
포함 관계: AI ⊃ ML ⊃ DL

1-2. 지도학습 vs 비지도학습

지도학습 (Supervised)비지도학습 (Unsupervised)
데이터레이블(정답)이 있는 데이터레이블 없이
목표입력 $X$가 주어졌을 때 정답 $Y$를 예측데이터를 그룹화하거나 차원을 축소
대표 기법분류(Classification), 회귀(Regression)군집화(Clustering), 차원 축소(PCA, t-SNE)
사용 예이메일 스팸 분류, 집값 예측, 이미지 분류고객 세분화, 이상치 탐지, 데이터 시각화

1-3. 과소적합 vs 과대적합

과소적합 (Underfitting)
  • 모델이 너무 단순해서 학습 데이터조차 잘 맞추지 못하는 상태
  • 학습·테스트 데이터 모두에서 성능이 낮다
  • 해결: 모델 복잡도 증가, 특성 추가, 학습 시간 증가
과대적합 (Overfitting)
  • 학습 데이터에만 과도하게 맞춰져 새 데이터에서 성능이 떨어지는 상태
  • 학습에서는 높고 테스트에서는 낮다
  • 해결: 정규화(Regularization), 데이터 증강, 조기 종료(Early Stopping)
이상적인 상태: 학습 데이터와 테스트 데이터 모두에서 적절한 성능을 보이는 균형 상태

실습 1 — 과소적합 ↔ 과대적합 직접 만들기

다항식 차수를 올리면 훈련 오차는 계속 줄지만 테스트 오차는 어느 지점부터 다시 커집니다. 그 “꺾이는 지점”이 바로 적절한 복잡도입니다. 노이즈와 데이터 개수도 바꿔보세요.

1-4. Train / Validation / Test 데이터 분할

분할용도비율
Train (학습)모델을 학습시키는 데 사용. 모델은 이 데이터로부터 패턴을 학습한다.보통 60~80%
Validation (검증)하이퍼파라미터를 조정하고 모델을 선택. 학습 중 성능을 모니터링하고 과적합을 방지.보통 10~20%
Test (테스트)최종 모델의 성능 평가. 학습에 전혀 사용되지 않은 “처음 보는 데이터”.보통 10~20%

참고: 간단한 실습에서는 Train/Test만 나누고 교차검증으로 Valid를 대체할 수 있습니다.

실습 2 — 분할 비율과 stratify 효과

클래스 비율이 불균형할 때 stratify 없이 나누면 특정 클래스가 한쪽에 몰릴 수 있습니다. [분할 20번 반복]으로 테스트셋 양성 비율이 얼마나 흔들리는지 보세요.

2. 탐색적 데이터 분석 (EDA)

EDA란? 데이터의 분포, 통계량, 관계를 시각화하여 데이터의 특성을 이해하는 과정. 바로 모델을 학습시키는 것보다, 데이터를 충분히 이해하는 것이 더 나은 모델을 만드는 지름길이다.
EDA에서 확인해야 할 항목
  1. 데이터 구조: 샘플 수, 특성 수, 데이터 타입
  2. 기초 통계량: 평균, 중앙값, 표준편차, 최솟값, 최댓값
  3. 결측치(Missing Values): 어떤 변수에 얼마나 결측이 있는가?
  4. 이상치(Outliers): 극단적인 값들이 존재하는가?
  5. 분포(Distribution): 타겟 변수와 특성들의 분포는 어떤가?
  6. 상관관계(Correlation): 변수들 간의 선형 관계는 어떠한가?

도구별 역할

도구역할
pandas DataFrame테이블 형태로 데이터를 저장하고 요약 통계, 데이터 선택·조작 기능을 제공
numpy 배열 연산배열 기반 고속 수치 연산과 통계 함수(평균·표준편차·히스토그램 등)를 지원
sns.heatmap상관계수 행렬을 색상으로 표현해 피처 간 상관관계를 직관적으로 파악
sns.histplot변수별 분포를 히스토그램과 KDE(커널 밀도 추정)로 동시에 시각화
sns.scatterplot이변량 산점도를 그려 변수 간 관계와 카테고리별 분포 차이를 표현
sns.pairplot여러 피처 쌍의 산점도·분포도를 한 번에 그려 상관관계와 분포 형태를 종합 탐색

2-3. 상관관계와 히트맵

$x$가 커질 때 $y$도 함께 커지는 경향을 띠면 “상관관계를 보인다”고 한다. 예측하려는 변수와 관계가 높은 특성은 문제를 푸는 데 중요한 열쇠가 될 수 있으므로 반드시 살펴본다.

Pearson 상관계수(Pearson's r) — 두 변수 사이의 선형관계를 $-1$에서 $1$ 사이로 표현.

$$r=\frac{\sum_i (x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum_i (x_i-\bar x)^2}\sqrt{\sum_i (y_i-\bar y)^2}}$$
  • $y=mx$ 형태로 엮여 있으면 높은 상관관계를 보인다.
  • $y=x^2$ 처럼 비선형 관계는 $x$의 분포에 따라 $r$이 높게도 낮게도 나오며, 완벽한 1이 되지 않는다.
⚠️ 상관관계는 인과관계가 아닙니다. 여름에 아이스크림 판매량이 늘고 동시에 익사 사고도 증가한다. 둘 사이에 높은 상관관계가 있지만 아이스크림이 익사의 원인은 아니다. (숨은 변수: 기온)
corr = df.corr(numeric_only=True)

fig, ax = plt.subplots(figsize=(10, 7))
n = len(corr)
mask = np.triu(np.ones((n, n)))     # 대각선 포함 위쪽 가리기
ax.grid(False)                       # 뒤 grid 제거
ax.set_title("Correlation between features")
sns.heatmap(data=corr, annot=True, fmt=".2f", cmap="coolwarm", mask=mask)
plt.show()
인자효과
annot=True각 칸에 수치를 함께 표시
fmt=".2f"소수점 두 자리 포맷
cmap="coolwarm"음수 파랑 ~ 양수 빨강
mask=np.triu(...)대각(자가상관=1)과 위쪽 삼각형(대칭 중복) 제거
ax.grid(False)가려진 영역 뒤의 격자 제거
⚠️ 원래 quality는 범주형 변수라 .corr()에서 제외되어야 하지만, 0/1/2가 연속형처럼 들어가 있어 계산이 됩니다. 해석할 때 이 점을 주의하세요.

    • 시계열: 이전 값이나 다음 값으로 채우기

실습 4 — 결측치를 평균 vs 중앙값으로 채우면?

분포가 치우쳐(skewed) 있을 때 평균 대체는 분포를 왜곡시키기 쉽습니다. 왜도와 결측 비율을 바꿔가며 원본/평균대체/중앙값대체의 통계량 변화를 비교하세요.

3-2. IQR 기반 이상치 탐지

이상치는 다른 데이터와 비교했을 때 값이 너무 크거나 작아서 눈에 띄는 데이터. 예: 대부분 150~190cm인데 250cm가 나오면 이상치일 가능성이 크다. 데이터 입력 실수, 측정 오류, 혹은 정말 드문 특별한 경우 때문에 발생한다.

IQR(사분위 범위): 데이터를 정렬해 아래 25% 지점 $Q_1$, 위 25% 지점 $Q_3$을 찾고,

$$\mathrm{IQR}=Q_3-Q_1,\qquad \text{정상 범위}=[\,Q_1-1.5\times \mathrm{IQR},\ \ Q_3+1.5\times \mathrm{IQR}\,]$$
  • 이 범위를 벗어나면 이상치로 판단
  • 평균·표준편차를 쓰는 방법보다 극단값에 덜 민감하고, 정규분포가 아니어도 사용 가능
def detect_outliers_iqr(data, column):
    Q1 = data[column].quantile(0.25)
    Q3 = data[column].quantile(0.75)
    IQR = Q3 - Q1
    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR
    return data[(data[column] < lower_bound) | (data[column] > upper_bound)]

outliers_alcohol = detect_outliers_iqr(df_missing, 'alcohol')
print(f"alcohol 이상치 개수: {len(outliers_alcohol)}")
sns.boxplot(x=df_missing['alcohol'])

이상치 처리 방법

  1. 삭제: 명백히 잘못된 값이면 해당 데이터를 삭제
  2. 변환: 로그 변환이나 제곱근 변환 등을 통해 데이터 분포를 조정
  3. 대체: 이상치를 상한·하한 경계값으로 바꾸거나 평균·중앙값으로 대체
중요: 무조건 제거하거나 바꾸기 전에 왜 생겼는지를 먼저 확인하세요. 실측 오류라면 제거하는 것이 맞지만, 의미 있는 값이라면 보존하거나 변환하는 것이 더 적절합니다.

실습 5 — IQR 이상치 탐지기 (직접 계산해 보기)

숫자를 쉼표로 입력하면 $Q_1,Q_3,\mathrm{IQR}$, 경계, 이상치를 즉시 계산하고 boxplot을 그립니다. $k$(기본 1.5)를 바꾸면 판정이 어떻게 달라지는지도 확인하세요.

4. 데이터 전처리

4-1. train_test_split

from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
        X, y,
        test_size=0.3,        # 테스트 30%
        random_state=42,      # 결과 고정(재현성)
        stratify=y)           # 클래스 비율 유지 (한쪽 쏠림 방지)
인자의미
test_size테스트 비율(0~1) 또는 개수
random_state난수 시드 고정 → 실행할 때마다 같은 분할
stratify=yy의 클래스 비율을 train/test에 동일하게 유지. “훈련에 전부 0, 검증에 전부 1” 같은 사고 방지
shuffle기본 True. 시계열은 False로 두고 시간순 분할해야 함
회귀에서 stratify — 타겟이 연속형이면 그대로 stratify가 불가능하다. pd.qcut(y, 10, labels=False) 처럼 구간으로 나눈 뒤 stratify에 넘기면 된다.

4-2. 표준화 (StandardScaler)

$$z=\frac{x-\mu}{\sigma}\qquad(\mu,\sigma\ \text{는 } \mathbf{train}\ \text{에서 계산})$$ 왜 표준화가 중요할까?
  • 로지스틱 회귀는 최적화 과정에서 특성 스케일 차이에 민감해 수렴 속도와 안정성이 달라질 수 있다.
  • L1/L2 규제는 계수 크기에 직접 작용하므로, 표준화하지 않으면 큰 스케일 특성이 과도한 영향을 준다.
  • 거리 기반 기법(KNN, KMeans, PCA)은 스케일이 큰 특성이 거리를 지배해버린다.

4-3. 데이터 누수(Data Leakage)

원칙
  1. 먼저 train/test를 분할한다.
  2. train 데이터로만 통계량(평균, 표준편차, IQR 등)을 계산한다.
  3. train에서 계산한 통계량을 test에도 동일하게 적용한다.
❌ 잘못된 예: 전체 데이터로 스케일링 → train/test 분할
✅ 올바른 예: train/test 분할 → train으로 scaler fit → 각각 transform 
scaler = StandardScaler()
scaler.fit(X_train)                       # ← train 통계만 학습
X_train_norm = scaler.transform(X_train)
X_test_norm  = scaler.transform(X_test)   # ← test는 transform만!

# fit_transform은 train에만 쓴다
X_train_norm = scaler.fit_transform(X_train)

실습 6 — 데이터 누수가 성능을 어떻게 부풀리는가

노이즈뿐인 특성을 잔뜩 만들고, 전체 데이터로 특성 선택을 한 뒤 분할하면 실제로는 아무 정보가 없는데도 테스트 정확도가 부풀려집니다. 올바른 순서와 비교해 보세요.

5. 모델 학습과 평가

5-1. scikit-learn 파이프라인

대부분의 sklearn 모듈은 다음 흐름으로 구동된다.
  1. Instance 선언 — model = LogisticRegression()
  2. .fit() 을 통한 매개변수 학습 혹은 초매개변수 설정
  3. 학습한 매개변수를 이용해 .predict() 로 예측, 혹은 .transform() 수행
역할클래스메서드
전처리(Transformer)StandardScaler, SimpleImputer, PCAfit / transform / fit_transform
예측(Estimator)LogisticRegression, LinearRegressionfit / predict / predict_proba
군집(Clusterer)KMeansfit / predict / fit_predict
from sklearn.linear_model import LogisticRegression
clf = LogisticRegression(max_iter=1000)     # ConvergenceWarning 시 max_iter↑ 또는 표준화
clf.fit(X_train_norm, y_train)
y_pred = clf.predict(X_test_norm)
ConvergenceWarning이 뜬다면? 최적화가 정해진 반복 안에 수렴하지 못했다는 뜻. ① 특성을 표준화했는지 확인 → ② max_iter를 늘리기 → ③ solver 변경

5-2. 분류 평가지표

혼동 행렬 (Confusion Matrix)

예측 0 (Negative)예측 1 (Positive)
실제 0TN (True Negative)FP (False Positive) · 과검출
실제 1FN (False Negative) · 미검출TP (True Positive)
$$\text{Accuracy}=\frac{TP+TN}{TP+TN+FP+FN},\qquad \text{Precision}=\frac{TP}{TP+FP},\qquad \text{Recall}=\frac{TP}{TP+FN}$$ $$F_1=2\cdot\frac{\text{Precision}\cdot\text{Recall}}{\text{Precision}+\text{Recall}}$$
  • Precision(정밀도): 1이라고 예측한 것 중 진짜 1의 비율 → 과검출(FP)에 민감
  • Recall(재현율): 진짜 1 중에서 찾아낸 비율 → 미검출(FN)에 민감
  • F1: 둘의 조화평균. 클래스 불균형에서 accuracy보다 신뢰할 만함
해석 힌트 — 대각선 값(정분류)이 클수록 좋고, 비대각선 값(오분류)이 어떤 클래스 쌍에서 큰지 확인. precision/recall/F1을 함께 보면 어떤 오류 유형(과검출/미검출)이 많은지 파악하기 쉽다.

실습 7 — 임계값(threshold)을 움직이면 지표가 어떻게 변할까

로지스틱 회귀는 확률을 내놓고, 기본적으로 0.5를 기준으로 0/1을 정합니다. 임계값을 낮추면 Recall↑ Precision↓, 높이면 그 반대. 정답은 문제에 따라 다릅니다.

5-3. ROC 곡선과 AUC

  • 임계값을 0→1로 훑으면서 $(\text{FPR},\ \text{TPR})$ 점을 이은 곡선
  • $\text{TPR}=\text{Recall}=\dfrac{TP}{TP+FN}$, $\text{FPR}=\dfrac{FP}{FP+TN}$
  • AUC: 곡선 아래 면적. 0.5 = 무작위, 1.0 = 완벽
  • 임계값을 정하지 않고 모델 자체의 순위 매기기 능력을 평가한다
from sklearn.metrics import roc_curve, roc_auc_score

y_score = clf.predict_proba(X_test_norm)[:, 1]   # 양성(1) 클래스 확률
fpr, tpr, thresholds = roc_curve(y_test, y_score)
auc = roc_auc_score(y_test, y_score)

plt.plot(fpr, tpr, label=f'ROC-AUC = {auc:.3f}')
plt.plot([0, 1], [0, 1], linestyle='--', label='Random')
⚠️ predict_proba에 넣는 데이터는 반드시 학습할 때와 같은 전처리를 거쳐야 합니다. clf.fit(X_train_norm,...) 해놓고 clf.predict_proba(X_test)(원본)를 넣으면 성능이 엉뚱해집니다.

실습 8 — ROC 곡선이 그려지는 과정

임계값을 움직이면 곡선 위의 빨간 점이 이동합니다. 분리도를 올리면 곡선이 왼쪽 위로 붙고 AUC가 1에 가까워집니다.

5-4. 회귀 평가지표

$$\text{RMSE}=\sqrt{\frac1n\sum_i (y_i-\hat y_i)^2},\qquad \text{MAE}=\frac1n\sum_i |y_i-\hat y_i|,\qquad R^2=1-\frac{\sum_i (y_i-\hat y_i)^2}{\sum_i (y_i-\bar y)^2}$$
지표특징단위
RMSE큰 오차에 민감(제곱). 타겟과 같은 단위라 해석이 쉬움타겟과 동일
MAE이상치에 덜 민감. 평균적인 오차 크기타겟과 동일
$R^2$모델의 설명력. 1에 가까울수록 좋음. 평균 예측보다 나쁘면 음수도 가능무단위
from sklearn.metrics import root_mean_squared_error, mean_absolute_error, r2_score
rmse = root_mean_squared_error(y_test, y_pred)   # sklearn >= 1.4
mae  = mean_absolute_error(y_test, y_pred)
r2   = r2_score(y_test, y_pred)

실습 9 — 이상치 하나가 RMSE와 MAE에 미치는 영향

이상치의 크기를 키워보세요. RMSE는 급격히 올라가지만 MAE는 완만하게 오릅니다. “이상치가 많은 데이터에서 MAE를 보라”는 말의 근거입니다.

5-5. 교차검증 (Cross-Validation)

모델의 성능을 더 신뢰성 있게 평가하기 위해 데이터를 여러 번 나누어 학습과 검증을 반복하는 방법. 단순히 한 번의 train/test 분할만으로 성능을 측정하면, 우연히 데이터가 편향되어 들어가 평가 결과가 과대·과소 추정될 수 있다.
  • 데이터를 여러 개의 폴드(fold)로 나눈 뒤, 각 폴드가 한 번씩 검증 데이터가 되도록 순환하며 학습·평가
  • 여러 번의 점수를 평균하면 분할에 따른 편차를 줄이고 일반화 성능을 안정적으로 추정
from sklearn.model_selection import cross_val_score

f1_scores = cross_val_score(clf, X_train_norm, y_train, cv=5, scoring='f1')
print("Average F1-score (CV):", f1_scores.mean())
# scoring 예: 'accuracy', 'f1', 'roc_auc', 'r2', 'neg_root_mean_squared_error'

실습 10 — K-Fold 교차검증 시각화

$k$를 바꾸면 폴드가 어떻게 나뉘는지, 각 폴드 점수와 평균·표준편차가 어떻게 변하는지 볼 수 있습니다. $k$가 클수록 학습 데이터는 많아지지만 계산 비용이 커집니다.

6. 비지도학습 — PCA와 KMeans

6-1. PCA (주성분 분석)

데이터의 차원을 줄여서 주요한 패턴을 두세 개의 축으로 표현해 주는 기법. 고차원 데이터라도 2~3차원에서 쉽게 시각화할 수 있어 분포나 구조를 직관적으로 파악할 수 있다.
  • 분산이 가장 큰 방향을 첫 번째 주성분(PC1), 그와 직교하면서 분산이 큰 방향을 PC2로 잡는다
  • explained_variance_ratio_ 로 각 주성분이 설명하는 분산 비율을 확인
  • 거리 기반이므로 표준화 후에 적용하는 것이 일반적
from sklearn.decomposition import PCA
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_train_norm)
print(pca.explained_variance_ratio_)   # 예: [0.36, 0.19] → 두 축이 55% 설명

실습 11 — PCA가 찾는 축 직접 보기

데이터 구름의 방향(상관)과 퍼짐을 바꿔보세요. PC1(빨강)이 분산이 가장 큰 방향, PC2(파랑)가 그와 직교하는 방향으로 자동으로 정렬됩니다.

6-2. KMeans

비지도 학습 기반의 군집화 알고리즘. 데이터들을 유사한 특성을 가진 그룹(클러스터)으로 나눈다. PCA로 축소한 데이터를 KMeans에 적용하면, 데이터가 어떤 기준으로 묶이는지 시각적으로 확인할 수 있다.
알고리즘
  1. $k$개의 중심(centroid)을 초기화
  2. 각 점을 가장 가까운 중심에 배정
  3. 각 클러스터의 평균으로 중심을 이동
  4. 중심이 더 이상 움직이지 않을 때까지 2~3 반복
from sklearn.cluster import KMeans
kmeans = KMeans(n_clusters=2, random_state=42, n_init=10)
y_cluster = kmeans.fit_predict(X_pca)
해석 힌트 — K-Means 라벨 번호(0,1,…)는 실제 클래스 번호와 대응하지 않는다. 색이 서로 바뀌어도 “분리 방향”이 같으면 잘 잡은 것이다.

실습 12 — KMeans 반복 과정 한 스텝씩

[한 스텝]을 누를 때마다 ① 배정 ② 중심 이동이 번갈아 일어납니다. 초기 중심 위치에 따라 결과가 달라지는 것(n_init이 필요한 이유)도 확인해 보세요.
