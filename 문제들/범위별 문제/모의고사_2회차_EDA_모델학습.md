## 객관식 (1~28)

**1.** AI, ML, DL의 포함 관계로 옳은 것은?
① DL ⊃ ML ⊃ AI ② AI ⊃ ML ⊃ DL ③ AI = ML = DL ④ ML ⊃ AI ⊃ DL

**2.** 머신러닝(ML)에 대한 설명으로 가장 적절한 것은?
① 규칙을 사람이 모두 직접 코딩하는 기술이다 ② 데이터로부터 패턴을 학습하는 AI의 한 방법이다 ③ 반드시 신경망 구조를 사용해야 한다 ④ 지도학습만을 의미한다

**3.** 지도학습과 비지도학습을 구분하는 가장 핵심적인 기준은?
① 데이터의 크기 ② 레이블(정답)의 유무 ③ 사용하는 프로그래밍 언어 ④ 모델의 파라미터 수

**4.** 과대적합(overfitting)의 특징으로 옳은 것은?
① 훈련 데이터와 테스트 데이터 모두에서 성능이 낮다 ② 훈련 데이터에서는 성능이 높고 테스트 데이터에서는 성능이 낮다 ③ 훈련 데이터에서는 성능이 낮고 테스트 데이터에서는 높다 ④ 항상 모델이 너무 단순해서 발생한다

**5.** 과소적합(underfitting)의 해결책으로 가장 적절한 것은?
① 정규화(Regularization) 강화 ② 조기 종료(Early stopping) ③ 모델 복잡도 증가, 특성 추가 ④ 데이터 증강만으로 해결 가능

**6.** Train/Validation/Test 데이터 분할에 대한 설명으로 옳지 않은 것은?
① Train은 모델이 패턴을 학습하는 데 사용된다 ② Validation은 하이퍼파라미터 조정과 과적합 방지 모니터링에 사용된다 ③ Test는 학습에 전혀 사용되지 않은 데이터로 최종 성능을 평가한다 ④ Test 데이터는 모델 학습 중 반복적으로 사용해도 무방하다

**7.** EDA(탐색적 데이터 분석)에서 확인해야 할 항목으로 거리가 먼 것은?
① 결측치와 이상치 유무 ② 변수들 간의 상관관계 ③ 모델의 최종 배포 서버 사양 ④ 타겟 변수와 특성들의 분포

**8.** Pearson 상관계수 $r$에 대한 설명으로 옳은 것은?
① 값의 범위는 $-1$에서 $1$ 사이이다 ② 항상 인과관계를 의미한다 ③ 비선형 관계도 항상 완벽하게 포착한다 ④ 범위는 $0$에서 $100$ 사이이다

**9.** $y=x^2$처럼 뚜렷한 비선형 관계가 있음에도 Pearson 상관계수 $r$이 0에 가깝게 나올 수 있는 이유는?
① Pearson 상관계수는 선형 관계만을 측정하기 때문 ② 계산 오류가 항상 발생하기 때문 ③ 이상치가 전혀 없기 때문 ④ 데이터 개수가 너무 많기 때문

**10.** 결측치 처리 방법으로 적절하지 않은 설명은?
① 결측치가 있는 행/열을 삭제할 수 있다 ② 평균, 중앙값, 최빈값으로 대체할 수 있다 ③ 분포가 치우쳐 있어도 항상 평균으로 대체하는 것이 최선이다 ④ train으로 학습한 대체 통계량을 test에도 동일하게 적용해야 한다

**11.** IQR(사분위 범위) 기반 이상치 탐지에서 이상치로 판단하는 정상 범위 기준은?
① $[Q_1 - \mathrm{IQR}, Q_3 + \mathrm{IQR}]$ ② $[Q_1 - 1.5\times\mathrm{IQR}, Q_3 + 1.5\times\mathrm{IQR}]$ ③ $[Q_1, Q_3]$ ④ $[\mathrm{평균}-2\sigma, \mathrm{평균}+2\sigma]$

**12.** 이상치 처리에 대한 설명으로 가장 적절한 것은?
① 이상치는 발견 즉시 무조건 삭제해야 한다 ② 왜 생겼는지 먼저 확인한 뒤 삭제/변환/대체 여부를 판단해야 한다 ③ 이상치는 절대 실제 값일 수 없다 ④ IQR 방법은 정규분포일 때만 사용 가능하다

**13.** `train_test_split`의 `stratify=y` 옵션의 역할은?
① 데이터를 무작위로 섞지 않는다 ② y의 클래스 비율을 train/test에 동일하게 유지한다 ③ 테스트 비율을 자동으로 결정한다 ④ 결측치를 자동으로 제거한다

**14.** StandardScaler가 수행하는 변환 공식으로 옳은 것은?
① $z = x - \mu$ ② $z = (x-\mu)/\sigma$ ③ $z = x/\sigma^2$ ④ $z = (x-\min)/(\max-\min)$

**15.** 표준화(StandardScaler)가 특히 중요한 경우로 거리가 먼 것은?
① 로지스틱 회귀처럼 최적화 기반 모델 ② KNN, KMeans, PCA 같은 거리 기반 기법 ③ L1/L2 규제를 사용하는 모델 ④ 결측치가 전혀 없는 순수 범주형 데이터만 있는 경우

**16.** 데이터 누수(Data Leakage)를 방지하는 올바른 절차는?
① 전체 데이터로 스케일링한 뒤 train/test로 분할한다 ② train/test로 먼저 분할한 뒤 train 데이터로만 통계량을 계산해 적용한다 ③ test 데이터로 scaler를 fit한다 ④ train과 test를 매번 합쳐서 재학습한다

**17.** `scaler.fit_transform(X_test)`처럼 test 데이터에 `fit_transform`을 적용하면 생기는 문제는?
① 계산 속도가 느려진다 ② test 통계로 다시 fit하게 되어 데이터 누수가 발생한다 ③ 아무 문제가 없다 ④ 결측치가 자동으로 생긴다

**18.** 혼동행렬(Confusion Matrix)에서 실제로는 양성인데 음성으로 잘못 예측한 경우를 가리키는 것은?
① TP(True Positive) ② TN(True Negative) ③ FP(False Positive) ④ FN(False Negative)

**19.** Precision(정밀도)에 대한 설명으로 옳은 것은?
① 1이라고 예측한 것 중 실제로 1인 비율로, 과검출(FP)에 민감하다 ② 실제 1 중에서 찾아낸 비율이다 ③ 항상 Recall과 같은 값이다 ④ 혼동행렬과 무관한 지표이다

**20.** F1-score에 대한 설명으로 옳은 것은?
① Precision과 Recall의 산술평균이다 ② Precision과 Recall의 조화평균으로, 클래스 불균형에서 accuracy보다 신뢰할 만하다 ③ TP만으로 계산하는 지표다 ④ 회귀 문제에서만 사용하는 지표다

**21.** ROC 곡선과 AUC에 대한 설명으로 옳지 않은 것은?
① ROC 곡선은 임계값을 0→1로 훑으며 (FPR, TPR) 점을 이은 곡선이다 ② AUC 0.5는 무작위 수준, 1.0은 완벽한 분류를 의미한다 ③ AUC는 특정 임계값 하나만을 기준으로 계산된다 ④ AUC는 모델 자체의 순위 매기기 능력을 평가한다

**22.** 회귀 평가지표 중 이상치에 상대적으로 덜 민감한 지표는?
① RMSE ② MAE ③ $R^2$ ④ 정확도(Accuracy)

**23.** $R^2$(결정계수)에 대한 설명으로 옳은 것은?
① 항상 0과 1 사이의 값만 가진다 ② 평균 예측보다 성능이 나쁘면 음수가 될 수도 있다 ③ 단위를 가지는 지표다 ④ 이상치에 가장 민감한 지표다

**24.** 교차검증(Cross-Validation)을 수행하는 주된 이유는?
① 학습 속도를 항상 더 빠르게 하기 위해 ② 데이터를 여러 번 나누어 평가함으로써 분할에 따른 편차를 줄이고 일반화 성능을 안정적으로 추정하기 위해 ③ 결측치를 자동으로 채우기 위해 ④ 항상 정확도를 100%로 만들기 위해

**25.** PCA(주성분분석)에 대한 설명으로 옳지 않은 것은?
① 분산이 가장 큰 방향을 첫 번째 주성분(PC1)으로 잡는다 ② 거리 기반 기법이므로 표준화 이후 적용하는 것이 일반적이다 ③ PCA는 지도학습 기법으로 레이블이 반드시 필요하다 ④ `explained_variance_ratio_`로 각 주성분이 설명하는 분산 비율을 확인할 수 있다

**26.** KMeans 알고리즘의 동작 순서로 옳은 것은?
① 중심 초기화 → 각 점을 가장 가까운 중심에 배정 → 클러스터 평균으로 중심 이동 → 반복 ② 무조건 한 번의 계산으로 끝난다 ③ 레이블을 먼저 부여한 후 군집 개수를 계산한다 ④ 지도학습처럼 정답 레이블을 필요로 한다

**27.** KMeans의 군집 라벨(0, 1, 2 …)에 대한 설명으로 옳은 것은?
① 항상 실제 클래스 번호와 정확히 일치한다 ② 실제 클래스 번호와 반드시 대응하지는 않으며, 분리 방향이 같으면 잘 잡힌 것으로 본다 ③ 라벨 번호가 클수록 더 좋은 군집이다 ④ KMeans는 라벨을 부여하지 않는다

**28.** 불균형 데이터에서 accuracy만으로 모델을 평가할 때의 문제점은?
① 계산이 너무 오래 걸린다 ② 소수 클래스를 무시하고 전부 다수 클래스로 예측해도 높은 값이 나올 수 있다 ③ accuracy는 항상 0에서 1 사이 값이 아니게 된다 ④ 회귀 문제에서는 계산 자체가 불가능하다
