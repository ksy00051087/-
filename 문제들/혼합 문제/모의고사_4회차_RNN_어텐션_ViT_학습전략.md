## 객관식 (1~28)

**1.** CNN이 갖는 두 가지 한계로 옳은 것은?
① 파라미터가 너무 적다는 점, 계산 속도가 느리다는 점 ② 순서를 반영하지 못한다는 점, 긴 거리 의존성을 다루기 어렵다는 점 ③ 항상 과적합이 발생한다는 점, 결측치를 처리하지 못한다는 점 ④ 이미지 데이터만 처리할 수 있다는 점, 회귀 문제를 풀 수 없다는 점

**2.** RNN(Recurrent Neural Network)에 대한 설명으로 옳은 것은?
① 순차적 데이터를 처리하기 위해 이전 단계의 정보를 은닉 상태로 다음 단계에 전달하는 구조다 ② 모든 시점마다 서로 다른 독립적인 가중치를 사용한다 ③ 병렬 연산에 매우 유리한 구조다 ④ 이미지 전용 신경망 구조다

**3.** 순수(vanilla) RNN의 은닉 상태 갱신 수식으로 옳은 것은?
① $h_t = \mathrm{ReLU}(W_{hh}h_{t-1}+W_{xh}x_t)$ ② $h_t = \tanh(W_{hh}h_{t-1}+W_{xh}x_t)$ ③ $h_t = \sigma(W_{hh}\cdot h_{t-1})$ ④ $h_t = W_{hy}x_t$

**4.** "문장 → 감정 분류(긍/부정)"와 같은 RNN 구조 유형은?
① One-to-One ② One-to-Many ③ Many-to-One ④ Many-to-Many

**5.** RNN이 시점마다 동일한 가중치 $W$를 재사용하는 가장 근본적인 이유는?
① 계산량을 항상 최소화하기 위해서만 ② 길이가 정해지지 않은(가변 길이) 입력을 처리하고, 학습한 방법을 길이에 상관없이 재사용하기 위해서 ③ 역전파를 아예 사용하지 않기 위해서 ④ 활성화 함수를 사용하지 않기 위해서

**6.** RNN에서 기울기 소실/폭발이 발생하는 근본적인 이유는?
① 활성화 함수로 ReLU를 사용하기 때문 ② 역전파 시 동일한 가중치 $W$가 시퀀스 길이만큼 반복적으로 곱해지기 때문 ③ 배치 크기가 너무 크기 때문 ④ 입력 데이터가 정규화되지 않았기 때문

**7.** 기울기 폭발을 막기 위한 "절삭(clipping)"에 대한 설명으로 옳은 것은?
① 기울기 소실 문제까지 완전히 해결한다 ② 폭발은 막을 수 있지만 기울기 소실 문제는 해결하지 못하는 임시방편이다 ③ LSTM보다 근본적인 해결책이다 ④ 학습 속도를 항상 감소시킨다

**8.** LSTM의 셀 상태(Cell State)와 은닉 상태(Hidden State)에 대한 설명으로 옳은 것은?
① 셀 상태는 단기 정보, 은닉 상태는 장기 정보를 저장한다 ② 셀 상태는 장기(long-term) 정보를, 은닉 상태는 단기(short-term) 정보를 저장한다 ③ 둘은 완전히 동일한 벡터다 ④ LSTM에는 셀 상태가 존재하지 않는다

**9.** LSTM의 3가지 게이트 중 "과거 정보를 얼마나 유지/제거할지"를 결정하는 게이트는?
① 입력 게이트(input gate) ② 망각 게이트(forget gate) ③ 출력 게이트(output gate) ④ 어텐션 게이트

**10.** LSTM의 셀 상태 갱신식 $c_t = f\odot c_{t-1} + i\odot g$ 에서, 기울기 소실을 완화하는 핵심 요인은?
① 곱셈 경로만 존재하기 때문에 ② 덧셈 형태의 경로가 존재해 기울기를 장기적으로 보존할 수 있기 때문에 ③ 시그모이드를 전혀 사용하지 않기 때문에 ④ 셀 상태가 항상 0이기 때문에

**11.** 어텐션 메커니즘에서 Query, Key, Value에 대한 설명으로 옳은 것은?
① Query는 질의 대상, Key는 입력 내 다른 토큰의 특성, Value는 실제 정보를 담는다 ② Query와 Key는 완전히 같은 개념이다 ③ Value는 유사도 계산에만 사용된다 ④ Key는 학습되지 않는 고정값이다

**12.** 어텐션 공식 $\mathrm{softmax}\left(\dfrac{QK^\top}{\sqrt{d_k}}\right)V$ 에서 $\sqrt{d_k}$로 나누는 스케일링의 목적은?
① 계산을 더 복잡하게 만들기 위해서 ② 내적 값이 커져 softmax가 지나치게 뾰족해지는 것을 방지하기 위해서 ③ Query 벡터의 차원을 줄이기 위해서 ④ Value를 정규화하기 위해서

**13.** 교차 어텐션(Cross-Attention)에 대한 설명으로 옳은 것은?
① Query, Key, Value가 모두 같은 시퀀스에서 나온다 ② 서로 다른(이종) 데이터에서 Query와 Key/Value를 각각 정의해 연결한다(예: 이미지-텍스트) ③ 항상 이미지 데이터에만 사용된다 ④ 셀프 어텐션과 완전히 동일한 계산이다

**14.** Vision Transformer(ViT)가 이미지를 처리하는 방식으로 옳은 것은?
① 이미지를 패치(patch)로 나눈 뒤 위치 인코딩을 더해 토큰 시퀀스로 변환한다 ② 이미지를 그대로 합성곱 필터에 통과시킨다 ③ 위치 정보를 전혀 사용하지 않는다 ④ 패치 크기와 무관하게 항상 동일한 토큰 개수를 사용한다

**15.** CNN과 ViT의 전역 관계 학습 방식 차이로 옳은 것은?
① CNN은 수용영역을 넓혀가며 전역을 이해하고, ViT는 어텐션 한 번으로 전역 맥락을 이해할 수 있다 ② 둘 다 전역 관계를 전혀 학습할 수 없다 ③ ViT는 항상 CNN보다 계산량이 적다 ④ CNN은 위치 인코딩이 반드시 필요하다

**16.** ViT 학습 시 유의점으로 옳은 것은?
① CNN과 같은 귀납적 편향(inductive bias)이 없어 정규화 기법·데이터 증강이 특히 중요하다 ② 항상 적은 데이터로도 CNN보다 좋은 성능을 낸다 ③ 파라미터 수가 매우 적어 가볍다 ④ 데이터 증강이 전혀 필요하지 않다

**17.** CNN, RNN, LSTM, Attention(Self-Attention)의 강점/약점 비교로 옳지 않은 것은?
① CNN은 지역적 특성에 강하지만 장거리 맥락 이해가 어렵다 ② RNN은 데이터 순서를 반영하지만 장거리 맥락 학습이 어렵다(기울기 소실/폭발) ③ Attention은 장거리 맥락에 강하지만 데이터 순서 정보가 없어 위치 인코딩이 필요하다 ④ LSTM은 순서 반영이 전혀 불가능하다

**18.** 활성화 함수 Sigmoid의 문제점으로 옳은 것은?
① 항상 음수를 출력한다 ② 입력이 매우 크거나 작으면 출력이 포화되어 역전파 신호가 소실될 수 있다 ③ 출력 범위가 무한대이다 ④ 지수 연산을 전혀 사용하지 않는다

**19.** ReLU 함수의 대표적인 문제점("Dead ReLU")은?
① 항상 계산이 매우 느리다 ② 음수 입력에서 뉴런이 완전히 죽어버릴 수 있다 ③ 출력이 항상 0~1 사이로 제한된다 ④ 지수 연산 때문에 계산 비용이 매우 크다

**20.** Leaky ReLU가 일반 ReLU와 다른 점은?
① 양의 영역에서 기울기가 0이다 ② 음수 영역에도 작은 기울기(예: 0.01)를 부여해 뉴런이 완전히 죽지 않게 한다 ③ 항상 ReLU보다 성능이 우세하다 ④ 0 중심 대칭 함수다

**21.** 가중치를 모두 0으로 초기화했을 때 발생하는 문제는?
① 학습 속도가 매우 빨라진다 ② 모든 뉴런의 출력과 기울기가 동일해져 서로 다른 패턴을 학습하지 못한다 ③ 아무 문제가 없다 ④ 항상 과적합이 발생한다

**22.** He 초기화의 표준편차 공식으로 옳은 것은? (ReLU 사용 가정, $D_{in}$: 입력 차원)
① $1/\sqrt{D_{in}}$ ② $\sqrt{2/D_{in}}$ ③ $D_{in}/2$ ④ $2\sqrt{D_{in}}$

**23.** Xavier 초기화와 He 초기화의 차이로 옳은 것은?
① He 초기화는 ReLU가 입력의 절반(음수)을 0으로 만드는 것을 감안해 분산을 Xavier의 2배로 설정한다 ② 둘은 완전히 동일한 공식이다 ③ Xavier 초기화는 항상 0으로 초기화한다 ④ He 초기화는 Sigmoid 전용이다

**24.** 가중치 감소(Weight Decay, L2 정규화)의 목적으로 옳은 것은?
① 가중치가 너무 커져 특정 입력에 과도하게 반응(과적합)하는 것을 막기 위함 ② 학습 속도를 항상 빠르게 하기 위함 ③ 활성화 함수를 대체하기 위함 ④ 데이터 정규화를 대체하기 위함

**25.** Inverted Dropout에 대한 설명으로 옳은 것은?
① 학습 시 살아남은 뉴런의 출력을 $1/(1-p)$배로 스케일링하여, 테스트 시에는 추가 연산 없이 그대로 사용할 수 있게 한다 ② 테스트 시에만 스케일링을 적용한다 ③ 드롭아웃 비율 $p$와 무관하게 항상 동일하게 동작한다 ④ 학습 파라미터를 새로 추가하는 기법이다

**26.** 학습률 스케줄링 중 "코사인 감소(cosine decay)"에 대한 설명으로 옳은 것은?
① 학습률이 계단식으로 급격히 변한다 ② 학습 곡선이 부드럽게 감소하도록 조정하는 가장 널리 쓰이는 방식이다 ③ 학습률이 항상 일정하게 유지된다 ④ 학습이 진행될수록 학습률이 계속 증가한다

**27.** 하이퍼파라미터 탐색 시 널리 쓰이는 실용적 전략으로 옳은 것은?
① 반드시 모든 조합을 끝까지 학습시켜 비교해야 한다 ② 작은 샘플로 일부러 과적합시켜 초기화·학습률 문제를 진단하고, 후보 조합은 1~5 epoch만 짧게 훈련해 검증 성능으로 비교한다 ③ 학습률은 항상 고정값 하나만 사용해야 한다 ④ 검증 세트는 사용하지 않는 것이 원칙이다

**28.** 데이터 전처리에서 이미지에 `Normalize(mean, std)`를 적용하는 것은 EDA/모델학습 차시의 어떤 기법과 같은 발상인가?
① PCA ② StandardScaler ③ KMeans ④ 교차검증
