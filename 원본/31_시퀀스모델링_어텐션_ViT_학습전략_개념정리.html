0학습 개관

■ 이번 자료의 질문 "좋은 구조만으로는 충분하지 않다 → 훈련 전략이 필요하다"는 관점에서, (1) CNN 이후 시퀀스·장거리 의존성 문제를 어떻게 푸는지, (2) 구조를 정했다면 어떻게 안정적으로 학습시키는지 두 갈래로 정리합니다.

1CNN만으로는 부족한 이유

! CNN의 두 가지 한계
  • 순서 무시: "약을 먹고 잠을 자고" vs "잠을 자고 약을 먹고"처럼 순서가 문맥·의미를 바꾸는 데이터(텍스트, 음성)를 CNN은 그대로 반영하지 못함.
  • 긴 거리 의존성 부족: 컨볼루션은 국소적(local) 영역에 집중하므로, 멀리 떨어진 요소 간의 관계는 receptive field를 아주 깊이 쌓아야 겨우 반영됨.
↺ 복습 연결 — 3차시 CNN Receptive Field(수용영역) 개념은 3차시에서 다룬 "층이 깊어질수록 한 뉴런이 보는 원본 영역이 커진다"는 내용 그대로입니다. 여기서는 그 receptive field를 무한히 넓혀야만 장거리 관계를 볼 수 있다는 점이 한계로 지적됩니다.

이 두 한계를 풀기 위한 흐름이 이 자료의 뼈대입니다: 순서 문제 → RNN, 장거리 의존성 문제 → Attention / ViT.

2-1RNN (Recurrent Neural Nets)

■ 정의 순차적(sequential) 데이터를 처리하기 위해 고안된 신경망 구조. 이전 단계의 정보를 은닉 상태(hidden state)로 다음 단계에 전달하여 시간/순서의 흐름을 반영합니다.

다섯 가지 구성 요소

구성요소역할
Input Chars (x_t)현재 시점 입력 (One-hot encoding 등으로 벡터화)
Hidden Layer (h_t)현재 입력 + 이전 은닉상태를 합쳐 만든 내부 메모리. "이전까지의 문맥(Context)"을 담아 다음 단계로 전달
W_xh입력 → 은닉 변환 가중치
W_hh이전 은닉 → 현재 은닉 변환 가중치 (재귀 연결의 핵심)
W_hy / Output Layer은닉 → 출력 변환. 각 값은 다음 문자가 될 확률 점수
★ 핵심 수식 $$h_t = f_W(h_{t-1}, x_t)$$ 데이터의 시계열 특징을 반영하는 모델이지만, RNN 상수(W)는 시계열(순서)에 무관하게 동일하게 재사용됩니다. 순수(vanilla) RNN에서는: $$h_t = \tanh(W_{hh}h_{t-1} + W_{xh}x_t)$$ tanh는 비선형 변환을 통해 더 복잡한 패턴 학습을 가능하게 합니다.
구조설명대표 예시
One-to-One단일 입력 → 단일 출력이미지 → 라벨 (CNN 분류)
One-to-Many단일 입력 → 시퀀스 출력이미지 → 캡션 생성, 음악 생성, 문장 생성
Many-to-One시퀀스 입력 → 단일 출력문장 → 감정 분류(긍/부정), 음성 → 단일 라벨, 비디오 → 행동 분류
Many-to-Many시퀀스 입력 → 시퀀스 출력기계 번역(영어 → 한국어), 음성 → 텍스트
+ 더 알아보기 — RNN도 결국 "펼치면" 깊은 신경망 재귀(recursion) 표현은 사이클(cycle) 하나로 그려지지만, 시간축으로 펼치면(unroll) $t=1,\dots,T$ 개의 층이 W를 공유하는 매우 깊은 신경망과 같습니다. 이 때문에 역전파(BPTT, Backpropagation Through Time)는 T번의 층을 통과하며, 4차시에서 다룰 기울기 소실/폭발 문제가 CNN보다 훨씬 두드러지게 나타납니다.

2-2단순 RNN의 한계

! 기울기 폭발 혹은 소실
  • 역전파의 시퀀스 데이터가 적용되면서 선형가중치 W가 기울기 계산 시 계속 곱셈으로 반영됨.
  • |W|의 특이값 ↑ → 곱할수록 무한히 커짐 → 기울기 폭발
  • |W|의 특이값 ↓ → 곱할수록 0에 수렴 → 기울기 소실
  • 이상적으로 W의 특이값이 1이면 온전한 학습이 가능하지만, 실제로 그렇게 유지되기는 어려움.
■ "강제 절삭"은 임시방편 폭발하지 않도록 기울기 값을 절삭(clipping)할 수는 있지만, 결국 잘못된 기울기 값을 양산하는 문제가 남습니다. 기울기 소실은 절삭으로 해결되지 않으며, 근본적으로 다른 모델(LSTM 등)이 필요합니다.
실습 02 · 기울기 소실/폭발 시뮬레이터

|W|^t 값의 변화로 보는 장기 의존성 붕괴

단순 RNN의 역전파 기울기는 대략 W^T 형태로 곱해집니다. |W|와 시퀀스 길이 T를 바꿔가며 기울기가 어떻게 폭발/소실하는지 확인하세요.

2-3대안 모델 — LSTM

■ LSTM (Long Short-Term Memory) 셀 상태(Cell State)와 게이트(Gate) 유닛으로 구성됩니다.
  • 셀 상태 (Cell State, c_t): 중요한 정보를 유지/기억하는 역할
  • 게이트 (Gate): 정보의 흐름을 제어 (입력은 얼마나 저장, 과거 정보는 얼마나 버릴지, 셀 상태를 얼마나 은닉정보에 반영할지)
게이트역할
입력 게이트 (i)새로운 정보의 저장 — 새로운 정보를 적절히 추가해 학습 안정화
망각 게이트 (f)과거 정보를 제거 — 필요 없는 정보는 줄여 상태가 폭발하지 않도록 제어
출력 게이트 (o)셀 상태를 현재 은닉 상태로 출력 — 필요한 정보만 은닉 상태로 전달
★ 핵심 수식 $$\begin{pmatrix}i\\f\\o\\g\end{pmatrix} = \begin{pmatrix}\sigma\\\sigma\\\sigma\\\tanh\end{pmatrix} W\begin{pmatrix}h_{t-1}\\x_t\end{pmatrix}$$ $$c_t = f \odot c_{t-1} + i \odot g \qquad h_t = o \odot \tanh(c_t)$$ 기울기 전파 시 선형가중치의 곱 이외에 덧셈 형태(f ⊙ c_{t-1} + i ⊙ g)로 전달되어 기울기를 장기적으로 보존할 수 있습니다.
↺ 복습 연결 — 2차시 로지스틱회귀 시그모이드 LSTM의 게이트는 모두 시그모이드(σ)를 통과합니다. 2차시에서 배운 시그모이드의 "0~1 사이 확률적 게이트" 성질이 여기서는 "정보를 얼마나 통과시킬지"를 결정하는 스위치 역할로 재사용됩니다.

3-1어텐션 메커니즘

■ 이미지로 이해하는 어텐션 픽셀 거리와 상관없이 유사한 패치(patch, 이미지를 일정 크기로 잘라낸 조각 단위)가 이미지 전역에 존재할 수 있습니다. 어텐션은 이런 "멀지만 관련 있는" 위치를 직접 연결합니다.
★ Q, K, V와 어텐션 공식
  • 쿼리(Q): 질의 대상 (입력 토큰/이미지 패치), $q = xW_q$
  • 키(K): 특성 (입력 내 다른 토큰), $k = xW_k$
  • 값(V): 키의 실제 정보, $v = xW_v$
  • 어텐션(a): 쿼리와 키의 유사도(확률 분포 형태), $a_{ij}=\text{softmax}(q_i\cdot k_j / \sqrt{D})$ — 쿼리와 키가 유사하면 해당 값에 가중치를 높임
  • 출력(o): 어텐션으로 가중된 값의 총합, $y_j=\sum_i a_{ij}v_i$
$$\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

교차 어텐션 (Cross-Attention)

둘 이상의 이종(異種) 데이터에서 패치 정보(쿼리/키/값)를 정의하는 방식. 예: Text-to-Image 모델에서 이미지-텍스트 간 연결 — 쿼리(Q)는 이미지 패치, 키(K)는 텍스트(텍스트 값의 정보). 이종 데이터 간 유사도(쿼리와 키 간 유사도)를 반영하려면 서로 비교할 수 있는 공간을 구축해야 합니다.

3-2Vision Transformer (ViT)

■ 이미지를 이미지 토큰 집합으로 변환 이미지를 패치로 나눈 뒤, 위치 인코딩(사인파 인코딩 등)으로 패치 토큰의 순서(위치)를 학습에 반영합니다. 데이터 해상도가 바뀌어도 동일한 룰을 적용할 수 있다는 장점이 있지만, 고정된 방식이라 특정 데이터/과업에 최적화된 방식은 아닙니다.
↺ 복습 연결 — CNN vs ViT의 전역 관계 학습 CNN은 지역적 영역에서 수용영역(receptive field)을 넓혀가며 전역을 이해하지만, ViT는 수용영역을 넓히지 않고도 어텐션 한 번으로 전역 맥락을 이해할 수 있습니다. 3차시에서 "receptive field를 키우려면 층을 깊게 쌓아야 한다"고 배운 문제를, ViT는 구조적으로 우회합니다.
CNNRNNLSTMAttention
강점지역적 특성에 집중데이터 순서 반영순서 반영 + 장거리 맥락장거리 맥락에 탁월, 정보 희석 없음
약점장거리 맥락 이해 어려움, 순서 반영 불가장거리 맥락 학습 어려움 (기울기 소실/폭발)정보 희석 문제데이터 순서 정보 없음 → 위치 인코딩 필요
! ViT 학습 시 유의점 ViT는 상수(파라미터)가 막대하고 CNN 같은 귀납적 편향(inductive bias)이 없어 정규화 기법·데이터 증강이 매우 중요합니다. 지식 증류(Knowledge Distillation, DeiT 2021)를 활용하면 상당한 개선 효과가 확인되었습니다 (원본 ViT-B/16 78% → 증류+장기학습+고해상도 입력 시 86%대까지 향상).

Vision Transformer의 트렌드

  • Swin Transformer: 이미지 전역에 직접 어텐션은 고비용·비효율 → 윈도우 단위로 어텐션을 계산하고, 다음 층에서 윈도우를 비껴가게 설정해 두 단계로 전역을 커버.
  • ViT-22B(구글): 220억 상수, 대규모 비공개 레이블 데이터(JFT-3B) 지도학습.
  • DINOv2(메타 AI): 자기지도(self-supervised) 학습, 최대 10억 상수, 공개 웹데이터 14억장 활용 — 현재 가장 많이 활용되는 백본.
  • EVA-CLIP: 이미지-텍스트 대조 학습 + 마스킹 기반 사전학습 결합.
  • InternImage-H: Conv+Transformer 하이브리드 백본, 탐지/분할에서 최고 수준 성능.
★ ViT 장단점 요약 장점: 전역 문맥을 한 번에 고려 가능 / 시계열·시퀀스 데이터에서도 순서 고려 가능(위치 인코딩) / 순서 없는 데이터는 선별 제거도 가능.
단점: 대규모 학습 자원 필요(데이터·GPU) / 학습 데이터가 적으면 CNN보다 성능 저하 / 한 번에 고려할 수 있는 토큰이 제한적.
활용: 이미지 분류/탐지/분할/생성에서 SoTA / 멀티모달 모델의 기준 아키텍처.

4-1활성화 함수 선택

■ 역할 신경망에 비선형성 부여 → 복잡한 패턴 학습 가능. 활성화 함수가 없다면 아무리 층을 쌓아도 단순 선형모델과 동일합니다. 단, 함수 특성에 따라 학습 안정성과 성능이 크게 좌우됩니다.
함수수식장점문제점
Sigmoid$a(x)=1/(1+e^{-x})$출력을 0~1 확률로 해석 가능입력이 매우 크거나 작으면 출력이 0/1에 고정 → 역전파 신호 소실. 지수 연산으로 계산비용 큼
Tanh범위 [-1,1]0 중심 대칭 → 학습 안정성 ↑ (Sigmoid보다 효과적)양 끝에서 여전히 포화 → 기울기 소실 가능
ReLU$f(x)=\max(0,x)$양의 영역 비포화, 단순 연산으로 매우 빠름, Sigmoid/Tanh 대비 6배 이상 빠른 수렴 보고됨음수 입력이면 뉴런이 완전히 죽어버릴 수 있음(Dead ReLU)
Leaky ReLU$f(x)=\max(0.01x,\,x)$ReLU 장점 유지 + 음수에도 작은 기울기 부여해 뉴런이 죽지 않음0.01이라는 기울기 값 설정이 임의적, '0' 중심 대칭 아님, 항상 ReLU보다 우세하지는 않음
ELU$x>0$이면 $x$, 아니면 $\alpha(e^x-1)$음수 영역에서도 부드럽게 포화 → 노이즈에 강건지수 연산으로 계산 복잡성 증가, 하이퍼파라미터 α 설정 필요
★ 결론 "큰 고민 말고, 일단 ReLU부터 시도!" 성능 경쟁이 필요한 상황이라면 ReLU의 개선판(Leaky ReLU, ELU 등)을 실험적으로 비교하세요.

4-3모델 상수(가중치) 초기화

! 아이디어 1 — 0으로 초기화 (실패) 모든 가중치(W)와 편향(b)을 0으로 초기화하면 모든 뉴런의 출력(y)과 기울기($\partial L/\partial W$)가 동일해져, 뉴런들이 서로 다른 패턴을 학습하지 못합니다 → 학습이 이뤄지지 않음.
■ 아이디어 2 — 임의(랜덤) 초기화 작은 랜덤 숫자(예: 0.01 × Gaussian 분포)로 초기화. 값이 너무 크거나 작아지는 것을 막기 위함이지만, 깊지 않은 모델에서만 잘 동작하는 전략입니다. 
W = 0.01 * np.random.randn(Din, Dout)
■ 아이디어 3 — Xavier 초기화 가중치 초기 분포의 분산을 입력 차원(Din)에 맞춤: $\text{std} = 1/\sqrt{D_{in}}$ 
W = np.random.randn(Din, Dout) / np.sqrt(Din)
■ 아이디어 4 — He 초기화 ReLU를 사용하는 네트워크를 위해 분산을 2배로: $\text{std} = \sqrt{2/D_{in}}$. ReLU가 입력의 절반(음수)을 0으로 만드는 것을 감안해 분산을 보정, 층이 깊어져도 활성값의 분포가 유지되도록 도와줍니다.

4-4정규화 — 가중치 감소 & 드롭아웃

■ 아이디어 1 — 가중치 감소 (Weight Decay) 가중치가 너무 크면 특정 입력에 과도하게 반응 → 훈련 데이터를 외워버림(과적합). 가중치 크기에 비례한 패널티를 적용합니다. $$R(W)=\sum_k\sum_l \beta W_{k,l}^2 + |W_{k,l}|$$ Elastic Net(L1+L2): β가 크면 L2 효과(모든 가중치를 작게), β가 작으면 L1 효과(희소한 모델). 훈련 오차를 줄이면서 + 가중치도 적당히 작게 유지하는 균형이 핵심.
■ 아이디어 2 — 드롭아웃 (Dropout) 장점: 과적합 방지(특정 뉴런에 과도하게 의존하지 않음), 여러 작은 모델을 합친 앙상블과 유사한 효과, 간단하지만 강력함.
단점: 학습시간 증가, 최적의 드롭 비율 탐색 필요, RNN/LSTM 등 시계열 데이터에서는 변형된 기법 필요, 배치정규화가 있으면 비선호되기도 함.
★ Inverted Dropout (실행단계 해결책) 학습 시 살아남은 뉴런의 출력을 1/(1-p)배로 스케일링(예: p=0.5면 활성 뉴런에 ×2) → 테스트 시엔 추가 연산 없이 그대로 사용. 기존 방식(테스트 때 (1-p)를 곱함)보다 실제 서비스 속도에 유리합니다.

4-6하이퍼파라미터 선택 비법

★ 모든 조합을 다 실험할 수는 없다 빅테크에서도 모든 조합을 실험하지 않습니다 — 몇 가지 규칙과 직관을 활용하면 GPU가 많지 않아도 좋은 성능을 낼 수 있습니다.
  1. 체크리스트 2 — 학습률과 초기값 확인: 작은 샘플로 정확도 100% 달성까지 과적합을 일부러 시켜봅니다. 손실이 폭발한다면 학습률을 줄이거나 초기화를 변경(가장 흔한 이슈), 또는 네트워크 깊이·구조적 이슈(RNN)를 의심.
  2. 체크리스트 4 — 조합 탐색: 후보 학습률 + 후보 가중치 변형 방식 중 좋은 조합을 1~5 epoch만 짧게 훈련해 탐색. 모든 조합을 끝까지 훈련하면 자원이 낭비되며, 좋은 조합은 초기 몇 epoch 내에 손실이 줄어드는 경향을 보입니다. 단, 검증 세트에서의 성능으로 관찰해야 합니다.
  3. 체크리스트 6 — 곡선 진단: 초반 손실값이 유지되면 초기값 문제, 학습률을 줄인 뒤 학습이 진행되지 않으면 너무 일찍 학습률을 줄였다는 신호, 학습/검증 정확도가 크게 벌어지면 과적합(정규화 방식 도입 필요).

  3. RNN의 대표적 한계는 ___ 문제와 장기 의존성 학습의 어려움이다. — 정답: A(기울기 소실), B(기울기 폭발)
  4. ViT의 특징 설명 중 옳지 않은 것은? — 정답: 데이터가 작을 때도 CNN보다 항상 높은 성능을 보장한다. (데이터가 적으면 오히려 CNN보다 성능이 떨어질 수 있음)
