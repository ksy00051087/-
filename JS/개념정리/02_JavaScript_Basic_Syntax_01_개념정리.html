3-1할당 연산자 · 증가 & 감소 연산자


  • 할당 연산자: 오른쪽에 있는 피연산자의 평가 결과를 왼쪽 피연산자에 할당하는 연산자 — 단축 연산자 지원: x = x + 1 을 x += 1 처럼
  • 증가 연산자 (++): 피연산자를 증가(1을 더함)시키고 연산자의 위치에 따라 증가하기 전이나 후의 값을 반환
  • 감소 연산자 (--): 피연산자를 감소(1을 뺌)시키고 연산자의 위치에 따라 감소하기 전이나 후의 값을 반환
  • → 코드의 가독성을 위해 += 1, -= 1과 같이 더 명시적인 표현으로 작성하는 것을 권장

3-2비교 연산자 · 동등 연산자 (==) · 일치 연산자 (===)


  • 비교 연산자: 피연산자들(숫자, 문자, Boolean 등)을 비교하고 결과 값을 boolean으로 반환하는 연산자 — 문자열은 유니코드 값으로 비교
  • 동등 연산자 (==): 두 피연산자가 같은 값으로 평가되는지 비교 후 boolean 값을 반환 — '암묵적 타입 변환'을 통해 타입을 일치시킨 후 같은 값인지 비교. 0 == false, '' == [] 가 true 가 되는 등, 직관과 다른 암묵적 타입 변환이 일어나니 주의. 두 피연산자가 모두 객체일 경우 메모리의 같은 객체를 바라보는지 판별 — 내용이 같아도 다른 객체이면 false 입니다.
  • 일치 연산자 (===): 두 피연산자의 값과 타입이 모두 같은 경우 true를 반환 — 같은 객체를 가리키거나, 같은 타입이면서 같은 값인지를 비교. 엄격한 비교가 이뤄지며 암묵적 타입 변환이 발생하지 않음. 특수한 경우를 제외하고는 동등 연산자가 아닌 일치 연산자 사용 권장

5-4배열 반복과 for...in — 사용하지 않는 이유


  • 객체 관점에서 배열의 인덱스는 "정수 이름을 가진 속성"이기 때문에 for...in을 쓸 수는 있지만,
  • for...in은 배열의 값이 아닌 인덱스를, 그것도 숫자가 아닌 '문자열'로 반환함
  • 배열의 프로토타입에 추가된 속성까지 순회할 수 있어, 예기치 않은 결과를 초래할 수 있음
  • 내부적으로 for...in은 정수가 아닌 이름과 속성을 반환하는 것과 더불어 특정 순서에 따라 인덱스를 반환하는 것을 보장할 수 없음 → 따라서 for...in은 인덱스의 순서가 중요한 배열에서는 사용하지 않음
  • → 배열에서는 for문, for...of를 사용

5-5반복문 사용 시 const 사용 여부


  • for 문: for (let i = 0; i < arr.length; i++) { ... }의 경우에는 최초 정의한 i를 "재할당" 하면서 사용하기 때문에 const를 사용하면 에러 발생
  • for...in, for...of: 재할당이 아니라, 매 반복마다 다른 속성 이름이 변수에 지정되는 것이므로 const를 사용해도 에러가 발생하지 않음 — 단, const 특징에 따라 블록 내부에서 변수를 수정할 수 없음

  statements
  return value
}
선언식 (function declaration)표현식 (function expression)
형태function add (num1, num2) { return num1 + num2 }const sub = function (num1, num2) { return num1 - num2 }

7-1화살표 함수 표현식


  • 함수 표현식의 간결한 표현법
  • const arrow = function (name) { return `hello, ${name}` } → const arrow = name => `hello, ${name}`
화살표 함수 작성 결과
  1. function 키워드 제거 후 매개변수와 중괄호 사이에 화살표(=>) 작성
  2. 함수의 매개변수가 하나 뿐이라면, 매개변수의 '( )' 제거 가능 (단, 생략하지 않는 것을 권장)
  3. 함수 본문의 표현식이 한 줄이라면, '{ }'와 'return' 제거 가능

8-1NaN을 반환하는 경우 예시

  • 정의할 수 없는 계산식 (0 * Infinity)

NaN은 자기 자신과 비교해도 false가 나오는 유일한 값입니다 (NaN === NaN // false). NaN은 '숫자가 아님'이라는 뜻이지만, 타입을 확인하면 'number'가 반환됩니다. 검사는 Number.isNaN()을 사용합니다.

8-2'값이 없음'에 대한 표현이 null과 undefined 2가지인 이유


  1. 역사적 맥락: JavaScript의 설계자 브랜던 아이크는 초기 언어 설계 시, 의도적인 값의 부재와 시스템적인 값의 부재를 구분하고자 함 — null: 개발자가 의도적으로 '값이 없다'는 것을 나타냄 / undefined: 시스템이 아직 값이 할당되지 않았음을 나타냄
  2. typeof null의 결과가 "object"인 이유 (역사적 버그): 초기 버전에서 값의 타입을 나타내는 데 32비트 시스템을 사용 — 타입 태그를 하위 비트에 저장했는데, null은 모든 비트가 0인 특별한 값(NULL 포인터)으로 표현되었고, 하필 객체 타입을 나타내는 태그 또한 000이었기 때문에 null을 객체로 잘못 판단
  3. ECMAScript 명세에서는 null을 원시 자료형으로 정의 — 그러나 typeof null의 결과는 역사적인 이유로 "object"를 유지
  4. ECMAScript 6 개발 중 이 문제를 수정하려는 시도가 있었지만, 이미 typeof null === 'object' 라는 전제하에 만들어진 수많은 웹 사이트와의 하위 호환성 문제 때문에 수정되지 못함
null == undefined   // true
null === undefined  // false

Basic Syntax 01 확인문제


1. 다음 중 원시 자료형(Primitive type)이 아닌 것은?
  1. Number
  2. String
  3. Array
  4. undefined
정답: Array — 배열(Array)은 객체(Object)에 속하는 참조 자료형이며 원시 자료형이 아닙니다.
2. typeof null 의 결과는?
정답: 'object' — JavaScript 초기 버전의 오류로 인해 typeof null이 'object'를 반환합니다.
3. == 와 === 연산자의 주된 차이점은?
정답: ===는 타입까지 비교하고 ==는 암묵적 타입 변환 후 비교한다
4. null과 undefined에 대한 설명으로 옳지 않은 것은?
  1. null은 의도적인 '값 없음'을 의미한다.
  2. undefined는 값이 할당되지 않았음을 의미한다.
  3. typeof null의 결과는 'null'이다.
  4. null == undefined 는 true이다.
정답: typeof null의 결과는 'null'이다. — 실제로는 'object'입니다.
5. 다음 중 단축 평가 결과가 0인 것은?
  1. 1 || 0
  2. 0 && 3
  3. 4 && 7
  4. '' || 'a'
정답: 0 && 3 — 앞이 false(0)이므로 뒤를 평가하지 않고 0을 반환합니다.
6. 삼항 연산자의 특징은?
  1. 세 개의 피연산자를 가진다.
  2. 두 개의 피연산자를 가진다.
  3. 반복문이다
  4. 함수이다
정답: 세 개의 피연산자를 가진다. — condition ? expr1 : expr2
7. 배열의 값을 순회하는 데 적합한 반복문은?
  1. for...in
  2. for...of
  3. while만
  4. 없음
정답: for...of — iterable 객체를 순회하는 데 사용됩니다. for...in은 객체의 속성을 순회합니다.
8. 함수 선언식과 표현식의 호이스팅 차이는?
정답: 함수 선언식은 호이스팅되어 선언 전에 호출 가능하지만, 함수 표현식은 변수가 TDZ에 있어 선언 전에 호출할 수 없습니다.
9. 정해지지 않은 수의 인자들을 배열로 받는 매개변수는?
  1. 기본 매개변수
  2. 나머지 매개변수
  3. spread
  4. 화살표
정답: 나머지 매개변수 (...restParams)
10. 올바른 화살표 함수 표현은?
  1. const arrow = name => { 'hello, ' + name }
  2. const arrow = name => 'hello, ' + name
  3. const arrow = (name) => return 'hello, ' + name
  4. const arrow = => 'hello, ' + name
정답: const arrow = name => 'hello, ' + name — 본문이 한 줄의 표현식이면 중괄호와 return을 동시에 생략할 수 있습니다. (a)는 중괄호만 있고 return이 없어 undefined를 반환합니다.

핵심 키워드


키워드설명예시
원시 자료형변수에 값이 직접 저장되는 자료형 — Number, String, Boolean, null, undefined. 데이터가 불변(immutable)이며, 다른 변수에 할당할 때 값이 복사const a = 'bar'
참조 자료형객체의 메모리 주소가 변수에 저장되는 자료형. 데이터가 가변(mutable)이며, 다른 변수에 할당할 때 주소가 복사되어 원본과 사본이 서로 영향을 줌Object, Array, Function
String · 템플릿 리터럴텍스트 데이터를 나타내며, + 연산자로 문자열을 결합 가능 / 백틱(`)을 사용해 변수를 ${} 형태로 문자열에 쉽게 삽입할 수 있는 방식`${age}세`
null · undefinednull은 개발자가 의도적으로 '값이 없음'을 나타낼 때 사용 / undefined는 '값이 할당되지 않음'을 시스템이 나타낼 때 사용let x = null
일치 연산자 (===)값과 타입이 모두 같을 때 true, 암묵적 타입 변환 없음'1' === 1 // false
for...of 반복문iterable(배열, 문자열) 값 순회for (const i of arr) { ... }
함수 표현식const funcName = function() {} 형태로 변수에 할당, 호이스팅 문제 없음const sub = function () {}
화살표 함수const arrow = () => {} — 함수 표현식의 간결한 표현const arrow = () => {}
기본 / 나머지 매개변수function (name = 'Anonymous') 처럼 인자가 전달되지 않을 경우를 대비해 기본값을 설정 / function (...args) {} 형태로 작성하며, 정해지지 않은 개수의 인자를 배열로 받음function (...args) {}






이 문서의 큰 줄기


  • 원시 = 값 복사(불변), 참조 = 주소 복사(공유) — 이 차이가 대부분의 "왜 같이 바뀌지?"를 설명한다.
  • 비교는 ===, 기본값은 || 또는 기본 매개변수, 배열 순회는 for...of.
  • 함수는 표현식(const) + 화살표 함수로 쓰는 것이 기본 — 객체를 바로 반환할 때는 () => ({ }).
