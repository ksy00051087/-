1환경 · 앱

가상 환경#1
python -m venv venv → source venv/Scripts/activate → deactivate
pip freeze > requirements.txt(기록) / pip install -r requirements.txt(설치) · venv는 git에 안 올림
앱 생성·등록#2
django-admin startproject 이름 . / python manage.py startapp articles
생성 먼저 → INSTALLED_APPS 등록 · 앱 이름은 복수형

2URL

URL ↔ view#3
요청 → urls.py → views.py → template · path('index/', views.index, name='index')
view 첫 인자 request · render(request, 'articles/index.html', context) · 위에서부터 매칭
Variable Routing#4
<int:pk> ↔ def detail(request, pk) 이름 일치 · 기본 converter str · int에 문자 → 404
include 함수#5
from django.urls import path, include · include('articles.urls') (점 표기, 파일경로 X) · 앱 urls.py는 직접 생성
include 매칭#6
일치한 앞부분('articles/')을 잘라내고 나머지를 앱 urls로 · 최종 URL = prefix + 앱 path · 앱의 '' = /articles/
URL 이름·import#7
name='index' → 주소가 바뀌어도 코드 수정 X · 앱 urls.py: from . import views
url 태그·app_name#8
앱 urls.py에 app_name = 'articles' → {% url 'articles:detail' article.pk %} (인자는 공백) · 이름만 쓰면 NoReverseMatch
redirect#9
from django.shortcuts import render, redirect · redirect('articles:detail', article.pk) · POST 처리 후엔 redirect(중복 제출 방지)

3Template (DTL)

태그와 필터#10
{{ 변수 }} · {{ 변수|필터 }} · {% 태그 %} · {# 주석 #}
{% for %}{% empty %}{% endfor %} · {% if %}{% endif %} · {% extends %}는 맨 첫 줄 · 인덱스는 {{ list.0 }}
DTL 필터#11
|length |upper |lower |truncatechars:10 |default:'없음' |date:'Y-m-d'
인자는 콜론(괄호 X) · 체이닝 가능(왼쪽부터) · 원본은 안 바뀜

4요청 · form · CSRF

GET vs POST#12
GET: 조회, Query String, 토큰 X, request.GET · POST: 생성/수정/삭제, Body, csrf_token 필요, request.POST
if request.method == 'POST': (대문자) · form 기본 method = GET
form·Query String#13
action(보낼 URL, 비우면 현재 URL) · method · name=key (name 없으면 전송 X)
/search/?q=django&page=2 → request.GET.get('q')
Delete#14
a 태그 = GET → 삭제는 POST form + csrf_token · view: if request.method == 'POST': article.delete() → redirect('articles:index')
CSRF · 403#15
사이트 간 요청 위조(Cross-Site Request Forgery) · POST form 안에 {% csrf_token %} · 없으면 403 Forbidden

5Model · ORM

migrate · 테이블#16
makemigrations(설계도 파일) → migrate(DB 반영) · 테이블명 articles_article · id 자동 생성 · CharField는 max_length 필수
추가 Migrations#17
기존 데이터에 필드 추가 → 기본값을 물어봄(1: 지금 입력 / 2: 종료 후 default 작성) · 0002 파일 생성 · auto_now_add(생성) / auto_now(수정마다)
인스턴스 속성#18
클래스=테이블 · 인스턴스=레코드 · 필드=컬럼 · article.title · pk == id · 속성 변경은 save() 해야 DB 반영
pk 부여 시점#19
Article() 직후 pk = None → save()/create() 시 부여 · commit=False 직후도 None · delete 후 None
QuerySet · save#20
all() · filter()(없으면 빈 QuerySet) · get()(1개, 없으면 DoesNotExist) · create()(save 불필요)
수정: 조회 → 속성 변경 → save() · 삭제: delete()

6Form · ModelForm

Form · Widget#21
forms.CharField(widget=forms.Textarea) · 위젯 = 렌더링만(검증 X) · 저장 X → forms.Form, 저장 O → forms.ModelForm
Meta exclude#22
model = Article(클래스) · fields = '__all__' 또는 exclude = ('title',)(쉼표) · 둘 중 하나 · auto_now 필드는 폼에 안 나옴
유효성 검사 흐름#23
if request.method == 'POST':
    form = ArticleForm(request.POST)
    if form.is_valid():
        article = form.save()
        return redirect('articles:detail', article.pk)
else:
    form = ArticleForm()
context = {'form': form}     # if/else 밖
return render(request, 'articles/create.html', context)
무효면 에러 담긴 form 다시 render

7Static · Media

STATIC_URL · static#24
STATIC_URL = 'static/'(URL 접두사) · {% load static %} → {% static 'articles/sample.png' %} · 기본 위치 articles/static/articles/
STATICFILES_DIRS#25
STATICFILES_DIRS = [BASE_DIR / 'static'] · 탐색: STATICFILES_DIRS → 앱 static(INSTALLED_APPS 순) · 먼저 찾은 파일 사용
ImageField#26
ImageField(blank=True, upload_to='images/') · Pillow 필요 · DB엔 경로 문자열, 파일은 MEDIA_ROOT/upload_to
MEDIA_ROOT = BASE_DIR / 'media' · MEDIA_URL = 'media/'
업로드 · FILES#27
form: enctype="multipart/form-data" + view: ArticleForm(request.POST, request.FILES) · 둘 다 필수
이미지 출력#28
urls: + static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
{% if article.image %}<img src="{{ article.image.url }}">{% endif %} · 없을 때 .url → ValueError
