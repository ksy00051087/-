# | SSAFY Debugging 월말평가 대비 연습문제 – 문제지 |

## 월말평가 – Debugging

### 시험 과목

- ✔ Debugging (Django REST framework – 1:N 관계 / 중첩 직렬화)

### 시험 목적

- ✔ 1:N 관계의 REST API를 구현할 수 있다.
- ✔ 에러 상황을 수정할 수 있다.

### 시험 유의 사항

1. 성실하게 테스트에 임할 것 (부정 행위 적발 시 강력 조치)
2. 코드 유사도 판단 프로그램 기준, 부정 행위로 판단 될 시 0점 처리 및 학사 기준에 의거 조치
3. 주어진 DB(`db.sqlite3`)를 이용하여 문제를 풀 것 (migration 필요 없음)
4. 문제에 명시된 수정 파일에서만 코드를 수정할 것 (다른 파일을 수정하면 정상 동작해도 오답 처리)
5. 각 문제에 명시된 URL은 `http://127.0.0.1:8000` 이 생략되어 있음

### 시험 코드 작성 유의 사항

최종 제출 코드가 다음 항목에 해당하는 경우, 감점 혹은 0점 처리 될 수 있음

1. Syntax Error 로 인한 채점이 불가능한 경우
2. 주석 설명이 없거나 미흡한 경우
3. 출력 결과에 정답과 무관하거나 불필요한 내용이 있는 경우
4. 문제를 풀지 못하였다면 작성한 코드를 주석 처리하거나 삭제
   (풀다만 문제로 인해 다른 문제가 오답처리되는 경우 해당 문제 모두 0점 처리)
5. `models.py` 는 수정 불가

---

### 시험 환경

- 개발환경 : python 3.11+, Django 5.2, Django REST framework 3.18, vscode, Postman
- 가상환경을 생성하여 주어진 `requirements.txt` 를 이용하여 환경 구축
  (이 때, 제시된 `requirements.txt` 이외의 패키지 설치는 불가)
- 필드 정보는 `articles/models.py` 를 참고
- Postman 요청시 URL 마지막에 `/` 를 반드시 붙여야 함
- 스켈레톤 코드에는 오류가 포함되어 있음. 각 문제의 **[현재 증상]** 을 직접 확인하고, 수정 파일의 코드를 고쳐 **[정상 동작]** 이 되도록 디버깅할 것

### 정답 제출 안내

제출 안내 사항 미 준수 시, 감점 혹은 0점 처리 될 수 있음

1. 반드시 서버가 정상적으로 동작하는 코드인지 확인 (중요)
   - 문제를 풀지 못하면 주석 처리하여 서버 실행에 이상없도록 만들 것
   - 에러로 서버 실행조차 되지 않는다면 0점
2. 압축 파일 이름
   - `지역0반_홍길동`
   - ex) `서울1반_홍길동` / `부울경2반_김싸피`
3. 압축시 주의 사항
   - 서술형 답안 파일(`problem_10.md`)도 같이 압축
   - `venv/` 폴더는 제외 후 압축

> 제출 마감 직전, 서버 요청이 집중될 수 있으므로, 미리 제출하는 것을 권장. (마감 시간 이후 제출 불가)

### API 명세

> URL 앞의 `http://127.0.0.1:8000` 생략. URL 마지막 `/` 필수.

| 기능 | Method | URL | Request Body | 성공 응답 |
|---|---|---|---|---|
| 게시글 목록 조회 | GET | `/api/v1/articles/` | - | 200 OK |
| 게시글 생성 | POST | `/api/v1/articles/` | `title`, `content` | 201 Created |
| 게시글 상세 조회 | GET | `/api/v1/articles/<int:article_pk>/` | - | 200 OK |
| 게시글 수정 | PUT | `/api/v1/articles/<int:article_pk>/` | `title`, `content` | 200 OK |
| 게시글 부분 수정 | PATCH | `/api/v1/articles/<int:article_pk>/` | `title` 또는 `content` | 200 OK |
| 게시글 삭제 | DELETE | `/api/v1/articles/<int:article_pk>/` | - | 204 No Content |
| 댓글 목록 조회 | GET | `/api/v1/comments/` | - | 200 OK |
| 댓글 생성 | POST | `/api/v1/articles/<int:article_pk>/comments/` | `content` | 201 Created |
| 댓글 상세 조회 | GET | `/api/v1/comments/<int:comment_pk>/` | - | 200 OK |
| 댓글 수정 | PUT | `/api/v1/comments/<int:comment_pk>/` | `content` | 200 OK |
| 댓글 삭제 | DELETE | `/api/v1/comments/<int:comment_pk>/` | - | 204 No Content |

- Request Body 는 Postman 에서 `Body` → `raw` → `JSON` 으로 전송
- `title` 은 최대 10자

### 응답 형식

- 게시글 상세 (`GET /api/v1/articles/<int:article_pk>/`)

  ```json
  {
    "id": 3,
    "comment_set": [
      {"id": 16, "content": "댓글 내용"},
      {"id": 17, "content": "댓글 내용"}
    ],
    "num_of_comments": 2,
    "title": "게시글 제목",
    "content": "게시글 내용",
    "created_at": "...",
    "updated_at": "..."
  }
  ```

- 댓글 (`GET /api/v1/comments/`, `GET /api/v1/comments/<int:comment_pk>/`)

  ```json
  {
    "id": 1,
    "article": {"title": "게시글 제목"},
    "content": "댓글 내용",
    "created_at": "...",
    "updated_at": "..."
  }
  ```

# 문제

## 문제 01. 게시글 목록 조회 500 오류 디버깅

- ❖ **Request** : `GET /api/v1/articles/`
- ❖ **수정 파일** : `articles/views.py`
- ❖ **[현재 증상]** 게시글 목록 조회를 요청하면 500 Internal Server Error (`AttributeError`) 가 발생한다.
- ❖ **[정상 동작]** 전체 게시글 목록이 각 게시글의 `id`, `title`, `content` 필드를 가진 리스트 형태로 200 OK 와 함께 응답되도록 수정하시오.

---

## 문제 02. 게시글 생성 응답 상태 코드 디버깅

- ❖ **Request** : `POST /api/v1/articles/`
- ❖ **수정 파일** : `articles/views.py`
- ❖ **요청 예시**

  ```json
  {
    "title": "새 게시글",
    "content": "게시글 내용"
  }
  ```

- ❖ **[현재 증상]** 게시글은 정상적으로 생성되지만, 200 OK 로 응답된다.
- ❖ **[정상 동작]** 게시글이 생성되고, 생성된 게시글 정보와 함께 201 Created 로 응답되도록 수정하시오.

---

## 문제 03. 존재하지 않는 게시글 조회 500 오류 디버깅

- ❖ **Request** : `GET /api/v1/articles/<int:article_pk>/`
- ❖ **수정 파일** : `articles/views.py`
- ❖ **요청 예시** : `GET /api/v1/articles/999/`
- ❖ **[현재 증상]** 존재하는 게시글은 정상 조회되지만, 존재하지 않는 게시글을 요청하면 500 Internal Server Error (`DoesNotExist`) 가 발생한다.
- ❖ **[정상 동작]** 존재하지 않는 게시글을 요청하면 404 Not Found 로 응답되도록 수정하시오.

---

## 문제 04. 게시글 조회 시 댓글 목록 누락 디버깅

- ❖ **Request** : `GET /api/v1/articles/<int:article_pk>/`
- ❖ **수정 파일** : `articles/serializers.py`
- ❖ **요청 예시** : `GET /api/v1/articles/3/`
- ❖ **[현재 증상]** 게시글 상세 조회 시 해당 게시글에 작성된 댓글 목록이 응답되지 않는다.
- ❖ **[정상 동작]** 상세 조회 응답에 `comment_set` 필드가 포함되고, 해당 게시글의 댓글 목록이 각 댓글의 `id`, `content` 필드를 가진 리스트 형태로 응답되도록 수정하시오.
  - `"comment_set": [{"id": 16, "content": "..."}, {"id": 17, "content": "..."}]`
  - 단, 게시글 생성·수정 요청 시 `comment_set` 은 입력받지 않아야 한다.

## 문제 05. 게시글 부분 수정(PATCH) 400 오류 디버깅

- ❖ **Request** : `PATCH /api/v1/articles/<int:article_pk>/`
- ❖ **수정 파일** : `articles/views.py`
- ❖ **요청 예시** : `PATCH /api/v1/articles/5/`

  ```json
  {
    "title": "제목만수정"
  }
  ```

- ❖ **[현재 증상]** `title` 만 담아 부분 수정을 요청하면 400 Bad Request 와 함께 `{"content": ["This field is required."]}` 가 응답된다.
- ❖ **[정상 동작]** 요청에 포함된 필드만 수정되고, 수정된 게시글 정보가 200 OK 로 응답되도록 수정하시오.

## 문제 06. 댓글 조회 시 게시글 제목 디버깅

- ❖ **Request** : `GET /api/v1/comments/`
- ❖ **수정 파일** : `articles/serializers.py`
- ❖ **[현재 증상]** 댓글 목록 조회 시 각 댓글의 `article` 필드에 게시글의 모든 필드(`id`, `title`, `content`, `created_at`, `updated_at`)가 응답된다.
- ❖ **[정상 동작]** 각 댓글의 `article` 필드에 게시글 제목만 응답되도록 수정하시오.
  - `"article": {"title": "..."}`

## 문제 07. 댓글 생성 400 오류 디버깅

- ❖ **Request** : `POST /api/v1/articles/<int:article_pk>/comments/`
- ❖ **수정 파일** : `articles/serializers.py`
- ❖ **요청 예시** : `POST /api/v1/articles/1/comments/`

  ```json
  {
    "content": "새 댓글"
  }
  ```

- ❖ **[현재 증상]** 댓글 생성을 요청하면 400 Bad Request 와 함께 `{"article": ["This field is required."]}` 가 응답된다.
- ❖ **[정상 동작]** 요청 데이터에 `article` 이 없어도 URL의 `article_pk` 게시글에 댓글이 생성되고, 생성된 댓글 정보와 함께 201 Created 로 응답되도록 수정하시오. 댓글 조회 시 응답의 `article` 필드는 그대로 포함되어야 한다.

## 문제 08. 댓글 삭제 405 오류 디버깅

- ❖ **Request** : `DELETE /api/v1/comments/<int:comment_pk>/`
- ❖ **수정 파일** : `articles/views.py`
- ❖ **요청 예시** : `DELETE /api/v1/comments/4/` → 이후 `GET /api/v1/comments/4/` 로 확인
- ❖ **[현재 증상]** 댓글 삭제를 요청하면 405 Method Not Allowed 가 응답되고, 댓글이 삭제되지 않는다.
- ❖ **[정상 동작]** 댓글이 삭제되고 204 No Content 로 응답되도록 수정하시오.

## 문제 09. 게시글 수정 내용 미반영 디버깅

- ❖ **Request** : `PUT /api/v1/articles/<int:article_pk>/`
- ❖ **수정 파일** : `articles/views.py`
- ❖ **요청 예시** : `PUT /api/v1/articles/4/`

  ```json
  {
    "title": "수정 제목",
    "content": "수정 내용"
  }
  ```

- ❖ **[현재 증상]** 게시글 수정을 요청하면 200 OK 가 응답되지만, 응답 데이터와 DB 모두 수정 전 내용 그대로이다.
- ❖ **[정상 동작]** URL의 `article_pk` 게시글이 요청 내용으로 수정되고, 수정된 게시글 정보가 200 OK 로 응답되도록 수정하시오.
