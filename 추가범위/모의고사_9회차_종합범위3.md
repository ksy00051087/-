## 객관식 (1~40)

**1.** 다중회귀에서 독립변수를 추가할 때 $R^2$에 나타나는 일반적인 경향과, 이를 보정하기 위한 지표는?
① 독립변수를 추가하면 $R^2$는 거의 항상 증가하거나 유지되므로, 변수 수를 반영해 보정한 조정된 결정계수(Adjusted $R^2$)를 사용한다 ② 독립변수를 추가하면 $R^2$는 항상 감소한다 ③ $R^2$는 변수 개수와 완전히 무관해 보정이 필요 없다 ④ 조정된 $R^2$는 항상 원래 $R^2$보다 크다

**2.** Batch GD, SGD(확률적 경사하강법), Mini-batch GD의 차이로 옳은 것은?
① Batch GD는 전체 데이터로, SGD는 샘플 1개로, Mini-batch GD는 일부 배치로 매 스텝 기울기를 계산해 업데이트한다 ② 세 방법 모두 항상 동일한 양의 데이터를 사용한다 ③ SGD는 반드시 전체 데이터셋을 한 번에 사용해야 한다 ④ Mini-batch GD는 기울기를 전혀 사용하지 않는다

**3.** 데이터 증강을 사용하는 주된 목적으로 옳은 것은?
① 오버피팅을 방지하고 모델의 일반화 성능을 향상시키기 위해 ② 모델의 파라미터 수를 강제로 늘리기 위해 ③ 학습 속도를 항상 느리게 만들기 위해 ④ 테스트 데이터의 라벨을 자동 생성하기 위해

**4.** 선형회귀와 로지스틱 회귀의 차이로 가장 적절한 것은?
① 선형회귀는 연속적인 값을 예측하고, 로지스틱 회귀는 시그모이드 변환을 통해 클래스에 속할 확률을 예측한다 ② 두 모델은 완전히 동일한 출력을 낸다 ③ 로지스틱 회귀는 항상 두 개 이상의 클래스만 다룰 수 없다 ④ 선형회귀는 확률을 직접 출력하도록 설계되어 있다

**5.** Multi-Head Attention의 최종 출력을 만드는 과정으로 옳은 것은?
① 각 헤드의 출력을 concat한 뒤 하나의 선형변환(linear projection)을 거쳐 최종 출력을 만든다 ② 각 헤드의 출력 중 하나만 무작위로 선택한다 ③ 각 헤드의 출력을 곱한 뒤 그대로 사용한다 ④ 헤드 출력을 사용하지 않고 입력을 그대로 반환한다

**6.** 선호 학습과 지시 학습(Instruction Tuning)의 차이로 옳은 것은?
① 지시 학습은 '어떤 응답을 생성해야 하는가'를, 선호 학습은 '어떤 응답이 상대적으로 더 나은가'를 학습한다 ② 두 학습 방식은 완전히 동일하다 ③ 지시 학습은 라벨이 전혀 필요 없다 ④ 선호 학습은 사전학습과 동일한 목적함수를 사용한다

**7.** "Self"-Attention이라는 이름이 붙은 이유로 가장 적절한 것은?
① Query, Key, Value가 모두 같은 입력 시퀀스로부터 만들어져 시퀀스가 자기 자신에 대해 어텐션을 수행하기 때문 ② 인코더와 디코더가 서로에게 어텐션을 수행하기 때문 ③ 출력이 항상 자기 자신과 동일하기 때문 ④ 학습이 필요 없는 어텐션이기 때문

**8.** Cross-Attention과 Self-Attention의 차이로 옳은 것은?
① Self-Attention은 Q,K,V가 모두 같은 시퀀스에서 나오고, Cross-Attention은 Q는 한 시퀀스에서, K·V는 다른 시퀀스에서 나온다 ② 둘은 완전히 동일한 계산을 수행한다 ③ Cross-Attention은 항상 Self-Attention보다 연산량이 적다 ④ Self-Attention은 두 개의 서로 다른 시퀀스가 반드시 필요하다

**9.** 언어모델의 성능을 평가하는 대표적인 지표인 Perplexity에 대한 설명으로 옳은 것은?
① 문장 생성 확률의 기하평균의 역수로, 값이 낮을수록 모델이 문장을 더 자연스럽게 여긴다는 뜻이다 ② 값이 높을수록 모델 성능이 더 좋다는 뜻이다 ③ 항상 0과 1 사이의 값만 가진다 ④ 정답 라벨이 있어야만 계산할 수 있는 지표이다

**10.** 실서비스에 배포된 모델의 분포 변화(Distribution Shift)를 다루기 위한 방법으로 가장 적절한 것은?
① 입력·출력 분포를 지속적으로 모니터링하고 최신 데이터로 주기적으로 재학습한다 ② 배포 후에는 모델을 다시 확인하지 않아도 된다 ③ 분포 변화는 모델 구조와 무관하므로 대응이 불필요하다 ④ 한 번 학습한 모델은 절대 다시 학습시키지 않는다

**11.** 온디바이스 VLM에서 양자화 비트 수를 낮출 때 발생하는 일반적인 트레이드오프는?
① 모델 크기와 연산량은 줄지만 정밀도 손실로 정확도가 떨어질 수 있다 ② 정확도가 항상 향상된다 ③ 모델 크기가 오히려 커진다 ④ 연산 속도가 항상 느려진다

**12.** 지도학습과 비지도학습의 가장 근본적인 차이로 옳은 것은?
① 지도학습은 라벨이 있는 데이터로 입출력 관계를 학습하고, 비지도학습은 라벨 없이 데이터의 구조나 패턴을 학습한다 ② 지도학습은 항상 이미지 데이터만 다룬다 ③ 비지도학습은 항상 정답 라벨이 필요하다 ④ 두 방식은 완전히 동일한 목적함수를 사용한다

**13.** 지시 학습 데이터에서 같은 태스크에 대해 여러 표현의 지시 템플릿을 사용하는 이유는?
① 학습 데이터의 표현 다양성을 늘려 모델이 다양한 형태의 지시를 이해하고 일반화하도록 돕기 위해 ② 학습 데이터 양을 줄이기 위해 ③ 모델이 하나의 템플릿만 암기하도록 만들기 위해 ④ 라벨링 비용을 완전히 없애기 위해

**14.** 지도학습의 데이터 생성 가정에서 참 함수 $f$에 대한 설명으로 옳은 것은?
① 입력 $X$와 출력 $Y$ 사이의 실제(이상적인) 관계이며 직접 관측할 수 없어 데이터로부터 추정해야 한다 ② 학습 과정에서 사람이 직접 수식으로 입력해주는 값이다 ③ 측정오차와 동일한 무작위 잡음이다 ④ 항상 선형 함수 형태를 가진다

**15.** 거리 기반 클러스터링 이전에 표준화(Standardization)가 필요한 이유는?
① 변수마다 척도(단위)가 다르면 거리 계산이 특정 변수에 치우쳐 군집 결과가 왜곡될 수 있기 때문 ② 표준화는 클러스터링 결과에 전혀 영향을 주지 않기 때문 ③ 표준화는 데이터 개수를 늘리기 위한 기법이기 때문 ④ 표준화를 하면 항상 군집 개수가 줄어들기 때문

**16.** 파인튜닝과 특징 추출(Feature Extraction, backbone freeze)의 차이로 옳은 것은?
① 파인튜닝은 사전학습된 가중치를 추가로 업데이트하고, 특징 추출은 backbone을 고정한 채 마지막 층만 새로 학습한다 ② 특징 추출은 backbone까지 포함해 모든 가중치를 업데이트한다 ③ 파인튜닝은 항상 backbone을 완전히 고정한다 ④ 두 방식은 완전히 동일한 절차다

**17.** CLIP이 대표적으로 활용되는 분야로 가장 적절한 것은?
① 제로샷 이미지 분류, 이미지-텍스트 검색 등 멀티모달 응용 ② 정형 데이터 회귀 예측 ③ 시계열 데이터 이상 탐지 ④ 음성 인식 전용 태스크

**18.** CLIP Zero-shot 분류의 한계로 가장 적절한 것은?
① 특정 태스크에 맞게 파인튜닝된 전용 모델보다 세부 정확도가 낮을 수 있다 ② 어떤 상황에서도 항상 100% 정확하다 ③ 텍스트 프롬프트를 전혀 사용할 수 없다 ④ 이미지 입력을 받을 수 없다

**19.** 풀링(Pooling) 층이 CNN의 공간 구조 처리에서 하는 역할은?
① 공간 크기를 축소하면서 작은 위치 변화에 대한 불변성(invariance)을 부여한다 ② 채널 수를 항상 두 배로 늘린다 ③ 가중치 개수를 학습 가능한 파라미터로 늘린다 ④ 이미지의 색상 정보를 완전히 제거한다

**20.** "same" 패딩과 "valid" 패딩에 대한 설명으로 옳은 것은?
① same 패딩은 출력 크기를 입력과 동일하게 유지하도록 패딩을 채우고, valid 패딩은 패딩 없이 합성곱해 출력 크기가 줄어든다 ② same 패딩은 항상 출력 크기를 절반으로 줄인다 ③ valid 패딩은 출력 크기를 입력의 두 배로 늘린다 ④ 두 방식은 출력 크기에 전혀 영향을 주지 않는다

**21.** 합성곱 층의 출력 채널 수를 늘리면 파라미터 수에 미치는 영향은?
① 출력 채널 수에 비례하여 파라미터 수가 증가한다 ② 파라미터 수는 출력 채널 수와 무관하다 ③ 파라미터 수가 오히려 감소한다 ④ 항상 파라미터 수가 절반으로 줄어든다

**22.** CNN과 ViT의 구조적 결합(하이브리드)에 대한 설명으로 가장 적절한 것은?
① CNN으로 저수준 특징을 추출한 뒤 Transformer의 Self-Attention으로 전역적 관계를 학습하는 방식이 활용된다 ② CNN과 ViT는 절대 함께 사용할 수 없다 ③ 하이브리드 구조는 항상 순수 CNN보다 파라미터가 적다 ④ 하이브리드 구조는 어텐션을 전혀 사용하지 않는다

**23.** 네트워크의 깊이(depth)와 폭(width)에 대한 설명으로 가장 적절한 것은?
① 깊이는 표현의 계층적 추상화를, 폭은 각 층에서 표현할 수 있는 특징의 다양성을 늘리는 경향이 있으며 둘 다 무한정 늘리면 과적합·최적화 문제가 생길 수 있다 ② 깊이와 폭은 모델 성능에 전혀 영향을 주지 않는다 ③ 폭을 늘리면 항상 기울기 소실이 사라진다 ④ 깊이만 중요하고 폭은 전혀 중요하지 않다

**24.** Diffusion 모델과 GAN을 비교할 때 옳은 것은?
① Diffusion은 일반적으로 학습이 안정적이지만 샘플링(생성) 속도가 GAN보다 느린 경향이 있다 ② GAN은 항상 Diffusion보다 학습이 안정적이다 ③ Diffusion은 판별자(Discriminator) 없이는 절대 동작하지 않는다 ④ 둘은 생성 원리가 완전히 동일하다

**25.** LSTM이 Vanilla RNN보다 장기 의존성 문제를 완화할 수 있는 이유는?
① 게이트 구조와 셀 상태를 통해 정보를 선택적으로 유지·전달하여 기울기가 덜 소실되도록 돕기 때문 ② LSTM은 항상 병렬로 계산되어 순서 정보를 아예 사용하지 않기 때문 ③ LSTM은 활성화 함수를 전혀 사용하지 않기 때문 ④ LSTM은 항상 RNN보다 파라미터가 적기 때문

**26.** Dying ReLU 문제를 완화하기 위해 제안된 변형 함수로 옳은 것은?
① Leaky ReLU (음수 구간에서도 작은 기울기를 허용) ② Sigmoid ③ Softmax ④ Identity Function

**27.** Transformer의 인코더-디코더 구조에서 Cross-Attention의 역할로 옳은 것은?
① 디코더가 인코더의 출력(Key, Value)을 참조하며 현재 생성 위치에 필요한 입력 정보를 가져온다 ② 인코더가 디코더의 출력을 참조한다 ③ 디코더가 자기 자신의 미래 토큰을 참조한다 ④ 인코더와 디코더가 서로 완전히 독립적으로 동작해 정보를 주고받지 않는다

**28.** Top-K와 Top-P 샘플링을 비교할 때 옳은 것은?
① Top-K는 후보 개수를 고정하고, Top-P는 누적 확률 기준으로 후보 개수를 문맥에 따라 유동적으로 조절한다 ② Top-K와 Top-P는 완전히 같은 방식으로 동작한다 ③ Top-P는 항상 정확히 1개의 후보만 남긴다 ④ Top-K는 확률과 무관하게 무작위로 후보를 고른다

**29.** $R^2$에 대한 설명으로 옳지 않은 것은?
① $R^2$는 항상 0과 1 사이의 값만 가지며 절대 음수가 될 수 없다 ② $R^2 = 1-\mathrm{RSS/TSS}$로 계산한다 ③ 1에 가까울수록 모형 설명력이 높다고 해석한다 ④ 테스트셋에서는 모형이 평균 예측보다 나빠 음수가 될 수도 있다

**30.** 경사하강법이 지역 최솟값(local minimum)이나 안장점(saddle point)에 빠지는 문제에 대한 설명으로 옳은 것은?
① 손실함수가 볼록하지 않을 때 전역 최솟값이 아닌 지점에서 기울기가 0에 가까워져 학습이 정체될 수 있다 ② 이 문제는 딥러닝에서 전혀 발생하지 않는다 ③ 안장점에서는 항상 기울기가 매우 크다 ④ 학습률을 낮추면 이 문제가 원리적으로 완전히 사라진다

**31.** 텍스트 데이터에 적용할 수 있는 데이터 증강 기법의 예시로 가장 적절한 것은?
① 동의어 치환(synonym replacement)이나 역번역(back-translation) ② 이미지 회전(rotation) ③ 합성곱 필터 크기 조정 ④ 풀링 크기 변경

**32.** 로지스틱 회귀의 결정 경계(decision boundary)에 대한 설명으로 옳은 것은?
① 시그모이드 출력값이 특정 임계값(예: 0.5)을 기준으로 클래스를 나누는 경계이다 ② 결정 경계는 항상 곡선 형태만 가능하다 ③ 결정 경계는 손실 함수와 전혀 관련이 없다 ④ 결정 경계는 로지스틱 회귀에서 존재하지 않는다

**33.** 헤드 수를 늘렸을 때 일반적으로 나타나는 효과로 가장 적절한 것은?
① 더 다양한 표현 부분공간에서 관계를 학습할 수 있지만, 헤드당 차원이 줄어드는 트레이드오프가 있다 ② 헤드 수는 모델 성능에 전혀 영향을 주지 않는다 ③ 헤드 수를 늘리면 항상 연산량이 감소한다 ④ 헤드 수는 항상 1개로 고정해야 한다

**34.** 선호 학습 데이터에서 흔히 사용되는 형태로 옳은 것은?
① 같은 프롬프트에 대한 두 응답 중 어느 쪽이 더 선호되는지 표시한 쌍(pairwise comparison) 데이터 ② 정답 라벨이 없는 순수 이미지 데이터 ③ 레이블이 전혀 없는 텍스트 코퍼스 ④ 숫자로만 이루어진 정형 데이터

**35.** Self-Attention이 RNN과 비교해 갖는 장점으로 옳은 것은?
① 순차 계산 없이 병렬화가 가능하고, 두 토큰 사이의 상호작용 거리가 시퀀스 길이와 무관하게 $O(1)$이다 ② 항상 RNN보다 연산량이 적다 ③ 위치 정보를 자동으로 사용할 필요가 없다 ④ 시퀀스 길이가 길어질수록 연산량이 줄어든다

**36.** 어텐션 스코어(alignment score)를 계산하는 일반적인 방식으로 옳은 것은?
① Query와 Key 벡터의 유사도(내적 등)를 계산한 뒤 softmax로 정규화해 가중치로 사용한다 ② Value 벡터만으로 무작위 점수를 매긴다 ③ 입력 순서만으로 점수를 고정한다 ④ 항상 모든 위치에 동일한 점수를 부여한다

**37.** 언어모델의 대표적인 생성 방식인 Autoregressive(자기회귀) 생성에 대한 설명으로 옳은 것은?
① 이전까지 생성된 토큰들을 조건으로 다음 토큰의 확률을 예측하고, 이를 반복해 순차적으로 문장을 생성한다 ② 모든 출력 토큰을 한 번에 동시에 생성한다 ③ 입력 없이 완전히 무작위로 토큰을 생성한다 ④ 항상 문장의 마지막 토큰부터 거꾸로 생성한다

**38.** 지시 학습(Instruction Tuning)에서 사용하는 학습 방법 자체의 성격으로 가장 적절한 것은?
① 지시와 응답 쌍으로 구성된 데이터에 대해 수행하는 지도 방식의 추가 학습(SFT)이다 ② 정답 라벨이 전혀 없는 자기지도학습이다 ③ 보상 함수만으로 학습하는 강화학습이다 ④ 군집화를 수행하는 비지도학습이다

**39.** 표준화(Standardization)의 계산식으로 옳은 것은? (평균 $\mu$, 표준편차 $\sigma$)
① $z=\dfrac{x-\mu}{\sigma}$ ② $z=x\times\mu$ ③ $z=x+\sigma$ ④ $z=\dfrac{\mu}{x-\sigma}$

**40.** 파인튜닝 시 발생할 수 있는 "Catastrophic Forgetting"이란?
① 새로운 태스크로 학습하는 과정에서 기존에 사전학습으로 습득했던 지식·능력을 잃어버리는 현상 ② 학습 속도가 지나치게 빨라지는 현상 ③ 모델이 절대 새로운 태스크를 배우지 못하는 현상 ④ 데이터셋 크기가 자동으로 줄어드는 현상
