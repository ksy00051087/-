## 객관식 (1~40)

**1.** CLIP(Contrastive Language-Image Pretraining)에 대한 설명으로 가장 옳은 것은?
① 이미지와 텍스트를 같은 임베딩 공간에 대조학습(contrastive learning)으로 정렬시키는 모델이다 ② 이미지만 입력으로 받아 분류만 수행하는 CNN 모델이다 ③ 텍스트만으로 이미지를 생성하는 디퓨전 모델이다 ④ RNN 기반의 순차적 이미지 캡셔닝 모델이다

**2.** CLIP을 이용한 Zero-shot 이미지 분류 방법으로 옳은 것은?
① 클래스명을 텍스트 프롬프트로 만들어 이미지 임베딩과의 유사도를 비교하고 가장 유사한 텍스트를 정답으로 선택한다 ② 각 클래스마다 별도의 분류기를 새로 학습시켜야 한다 ③ 이미지를 텍스트로 변환한 뒤 텍스트 분류기로 분류한다 ④ 라벨이 없는 이미지는 항상 무작위로 분류한다

**3.** CNN이 이미지의 공간 구조를 보존할 수 있는 핵심 이유는?
① 지역 연결성(local connectivity)과 가중치 공유(weight sharing)로 인접 픽셀 간 관계를 반영하기 때문 ② 완전연결층만으로 구성되어 있기 때문 ③ 이미지를 1차원 벡터로 완전히 평탄화하기 때문 ④ 픽셀 순서를 무작위로 섞어 학습하기 때문

**4.** 합성곱 출력 크기 공식으로 옳은 것은? (W: 입력크기, F: 필터크기, P: 패딩, S: 스트라이드)
① $O=\lfloor (W-F+2P)/S \rfloor + 1$ ② $O=W \times F$ ③ $O=(W+F)/P$ ④ $O=W-F-S$

**5.** 합성곱 층의 파라미터 수 계산 공식으로 옳은 것은? (F: 필터크기, Cin: 입력채널, Cout: 출력채널)
① $(F\times F\times C_{in}+1)\times C_{out}$ ② $F\times C_{in}\times C_{out}$만 ③ $F+C_{in}+C_{out}$ ④ $(F\times F)\times C_{out}$만

**6.** CNN과 ViT(Vision Transformer)를 비교할 때 옳은 것은?
① CNN은 지역성·이동불변성 같은 inductive bias가 강해 적은 데이터에서도 잘 학습되고, ViT는 이런 편향이 약해 대량의 데이터가 필요하다 ② ViT는 합성곱 연산만으로 이미지를 처리한다 ③ CNN은 항상 ViT보다 대규모 데이터에서 성능이 좋다 ④ 둘은 이미지 처리 방식이 완전히 동일하다

**7.** 신경망을 깊게(Deep) 쌓는 주된 이유는?
① 층을 깊게 쌓을수록 더 복잡하고 추상적인 표현(representation)을 계층적으로 학습할 수 있기 때문 ② 깊을수록 항상 연산 속도가 빨라지기 때문 ③ 깊을수록 파라미터 수가 항상 줄어들기 때문 ④ 깊이는 모델 성능과 무관하기 때문

**8.** Diffusion 모델의 Forward Process에 대한 설명으로 옳은 것은?
① 원본 이미지에 점진적으로 노이즈를 추가해 완전한 노이즈로 만드는 과정이다 ② 노이즈로부터 이미지를 한 번에 복원하는 과정이다 ③ 이미지를 텍스트로 변환하는 과정이다 ④ 이미지를 압축해 저장하는 과정이다

**9.** LLM 안전 정렬에서 Anthropic이 제시한 HHH 원칙에 포함되지 않는 것은?
① Helpful ② Harmless ③ Honest ④ Handsome

**10.** LSTM의 Forget Gate가 하는 역할로 옳은 것은?
① 이전 셀 상태(cell state)에서 어떤 정보를 버릴지 결정한다 ② 새로운 정보를 셀 상태에 무조건 추가한다 ③ 출력값을 항상 0으로 만든다 ④ 입력 시퀀스의 길이를 조절한다

**11.** p-value에 대한 정의로 가장 적절한 것은?
① 귀무가설이 참이라고 가정했을 때, 관측된 결과 이상으로 극단적인 값이 나올 확률 ② 대립가설이 참일 확률 ③ 표본 크기가 클 확률 ④ 모형의 결정계수 값

**12.** ReLU(Rectified Linear Unit) 활성화 함수의 수식으로 옳은 것은?
① $f(x)=\max(0,x)$ ② $f(x)=\dfrac{1}{1+e^{-x}}$ ③ $f(x)=\tanh(x)$ ④ $f(x)=x^2$

**13.** RLHF(Reinforcement Learning from Human Feedback)의 3단계 순서로 옳은 것은?
① 지시 학습(SFT) → 보상 모델(RM) 학습 → 강화학습(PPO) ② 보상 모델 학습 → 사전학습 → 데이터 증강 ③ PPO → SFT → RM 학습 ④ RM 학습 → PPO → 사전학습

**14.** 기본적인 Seq2Seq 구조에 대한 설명으로 옳은 것은?
① 인코더가 입력 시퀀스를 고정 길이 벡터로 요약하고 디코더가 이를 바탕으로 출력 시퀀스를 생성한다 ② 인코더와 디코더가 완전히 동일한 가중치를 공유해야 한다 ③ 입력과 출력의 길이가 항상 같아야 한다 ④ RNN을 전혀 사용하지 않는 구조다

**15.** Top-K 샘플링에 대한 설명으로 옳은 것은?
① 다음 토큰 후보를 확률이 높은 상위 K개로 제한한 뒤 그 안에서 샘플링한다 ② 확률이 가장 낮은 토큰만 선택한다 ③ 모든 토큰을 항상 동일한 확률로 샘플링한다 ④ K값과 관계없이 항상 1개의 토큰만 남긴다

**16.** 개방형(Open) LLM과 폐쇄형(Closed) LLM을 구분하는 가장 핵심적인 기준은?
① 모델 가중치가 공개되어 다운로드·수정이 가능한지 여부 ② 모델의 파라미터 수가 100억 개를 넘는지 여부 ③ 모델이 한국어를 지원하는지 여부 ④ 모델이 이미지 입력을 지원하는지 여부

**17.** 결정계수 $R^2$의 계산식으로 옳은 것은?
① $R^2 = 1 - \mathrm{RSS/TSS}$ ② $R^2 = \mathrm{RSS} \times \mathrm{TSS}$ ③ $R^2 = \mathrm{RSS} + \mathrm{TSS}$ ④ $R^2 = \mathrm{TSS}/\mathrm{RSS}$

**18.** 경사하강법(Gradient Descent)의 기본 원리로 옳은 것은?
① 손실함수의 기울기(gradient)가 감소하는 방향, 즉 기울기의 반대 방향으로 파라미터를 업데이트한다 ② 손실함수의 기울기와 같은 방향으로 파라미터를 업데이트한다 ③ 손실함수를 무시하고 무작위로 파라미터를 갱신한다 ④ 파라미터를 항상 0으로 초기화한 뒤 고정한다

**19.** 데이터 증강(Data Augmentation)에 대한 정의로 가장 적절한 것은?
① 기존 데이터를 변형하여 학습 데이터의 다양성을 인위적으로 늘리는 기법 ② 학습 데이터를 무작위로 삭제하는 기법 ③ 테스트 데이터를 학습 데이터에 그대로 포함시키는 기법 ④ 라벨을 무작위로 바꾸는 기법

**20.** 로지스틱 회귀가 선형회귀의 출력을 확률값으로 변환하기 위해 사용하는 함수는?
① 시그모이드(sigmoid) 함수 ② ReLU 함수 ③ 소프트맥스만 사용하고 시그모이드는 사용하지 않는다 ④ 항등 함수(identity function)

**21.** Multi-Head Attention을 사용하는 주된 이유로 가장 적절한 것은?
① 문법적 관계, 의미적 맥락 등 서로 다른 관점의 정보를 여러 헤드가 병렬로 동시에 포착하기 위해 ② 계산량을 항상 줄이기 위해서만 ③ 위치 정보를 완전히 대체하기 위해 ④ 파라미터 수를 늘리지 않기 위해

**22.** 선호 학습(Preference Learning)에 대한 정의로 가장 적절한 것은?
① 여러 응답 후보 중 어떤 응답이 상대적으로 더 선호되는지를 데이터로부터 학습하는 것 ② 정답이 하나로 고정된 분류 문제를 푸는 것 ③ 레이블 없이 군집을 나누는 것 ④ 이미지의 픽셀 값을 직접 예측하는 것

**23.** Self-Attention에서 사용하는 세 가지 벡터로 옳은 것은?
① Query, Key, Value ② Input, Output, Hidden ③ Weight, Bias, Gradient ④ Encoder, Decoder, Attention

**24.** 어텐션(Attention) 메커니즘의 기본 아이디어로 옳은 것은?
① 입력의 여러 부분 중 현재 예측에 중요한 부분에 더 큰 가중치를 두어 가중합(weighted sum)으로 정보를 반영하는 것 ② 입력을 항상 균등한 가중치로만 처리하는 것 ③ 입력의 마지막 부분만 사용하고 나머지는 완전히 무시하는 것 ④ 입력 순서를 무작위로 섞는 것

**25.** 언어모델(Language Model)의 기본적인 정의로 가장 적절한 것은?
① 주어진 문맥에서 다음에 올 단어(토큰)의 확률 분포를 예측하는 모델 ② 이미지를 분류하는 모델 ③ 정형 데이터를 군집화하는 모델 ④ 음성을 텍스트 없이 그대로 저장하는 모델

**26.** 학습 데이터에서는 성능이 매우 좋지만 새로운 데이터에서는 성능이 크게 떨어지는 현상을 무엇이라 하는가?
① 오버피팅(과적합) ② 언더피팅(과소적합) ③ 정규화(Regularization) ④ 데이터 증강

**27.** 온디바이스 VLM이 모바일 NPU를 활용하는 주된 이유는?
① 제한된 전력과 자원 안에서 비전-언어 연산을 효율적으로 가속하기 위해 ② 네트워크 대역폭을 늘리기 위해 ③ 모델 가중치를 서버로 전송하기 위해 ④ 학습 데이터를 자동으로 수집하기 위해

**28.** 지도학습(Supervised Learning)의 목적으로 가장 적절한 것은?
① 입력과 정답 라벨 쌍의 데이터로부터, 참 함수 $f$를 근사하는 함수 $\hat f$를 추정하는 것 ② 레이블 없이 데이터를 몇 개의 군집으로 나누는 것 ③ 보상 신호만으로 행동 정책을 학습하는 것 ④ 데이터의 차원을 축소하는 것

**29.** 지시 학습(Instruction Tuning)의 핵심 아이디어로 옳은 것은?
① 모든 NLP 태스크를 '지시(instruction) + 응답' 형태로 표현하여 학습하는 것 ② 라벨을 완전히 제거하고 비지도 방식으로만 학습하는 것 ③ 이미지 데이터만을 대상으로 학습하는 것 ④ 모델 파라미터를 전혀 갱신하지 않는 것

**30.** 지도학습에서 가정하는 데이터 생성 모형 $Y=f(X)+\varepsilon$에서 $\varepsilon$의 성질로 옳은 것은?
① 모델을 아무리 개선해도 원리적으로 줄일 수 없는 비가역 오차(irreducible error)이다 ② 모델을 복잡하게 만들면 완전히 제거할 수 있다 ③ 참 함수 $f$와 동일한 개념이다 ④ 항상 양수 값만 가진다

**31.** 클러스터링(Clustering)에 대한 정의로 가장 적절한 것은?
① 라벨 없이 데이터를 유사한 특성끼리 그룹(군집)으로 나누는 비지도학습 기법 ② 정답 라벨을 이용해 분류 경계를 학습하는 지도학습 기법 ③ 시계열 데이터를 예측하는 기법 ④ 이미지를 생성하는 기법

**32.** 파인튜닝(Fine-tuning)에 대한 정의로 가장 적절한 것은?
① 사전학습된 모델을 특정 태스크의 데이터로 추가 학습시켜 그 태스크에 맞게 적응시키는 것 ② 모델을 처음부터 무작위 초기화하여 학습하는 것 ③ 라벨 없이 데이터를 군집화하는 것 ④ 모델의 구조를 전혀 바꾸지 않고 추론만 수행하는 것

**33.** CLIP의 학습 방식으로 옳은 것은?
① 실제 (이미지, 텍스트) 쌍의 임베딩 유사도는 높이고, 짝이 아닌 쌍의 유사도는 낮추도록 대조 손실을 학습한다 ② 이미지에 대한 정답 클래스 라벨만으로 지도학습한다 ③ 텍스트 없이 이미지만으로 오토인코더처럼 복원 학습한다 ④ 사람이 직접 유사도 점수를 매긴 데이터로만 학습한다

**34.** CLIP Zero-shot 분류의 가장 큰 장점은?
① 추가 학습(파인튜닝) 없이도 새로운 클래스를 분류할 수 있다 ② 항상 파인튜닝된 전용 모델보다 정확도가 높다 ③ 라벨링된 학습 데이터가 반드시 있어야 동작한다 ④ 이미지 인코더 없이 텍스트만으로 분류한다

**35.** 완전연결층(FC)과 비교했을 때 CNN이 공간 정보를 더 잘 보존하는 이유는?
① FC는 입력을 1차원으로 펼쳐 위치 정보를 잃지만, CNN은 커널이 2차원 구조를 유지한 채 슬라이딩하며 인접 정보를 학습하기 때문 ② FC가 항상 더 많은 파라미터를 갖기 때문 ③ CNN은 배치 정규화를 사용하지 않기 때문 ④ FC는 활성화 함수를 사용하지 않기 때문

**36.** 입력 크기 $32\times32$, 필터 크기 $5\times5$, 패딩 0, 스트라이드 1일 때 출력 크기는?
① $28\times28$ ② $32\times32$ ③ $27\times27$ ④ $16\times16$

**37.** 필터 크기 $3\times3$, 입력채널 3, 출력채널 16(편향 포함)인 합성곱 층의 파라미터 수는?
① 448 ② 144 ③ 432 ④ 27

**38.** ViT가 이미지를 처리하는 방식으로 옳은 것은?
① 이미지를 일정 크기의 패치로 나눈 뒤 각 패치를 토큰처럼 취급해 Self-Attention으로 처리한다 ② 이미지를 픽셀 단위로 하나씩 RNN에 순차 입력한다 ③ 이미지를 합성곱 필터로만 처리하고 어텐션은 사용하지 않는다 ④ 이미지를 항상 흑백으로 변환한 뒤 처리한다

**39.** 심층 신경망 학습에서 발생하는 기울기 소실(Vanishing Gradient) 문제의 원인으로 옳은 것은?
① 역전파 과정에서 작은 값들이 층을 거치며 반복해서 곱해져 기울기가 점점 0에 가까워지기 때문 ② 학습률이 항상 너무 크기 때문 ③ 배치 크기가 항상 너무 작기 때문 ④ 활성화 함수를 전혀 사용하지 않기 때문

**40.** Diffusion 모델의 학습 목표로 가장 적절한 것은?
① 각 단계에서 추가된 노이즈를 예측하도록 신경망을 학습시킨다 ② 이미지의 클래스 라벨만 예측하도록 학습시킨다 ③ 노이즈 없이 원본 이미지를 그대로 암기하도록 학습시킨다 ④ 텍스트 임베딩만 예측하도록 학습시킨다
