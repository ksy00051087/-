## 다루는 범위

1. **선형회귀** — 단순/다중선형회귀, 최소제곱법, RSS·R², 표준오차·t·p-value, 정규방정식, 다중공선성, 상관≠인과
2. **로지스틱회귀** — 분류, 시그모이드, 오즈·로짓, MLE(log-likelihood), 신용카드 연체 사례
3. **신경망 모델** — Shallow 네트워크, ReLU, 조각별 선형, 보편적 근사 정리, 다중 입출력, Deep 네트워크와 접기(folding), 행렬·벡터 표기
4. **신경망 적합** — 손실함수, 미분과 최적화, 경사하강법, Convex vs Non-convex, SGD, 역전파(연쇄법칙)

## HTML 안의 인터랙티브 실습 13개

1. 최소제곱법 직접 맞춰보기 (슬라이더로 직선 조정 → RSS 실시간 비교)
2. 결정계수 R²가 뜻하는 것 (노이즈 σ 조절)
3. 다중공선성 체험 (상관 ↑ → 계수 추정치 요동)
4. 시그모이드 & 결정경계 탐색기 (확률·오즈·로짓 동시 계산)
5. 우도 vs 로그우도 (최대점이 같음을 확인)
6. Shallow 네트워크 조립하기 (ReLU 3개, 꺾임점 관찰)
7. 보편적 근사 정리 체감 (D를 늘리며 MSE 감소)
8. Deep vs Shallow 접기 실험 (조각 수 폭발)
9. 미분(기울기)과 경사하강 한 걸음 (α>1이면 발산)
10. 경사하강법 시뮬레이터 (손실 등고선 + 직선 동시 표시)
11. Convex / Non-convex 출발점 실험
12. GD vs SGD 경로 비교
13. 역전파 한 스텝 손으로 따라가기 (순전파/역전파 값 전개)
