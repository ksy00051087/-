## 객관식 (1~28)

**1.** 원-핫 인코딩의 근본적인 한계로 옳은 것은?
① 항상 계산 속도가 매우 느리다 ② 서로 다른 단어의 벡터가 항상 직교하여 단어 간 유사도를 측정할 수 없다 ③ 벡터 차원이 항상 2차원으로 고정된다 ④ 신경망에서는 아예 사용할 수 없다

**2.** "You shall know a word by the company it keeps"라는 문구가 나타내는 아이디어는?
① 원-핫 인코딩의 원리 ② 분포 가설(distributional hypothesis) — 주변 단어로 단어의 의미를 파악할 수 있다는 아이디어 ③ N-gram 모델의 한계 ④ Attention 메커니즘의 정의

**3.** Word2Vec의 Skip-gram 알고리즘에 대한 설명으로 옳은 것은?
① 주변 단어들로 중심 단어를 예측한다 ② 중심 단어로 주변 단어들을 예측한다 ③ 문장 전체의 감성을 분류한다 ④ 항상 CBOW보다 학습 속도가 빠르다

**4.** Skip-gram과 CBOW를 비교할 때 옳은 것은?
① CBOW가 희귀 단어 표현에 더 강하다 ② Skip-gram은 적은 데이터에도 잘 동작하고 희귀 단어에 강하지만 학습 속도가 느리다 ③ 둘의 학습 예시 개수는 항상 동일하다 ④ Skip-gram은 학습 속도가 항상 CBOW보다 빠르다

**5.** 순차적 데이터(Sequential Data)의 세 가지 특징에 해당하지 않는 것은?
① 순서가 중요하다 ② 장기 의존성이 존재할 수 있다 ③ 가변 길이를 가질 수 있다 ④ 항상 고정된 길이를 가져야 한다

**6.** N-gram 언어모델의 근본적인 한계로 옳은 것은?
① $n$을 키울수록 본 적 없는 조합이 급격히 늘어나 희소성(sparsity) 문제가 생긴다 ② $n$을 키우면 저장 공간이 오히려 줄어든다 ③ N-gram은 신경망보다 항상 성능이 좋다 ④ N-gram은 결측치를 자동으로 채워준다

**7.** Seq2Seq(sequence-to-sequence) 구조에 대한 설명으로 옳은 것은?
① 인코더가 입력을 고정된 차원의 벡터로 요약하고, 디코더가 이 벡터로부터 출력 시퀀스를 생성한다 ② 인코더와 디코더가 서로 완전히 독립적으로 학습된다 ③ 입력과 출력의 길이가 항상 같아야 한다 ④ RNN을 전혀 사용하지 않는 구조다

**8.** Seq2Seq의 "병목 문제(bottleneck problem)"란?
① 디코더가 인코더의 모든 hidden state에 직접 접근하는 문제 ② 입력 문장 전체 의미가 고정 길이 벡터 하나에 압축되어 정보 손실이 발생하는 문제 ③ 학습 속도가 너무 빨라지는 문제 ④ 파라미터가 너무 적어지는 문제

**9.** Teacher Forcing에 대한 설명으로 옳은 것은?
① 디코더의 입력으로 모델이 스스로 예측한 값 대신 정답 토큰을 강제로 넣어주는 학습 기법이다 ② 추론(inference) 시에만 사용하는 기법이다 ③ 인코더에서만 사용하는 기법이다 ④ 항상 성능을 저하시키는 기법이다

**10.** Greedy Decoding과 Beam Search를 비교할 때 옳은 것은?
① Greedy는 매 단계 가장 확률 높은 토큰만 선택하며 한 번 선택하면 되돌릴 수 없다 ② Beam Search는 항상 계산 비용이 더 적게 든다 ③ Greedy가 항상 전역적으로 최적의 문장을 찾는다 ④ Beam Search는 후보를 단 1개만 유지한다

**11.** Attention 메커니즘이 Seq2Seq의 병목 문제를 완화하는 방식은?
① 디코더가 인코더의 마지막 hidden state만 사용하도록 제한한다 ② 디코더가 매 스텝마다 인코더의 모든 hidden state 중 필요한 부분에 직접 접근(가중합)할 수 있게 한다 ③ 인코더를 아예 제거한다 ④ 병목 문제와 Attention은 관련이 없다

**12.** RNN과 비교했을 때 Self-Attention의 특징으로 옳은 것은?
① 상호작용 거리는 $O(\text{sequence length})$이고 병렬화가 쉽다 ② 상호작용 거리는 $O(1)$이지만 연산량/메모리는 시퀀스 길이의 제곱, 즉 $O(n^2)$이다 ③ RNN처럼 반드시 순차적으로 계산해야 한다 ④ 항상 RNN보다 계산량이 적다

**13.** Self-Attention의 세 가지 한계와 해결책의 짝으로 옳지 않은 것은?
① 순서 정보 부재 → Positional Encoding ② 비선형성 부족 → Feed-Forward Network 추가 ③ 미래 참조 문제 → Masked Self-Attention ④ 계산량 문제 → Dropout 추가

**14.** Multi-Head Attention을 사용하는 이유로 가장 적절한 것은?
① 계산량을 줄이기 위해서만 ② 문법적 관계, 의미적 맥락 등 여러 관점에서 동시에 정보를 파악하기 위해서 ③ 파라미터 수를 늘리지 않기 위해서 ④ 위치 정보를 대체하기 위해서

**15.** Scaled Dot Product Attention에서 $\sqrt{d_k}$(또는 $\sqrt{d/h}$)로 나누는 이유는?
① Query와 Key의 내적 값이 커져 softmax 출력이 지나치게 뾰족해지고 기울기 소실이 생기는 것을 방지하기 위해 ② 계산 속도를 늦추기 위해 ③ Value 벡터의 크기를 늘리기 위해 ④ 항상 결과값을 0으로 만들기 위해

**16.** Residual Connection과 Layer Normalization을 Transformer 블록에 사용하는 목적은?
① 층이 깊어질수록 학습이 어려워지는 문제(기울기 소실/폭발, 불안정한 값 크기)를 완화하기 위해 ② 파라미터 수를 늘리기 위해 ③ 위치 정보를 제거하기 위해 ④ 어텐션 계산을 생략하기 위해

**17.** Transformer의 Decoder 블록이 Encoder 블록과 다른 점은?
① Decoder는 Self-Attention에서 미래 토큰을 가리는 마스킹(Masked Self-Attention)을 사용해 단방향 문맥만 활용한다 ② Encoder만 Feed-Forward Network를 사용한다 ③ Decoder에는 Attention이 전혀 없다 ④ 둘은 완전히 동일한 구조다

**18.** Cross-Attention에 대한 설명으로 옳은 것은?
① Query, Key, Value가 모두 디코더에서 나온다 ② Query는 디코더에서, Key와 Value는 인코더에서 가져온다 ③ Query, Key, Value가 모두 인코더에서 나온다 ④ 인코더-디코더 구조가 아닌 모델에서만 사용된다

**19.** BERT의 Masked Language Model(MLM) 학습 방식에 대한 설명으로 옳은 것은?
① 입력 토큰의 15%를 무작위로 선택해 그 중 80%는 [MASK]로, 10%는 랜덤 토큰으로, 10%는 그대로 두고 예측시킨다 ② 선택된 토큰을 100% [MASK]로만 치환한다 ③ 모든 토큰을 항상 마스킹한다 ④ 마스킹은 파인튜닝 단계에서만 사용된다

**20.** BERT의 NSP(Next Sentence Prediction) 태스크의 목적은?
① 두 문장이 실제로 이어지는 문장인지 여부를 예측해 문장 간 관계를 학습하기 위해 ② 다음 단어를 예측하기 위해 ③ 이미지와 텍스트를 연결하기 위해 ④ 번역 성능을 높이기 위해

**21.** T5의 사전학습 방식인 Span Corruption에 대한 설명으로 옳은 것은?
① 단어 하나씩 개별적으로 마스킹한다 ② 연속된 토큰(span)을 무작위로 제거하고 placeholder로 치환한 뒤, 디코더가 원래 span을 복원하도록 학습한다 ③ 문장 전체를 뒤집어서 학습한다 ④ 레이블 없이 분류만 수행한다

**22.** GPT 계열(Decoder-only) 모델의 사전학습 방식은?
① Masked Language Model ② Next Sentence Prediction ③ 다음 단어 예측(Next Token Prediction) ④ Span Corruption

**23.** In-Context Learning(ICL)에 대한 설명으로 옳은 것은?
① 프롬프트 안의 설명과 예시만으로 새로운 태스크를 수행하며, 이 과정에서 모델의 가중치는 갱신되지 않는다 ② 반드시 파인튜닝(가중치 업데이트)이 함께 일어나야 한다 ③ 예시 수가 늘어나도 성능에 변화가 없다 ④ 작은 모델일수록 더 뚜렷하게 나타나는 현상이다

**24.** 파운데이션 모델(Foundation Model)을 구성하는 3가지 요소로 옳은 것은?
① 빅데이터, 자가 학습(Self-supervised Learning), 어텐션 기반 트랜스포머 ② 지도학습, 결측치 처리, PCA ③ CNN, RNN, LSTM ④ 원-핫 인코딩, N-gram, SMT

**25.** 규모의 법칙(Scaling Law)과 창발성(Emergent Property)의 차이로 옳은 것은?
① 규모의 법칙은 연속적·예측 가능한 개선이고, 창발성은 특정 규모를 넘으면 불연속적으로 나타나는 능력이다 ② 둘은 완전히 같은 개념이다 ③ 창발성은 모델을 작게 만들수록 강해진다 ④ 규모의 법칙은 모델 크기와 무관하다

**26.** RLHF(Reinforcement Learning from Human Feedback)의 3단계로 옳은 것은?
① 사전학습 → 데이터 증강 → 배포 ② 지시 학습(SFT) → 보상 모델(RM) 학습 → 강화학습(PPO) ③ MLM → NSP → Fine-tuning ④ Greedy → Beam → Sampling

**27.** 디코딩 알고리즘 중 Temperature $T$에 대한 설명으로 옳은 것은?
① $T>1$이면 확률 분포가 평평해져 다양성이 커지고, $T<1$이면 분포가 뾰족해져 항상 비슷한 답만 나오기 쉽다 ② $T$ 값은 항상 결과에 영향을 주지 않는다 ③ $T<1$일 때 다양성이 극대화된다 ④ Temperature는 Beam Search 전용 하이퍼파라미터다

**28.** LLM 평가에서 "정답이 정해져 있지 않은 경우"에 해당하지 않는 평가 방법은?
① 사람이 작성한 참조 정답과 비교(ROUGE, Sentence-BERT) ② 정답과 무관하게 텍스트 자체 품질 측정(Perplexity) ③ MMLU처럼 예측과 정답을 직접 비교해 Accuracy를 계산 ④ 두 응답 중 상대적으로 더 나은 것을 판단(LLM-as-judge, LMArena)
