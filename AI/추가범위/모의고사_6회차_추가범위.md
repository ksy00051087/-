## 객관식 (1~28)

**1.** LLM의 "안전 정렬(Safety Alignment)"에 대한 설명으로 가장 옳은 것은?
① 모델의 추론 속도를 높이는 최적화 기법이다 ② 모델이 유해하거나 위험한 요청을 거부하고 사회적 가치에 부합하는 응답을 하도록 만드는 정렬 학습이다 ③ 모델 파라미터 수를 줄이는 경량화 기법이다 ④ 모델의 사전학습 데이터셋 크기를 늘리는 기법이다

**2.** Anthropic이 제시한 HHH 원칙에 해당하지 않는 것은?
① Helpful(유용함) ② Harmless(무해함) ③ Honest(정직함) ④ Humorous(유머러스함)

**3.** Red-teaming에 대한 설명으로 옳은 것은?
① 모델의 학습 속도를 높이기 위한 병렬화 기법이다 ② 배포 전 적대적 프롬프트로 모델의 취약점을 미리 찾아내는 과정이다 ③ 여러 모델을 앙상블하는 기법이다 ④ 학습 데이터에서 이상치를 자동으로 제거하는 기법이다

**4.** Constitutional AI(RLAIF)의 핵심 아이디어로 옳은 것은?
① 사람이 만든 소수의 원칙(헌법)을 기준으로 모델이 스스로 응답을 비판·수정하게 하여 AI 피드백 기반 선호 데이터를 만든다 ② 사람의 피드백을 완전히 배제하고 무작위로 응답을 생성한다 ③ 헌법 조문을 그대로 학습 데이터로 사용해 암기시킨다 ④ 모델 크기를 늘려 안전성을 확보하는 기법이다

**5.** 안전 정렬에서 "과잉 거절(Over-refusal)"이 의미하는 것은?
① 모델이 모든 질문에 답을 하지 않는 것 ② 실제로는 무해한 요청까지 유해하다고 판단해 거절하는 것 ③ 모델이 유해한 요청에도 답을 하는 것 ④ 모델이 학습을 거부하는 현상

**6.** 안전 정렬 파이프라인의 흐름으로 가장 적절한 것은?
① 배포 → 사전학습 → 삭제 ② 안전 SFT → Red-teaming → 안전 선호 데이터 생성 → RM 재학습 → RLHF → 배포 후에도 반복 ③ RLHF 한 번으로 영구히 완료 ④ 데이터 증강 → PCA → 클러스터링

**7.** 폐쇄형(Closed) LLM에 대한 설명으로 옳은 것은?
① 모델 가중치가 공개되어 누구나 다운로드할 수 있다 ② 모델 가중치·구조가 비공개이며 API 호출을 통해서만 접근할 수 있다 ③ 항상 개방형보다 계산 자원이 적게 든다 ④ 대표 예시로 LLaMA, Qwen이 있다

**8.** 개방형(Open) LLM의 장점으로 가장 적절한 것은?
① API 호출 비용이 전혀 없고 모델 가중치가 공개되어 파인튜닝·온디바이스 배포 등에 자유롭다 ② 항상 폐쇄형보다 성능이 뛰어나다 ③ 별도의 계산 자원 없이도 실행할 수 있다 ④ 모델 구조를 절대 확인할 수 없다

**9.** 다음 중 폐쇄형 LLM의 예시로만 짝지어진 것은?
① ChatGPT, Claude, Gemini ② LLaMA, Gemma, Mistral ③ ChatGPT, LLaMA ④ Qwen, DeepSeek

**10.** 개방형 LLM 접근 방법으로 가장 적절한 것은?
① 반드시 유료 API를 호출해야 한다 ② Hugging Face 허브 등에서 가중치를 직접 다운로드해 로컬/서버에서 실행한다 ③ 웹 브라우저 채팅 화면으로만 접근 가능하다 ④ 접근이 원천적으로 불가능하다

**11.** 데이터가 외부로 나갈 수 없는 민감한 환경(온프레미스)에서 LLM을 선택할 때 가장 적절한 기준은?
① 무조건 최신 폐쇄형 API를 사용한다 ② 가중치를 직접 보유해 내부망에서 실행할 수 있는 개방형 모델을 고려한다 ③ 데이터를 익명화 없이 외부 API로 그대로 전송한다 ④ 모델 선택과 데이터 민감도는 무관하다

**12.** 개방형/폐쇄형 LLM 선택에서 고려해야 할 트레이드오프 축으로 옳지 않은 것은?
① 초기 비용과 인프라 구축 부담 ② 데이터 민감도와 보안 요구 수준 ③ 커스터마이징(파인튜닝) 자유도 ④ 모델의 글꼴(font) 종류

**13.** 오버피팅(과적합)에 대한 설명으로 옳은 것은?
① 학습 데이터의 패턴과 노이즈까지 과도하게 암기하여 새로운 데이터에서 성능이 떨어지는 현상이다 ② 학습 데이터와 테스트 데이터 모두에서 성능이 낮은 현상이다 ③ 모델이 너무 단순해서 발생하는 현상이다 ④ 항상 데이터 양이 많을 때만 발생한다

**14.** 오버피팅을 방지하는 기법으로 옳지 않은 것은?
① Dropout ② Early Stopping ③ L2 정규화(Regularization) ④ 모델의 파라미터 수를 무제한으로 늘리기

**15.** 분포 변화(Distribution Shift)에 대한 설명으로 옳은 것은?
① 학습 데이터의 분포와 배포 후 실제로 마주치는 데이터의 분포가 달라지는 현상이다 ② 항상 모델 구조를 바꾸면 해결되는 현상이다 ③ 학습 데이터 양이 많으면 절대 발생하지 않는다 ④ 오버피팅과 전혀 관련이 없는 개념이다

**16.** 분포 변화의 세 가지 유형과 그 정의를 옳게 짝지은 것은?
① Covariate Shift(입력 분포 변화) — Label Shift(출력 분포 변화) — Concept Shift(입출력 관계 변화) ② Covariate Shift(출력 분포 변화) — Label Shift(입력 분포 변화) — Concept Shift(모델 구조 변화) ③ 세 유형 모두 동일한 것을 가리키는 다른 이름이다 ④ Concept Shift는 항상 Overfitting과 같은 의미다

**17.** 오버피팅과 분포 변화의 관계에 대한 설명으로 가장 적절한 것은?
① 오버피팅된 모델은 학습 분포에만 과도하게 최적화되어 있어 분포 변화가 일어났을 때 성능이 더 크게 흔들린다 ② 오버피팅과 분포 변화는 서로 완전히 독립적이며 아무 관련이 없다 ③ 분포 변화가 있으면 오버피팅은 자동으로 해결된다 ④ 오버피팅이 심할수록 분포 변화에 대한 강건성이 높아진다

**18.** 온디바이스 VLM(Vision-Language Model)에 대한 설명으로 가장 적절한 것은?
① 클라우드 서버에서만 실행되는 초대형 비전-언어 모델이다 ② 스마트폰 등 자원이 제한된 단말기에서 직접 실행되도록 경량화된 비전-언어 모델이다 ③ 텍스트만 처리하고 이미지는 처리하지 못하는 모델이다 ④ 반드시 인터넷 연결이 있어야만 동작하는 모델이다

**19.** 온디바이스 VLM이 필요한 이유로 옳지 않은 것은?
① 민감한 이미지 데이터를 서버로 전송하지 않아도 되는 프라이버시 이점 ② 네트워크 왕복 없이 즉시 응답하는 낮은 지연시간 ③ 인터넷 연결이 없는 환경에서도 동작 가능 ④ 서버보다 항상 더 높은 정확도를 보장

**20.** 온디바이스 VLM의 경량화 기법 중 "양자화(Quantization)"에 대한 설명으로 옳은 것은?
① 모델 가중치의 비트 수(예: 32비트 → 8비트)를 낮춰 모델 크기와 연산량을 줄이는 기법이다 ② 학습 데이터를 인위적으로 늘리는 기법이다 ③ 여러 모델의 출력을 평균내는 기법이다 ④ 어텐션 헤드 수를 늘리는 기법이다

**21.** 지식 증류(Knowledge Distillation)에 대한 설명으로 옳은 것은?
① 크고 성능이 좋은 teacher 모델의 출력을 작은 student 모델이 모방하도록 학습시켜 크기는 줄이면서 성능은 최대한 유지하는 기법이다 ② 모델의 가중치를 완전히 무작위로 초기화하는 기법이다 ③ 학습 데이터에서 라벨을 제거하는 기법이다 ④ 모델을 여러 GPU에 분산 배치하는 기법과 동일하다

**22.** VLM의 기본 구조로 가장 적절한 것은?
① 이미지 인코더의 출력을 Projection Layer로 LLM 임베딩 공간에 정렬한 뒤 LLM(디코더)이 텍스트를 생성한다 ② 텍스트 인코더만 존재하고 이미지는 사용하지 않는다 ③ 이미지와 텍스트를 완전히 독립적으로 처리해 서로 절대 연결하지 않는다 ④ 반드시 CNN 없이 완전연결층만으로 구성된다

**23.** 온디바이스 VLM과 클라우드 VLM을 비교할 때 옳은 것은?
① 온디바이스 VLM은 일반적으로 지연시간이 낮고 프라이버시에 유리하지만, 경량화로 인해 정확도는 상대적으로 낮아지는 경향이 있다 ② 온디바이스 VLM은 항상 클라우드 VLM보다 정확도가 높다 ③ 클라우드 VLM은 네트워크 없이도 즉시 응답한다 ④ 두 방식은 트레이드오프가 전혀 없다

**24.** 지도학습에서 가정하는 데이터 생성 모형 $Y=f(X)+\varepsilon$ 에서 $f$가 의미하는 것은?
① 관측되지 않는 무작위 잡음 ② 입력과 출력 사이의 실제(이상적인) 관계를 나타내는 참 함수 ③ 모델 학습에 사용된 손실 함수 ④ 데이터의 표준편차

**25.** 위 모형에서 $\varepsilon$(측정오차)에 대한 설명으로 옳은 것은?
① $X$만으로는 설명되지 않는 무작위 잡음으로, 평균이 0이라고 가정하는 경우가 많다 ② 모델을 복잡하게 만들면 완전히 제거할 수 있는 오차이다 ③ 참 함수 $f$와 동일한 것을 가리키는 다른 표현이다 ④ 항상 양수 값만 가진다

**26.** 지도학습의 목적으로 가장 적절한 것은?
① 측정오차 $\varepsilon$을 정확히 예측하는 것 ② 관측된 데이터로부터 참 함수 $f$를 최대한 잘 근사하는 추정 함수 $\hat f$를 찾는 것 ③ 데이터의 개수를 최대한 늘리는 것 ④ 입력 변수의 개수를 0으로 줄이는 것

**27.** 기대 예측오차의 분해식 $E[(Y-\hat f(x_0))^2] = \text{Bias}^2 + \text{Var} + \text{Var}[\varepsilon]$ 에서 "비가역 오차(irreducible error)"에 해당하는 항은?
① $\text{Bias}^2$ ② $\text{Var}[\hat f(x_0)]$ (분산) ③ $\text{Var}[\varepsilon]$ (측정오차의 분산) ④ 세 항의 합 전체

**28.** 비가역 오차(측정오차의 분산)에 대한 설명으로 옳은 것은?
① 모델을 아무리 개선해도 원리적으로 줄일 수 없는, 데이터 자체에 내재된 오차이다 ② 모델 구조를 바꾸면 항상 0으로 만들 수 있다 ③ 편향과 완전히 동일한 개념이다 ④ 학습 데이터를 늘리면 사라지는 오차이다
