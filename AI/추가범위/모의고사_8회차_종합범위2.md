## 객관식 (1~40)

**1.** Red-teaming이 LLM 안전 정렬 과정에서 하는 역할로 옳은 것은?
① 배포 전 적대적 프롬프트로 모델의 취약점을 찾아 이후 재학습에 반영한다 ② 모델의 추론 속도를 물리적으로 높인다 ③ 학습 데이터의 저작권 문제를 해결한다 ④ 모델 파라미터 수를 줄인다

**2.** LSTM의 Input Gate와 Output Gate에 대한 설명으로 옳은 것은?
① Input Gate는 새 정보를 셀 상태에 얼마나 반영할지, Output Gate는 셀 상태를 얼마나 출력(hidden state)으로 내보낼지 결정한다 ② Input Gate와 Output Gate는 완전히 동일한 계산을 수행한다 ③ 두 게이트 모두 기울기 소실과는 무관하다 ④ Output Gate는 셀 상태를 완전히 삭제하는 역할만 한다

**3.** 일반적으로 유의수준 0.05를 기준으로 p-value를 해석할 때 옳은 것은?
① p-value가 0.05보다 작으면 귀무가설을 기각할 통계적 근거로 해석하는 경우가 많다 ② p-value가 0.05보다 크면 항상 귀무가설을 기각해야 한다 ③ p-value는 항상 1보다 큰 값을 가진다 ④ p-value는 유의수준과 아무 관계가 없다

**4.** ReLU가 시그모이드보다 심층 신경망에서 선호되는 주된 이유는?
① 양수 구간에서 기울기가 1로 일정해 기울기 소실 문제를 완화하고 계산이 단순해 효율적이기 때문 ② ReLU는 항상 출력값이 음수이기 때문 ③ ReLU는 미분이 불가능해 학습이 더 안정적이기 때문 ④ ReLU는 항상 시그모이드보다 파라미터 수가 적기 때문

**5.** RLHF에서 보상 모델(Reward Model)이 하는 역할로 옳은 것은?
① 사람의 선호 순위 데이터를 학습해 (프롬프트, 응답)을 입력받아 스칼라 보상 점수를 출력한다 ② 다음 토큰을 직접 생성한다 ③ 학습 데이터를 자동으로 라벨링 없이 수집한다 ④ 모델의 파라미터 수를 줄인다

**6.** Seq2Seq의 병목 문제(bottleneck problem)란?
① 입력 문장 전체의 의미가 고정 길이 벡터 하나에 압축되어 정보 손실이 발생하는 문제 ② 디코더가 인코더의 모든 hidden state에 직접 접근하는 문제 ③ 학습 속도가 지나치게 빨라지는 문제 ④ 출력 시퀀스 길이가 항상 0이 되는 문제

**7.** Top-P(Nucleus) 샘플링에 대한 설명으로 옳은 것은?
① 누적 확률이 P를 넘을 때까지 확률이 높은 토큰들을 후보로 묶고, 이 안에서 샘플링해 문맥에 따라 후보 개수가 자동으로 조절된다 ② 항상 고정된 개수 K개의 토큰만 후보로 삼는다 ③ 확률이 0인 토큰만 선택한다 ④ P 값과 무관하게 항상 전체 어휘를 후보로 사용한다

**8.** 개방형 LLM이 커스터마이징 측면에서 갖는 장점으로 옳은 것은?
① 가중치 수준에서 자유롭게 파인튜닝·경량화·온디바이스 배포를 할 수 있다 ② 항상 API 비용이 폐쇄형보다 비싸다 ③ 모델 구조를 절대 확인할 수 없다 ④ 커스터마이징이 원천적으로 불가능하다

**9.** 결정계수 $R^2$ 값이 1에 가까울수록 의미하는 것은?
① 모형이 데이터의 분산을 잘 설명하고 있다 ② 모형이 데이터를 전혀 설명하지 못한다 ③ 잔차제곱합(RSS)이 전체제곱합(TSS)보다 항상 크다 ④ 독립변수가 하나도 없다는 뜻이다

**10.** 학습률(learning rate)이 지나치게 클 때 발생할 수 있는 문제는?
① 최솟값 부근에서 진동하거나 발산하여 손실이 오히려 증가할 수 있다 ② 학습이 항상 더 안정적으로 수렴한다 ③ 파라미터가 전혀 업데이트되지 않는다 ④ 기울기가 항상 정확히 0이 된다

**11.** 이미지 데이터 증강 기법의 예시로 옳지 않은 것은?
① 결정계수(R^2) 계산 ② 회전(rotation) ③ 크롭(cropping) ④ 색상 변화(color jitter)

**12.** 로지스틱 회귀에서 "로짓(logit)" 변환이 의미하는 것은?
① 확률 $p$를 오즈비의 로그값 $\log(p/(1-p))$로 변환하는 것 ② 확률을 정수로 반올림하는 것 ③ 입력 변수를 표준화하는 것 ④ 잔차를 제곱하는 것

**13.** Multi-Head Attention에서 각 헤드의 차원은 일반적으로 어떻게 설정되는가?
① 전체 모델 차원 $d_{model}$을 헤드 개수 $h$로 나눈 $d_{model}/h$ ② 항상 $d_{model}$과 동일하게 설정된다 ③ 헤드 개수와 무관하게 항상 1로 고정된다 ④ 항상 입력 시퀀스 길이와 같게 설정된다

**14.** 선호 학습이 RLHF 파이프라인에서 사용되는 지점으로 옳은 것은?
① 사람이 매긴 응답 쌍의 선호 순위 데이터로 보상 모델(RM)을 학습하는 단계 ② 사전학습(pre-training) 단계에서 다음 토큰을 예측하는 부분 ③ 이미지 인코더를 학습하는 단계 ④ 토크나이저를 구축하는 단계

**15.** Scaled Dot-Product Attention의 수식으로 옳은 것은?
① $\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\dfrac{QK^\top}{\sqrt{d_k}}\right)V$ ② $\mathrm{Attention}(Q,K,V)=QKV$ ③ $\mathrm{Attention}(Q,K,V)=\mathrm{softmax}(Q+K+V)$ ④ $\mathrm{Attention}(Q,K,V)=Q/K/V$

**16.** Attention이 Seq2Seq의 병목 문제를 완화하는 방식으로 옳은 것은?
① 디코더가 매 스텝마다 인코더의 모든 hidden state 중 필요한 부분에 직접 접근(가중합)할 수 있게 한다 ② 인코더를 아예 제거하여 정보 손실을 없앤다 ③ 디코더가 인코더의 마지막 hidden state만 사용하도록 제한한다 ④ 어텐션은 병목 문제와 관련이 없다

**17.** N-gram 언어모델과 신경망 기반 언어모델을 비교할 때 옳은 것은?
① N-gram은 정해진 개수의 이전 단어만 보고 확률을 추정해 희소성(sparsity) 문제가 있는 반면, 신경망 언어모델은 연속적인 임베딩으로 더 긴 문맥을 일반화해 다룰 수 있다 ② N-gram은 항상 신경망보다 더 넓은 문맥을 본다 ③ 둘은 완전히 동일한 방식으로 확률을 계산한다 ④ 신경망 언어모델은 확률 분포를 전혀 출력하지 않는다

**18.** 교차검증(Cross-validation)이 오버피팅 진단에 활용되는 방식으로 옳은 것은?
① 데이터를 여러 번 다르게 나눠 학습·검증하여 일반화 성능을 더 안정적으로 추정함으로써 오버피팅 여부를 판단하는 데 활용된다 ② 교차검증은 항상 학습 데이터를 늘리는 기법이다 ③ 교차검증은 모델 구조를 자동으로 변경하는 기법이다 ④ 교차검증은 분포 변화와 전혀 관련이 없다

**19.** 온디바이스 VLM 설계에서 배터리·발열을 고려해야 하는 이유는?
① 연산 부담이 서버가 아닌 기기 자체로 이전되어 전력 소모와 발열에 직접 영향을 주기 때문 ② 배터리와 발열은 모델 정확도와 전혀 관련이 없기 때문 ③ 온디바이스 모델은 항상 전력을 소모하지 않기 때문 ④ 발열은 클라우드 서버에서만 발생하는 문제이기 때문

**20.** 지도학습이 성립하기 위해 반드시 필요한 것으로 옳은 것은?
① 입력에 대응하는 정답(라벨)이 있는 학습 데이터 ② 라벨이 전혀 없는 데이터만 ③ 보상 함수와 환경만 ④ 군집의 개수를 미리 정하는 것

**21.** FLAN 논문에서 보여준 지시 학습의 대표적인 효과로 옳은 것은?
① 여러 태스크로 지시 학습한 모델이 학습 중 보지 못한 새로운 태스크에서도 zero-shot 성능이 크게 향상되었다 ② 지시 학습은 항상 성능을 저하시켰다 ③ 지시 학습은 태스크가 한 개일 때만 효과가 있었다 ④ 지시 학습은 사전학습을 완전히 대체할 수 없어 아무 의미가 없었다

**22.** 기대 예측오차의 분해 $E[(Y-\hat f(x_0))^2]=\mathrm{Bias}^2+\mathrm{Var}+\mathrm{Var}[\varepsilon]$에서 모델 선택으로 조절 가능한 항으로 옳은 것은?
① 편향²(Bias²)과 분산(Variance) ② 비가역 오차(Var[ε]) ③ 세 항 모두 조절 불가능 ④ $Y$ 자체

**23.** K-Means 알고리즘의 기본 절차로 옳은 것은?
① 중심점을 초기화한 뒤, 각 데이터를 가장 가까운 중심점에 할당하고 중심점을 다시 계산하는 과정을 반복한다 ② 데이터를 항상 무작위로 한 번만 나눈다 ③ 라벨을 먼저 학습한 뒤 중심점을 계산한다 ④ 군집 개수를 알고리즘이 스스로 무한히 늘린다

**24.** 전체 파인튜닝(Full Fine-tuning)과 PEFT(예: LoRA) 방식의 차이로 옳은 것은?
① 전체 파인튜닝은 모델의 모든 파라미터를 업데이트하고, LoRA 같은 PEFT는 일부 저차원 파라미터만 학습해 효율적으로 적응시킨다 ② 두 방식은 완전히 동일한 양의 파라미터를 학습한다 ③ PEFT는 항상 전체 파인튜닝보다 더 많은 자원을 필요로 한다 ④ 전체 파인튜닝은 파라미터를 전혀 갱신하지 않는다

**25.** CLIP의 구조에 대한 설명으로 옳은 것은?
① 이미지 인코더(ViT/CNN)와 텍스트 인코더(Transformer)가 각각 임베딩을 만들고, 두 임베딩의 유사도를 비교한다 ② 하나의 인코더가 이미지와 텍스트를 동시에 입력받아 하나의 벡터로 압축한다 ③ 이미지 인코더만 존재하며 텍스트는 후처리로 붙인다 ④ 디코더 전용 구조로 다음 토큰만 예측한다

**26.** CLIP Zero-shot 분류에서 "a photo of a {class}"와 같은 문구를 사용하는 이유는?
① 프롬프트 형식이 CLIP의 zero-shot 분류 성능에 영향을 주기 때문에(프롬프트 엔지니어링) ② 텍스트 인코더의 입력 길이를 강제로 늘리기 위해 ③ 이미지 인코더의 해상도를 맞추기 위해 ④ 모델 학습 속도를 높이기 위해

**27.** CNN의 얕은 층과 깊은 층이 학습하는 특징의 차이로 옳은 것은?
① 얕은 층은 edge·texture 같은 저수준 특징을, 깊은 층은 객체·의미 같은 고수준(semantic) 특징을 학습하는 경향이 있다 ② 얕은 층과 깊은 층은 항상 동일한 특징을 학습한다 ③ 깊은 층일수록 항상 저수준 특징만 학습한다 ④ 층의 깊이는 학습되는 특징의 종류와 무관하다

**28.** 입력 크기 $28\times28$에 $2\times2$ 맥스풀링(스트라이드 2)을 적용하면 출력 크기는?
① $14\times14$ ② $28\times28$ ③ $56\times56$ ④ $7\times7$

**29.** CNN이 완전연결층보다 이미지 처리에서 파라미터 효율이 좋은 핵심 이유는?
① 가중치 공유(weight sharing)로 같은 필터를 이미지 전체에 재사용하기 때문 ② 항상 층 수가 더 적기 때문 ③ 입력 해상도를 자동으로 줄이기 때문 ④ 활성화 함수를 사용하지 않기 때문

**30.** 데이터 규모와 CNN·ViT 성능의 관계로 옳은 것은?
① 데이터가 충분히 많아지면 ViT가 CNN의 성능을 따라잡거나 능가하는 경향이 있다 ② 데이터 양은 두 모델의 성능에 전혀 영향을 주지 않는다 ③ ViT는 데이터가 적을수록 항상 CNN보다 성능이 좋다 ④ CNN은 데이터가 많아져도 성능이 향상되지 않는다

**31.** Residual Connection(잔차 연결)이 심층 신경망 학습을 돕는 방식으로 옳은 것은?
① 입력을 출력에 더해주는 지름길(skip connection)을 만들어 기울기가 더 잘 전달되도록 한다 ② 모든 층의 가중치를 0으로 초기화한다 ③ 층의 개수를 자동으로 줄여준다 ④ 활성화 함수를 완전히 제거한다

**32.** Diffusion 모델의 이미지 생성(샘플링) 과정으로 옳은 것은?
① 랜덤 노이즈에서 시작해 학습된 노이즈 예측 모델로 점진적으로 노이즈를 제거(디노이징)하며 이미지를 생성한다 ② 학습 데이터 중 하나를 그대로 복사해서 출력한다 ③ 한 번의 순전파로 노이즈 없이 즉시 이미지를 완성한다 ④ 텍스트 인코더만으로 픽셀을 직접 계산한다

**33.** 안전 정렬에서 과잉 거절(Over-refusal) 문제가 발생하는 이유로 가장 적절한 것은?
① 안전성을 지나치게 강조한 나머지 실제로는 무해한 요청까지 걸러내기 때문 ② 모델이 안전 정렬을 전혀 받지 않았기 때문 ③ 모델이 항상 모든 요청에 답하도록 설계되었기 때문 ④ 안전 정렬과 유용성은 서로 아무 관련이 없기 때문

**34.** LSTM의 셀 상태(Cell State)가 하는 역할로 가장 적절한 것은?
① 게이트들의 조절을 받으며 장기적인 정보를 비교적 안정적으로 유지·전달하는 통로 역할을 한다 ② 매 타임스텝마다 완전히 초기화된다 ③ 입력과 무관하게 항상 고정된 값을 유지한다 ④ 출력값과 동일한 벡터이다

**35.** p-value 해석에서 주의해야 할 점으로 가장 적절한 것은?
① p-value가 작다고 해서 반드시 효과의 크기(실질적 유의성)가 크다는 것을 의미하지는 않는다 ② p-value는 효과크기와 완전히 동일한 지표이다 ③ p-value가 작으면 표본 크기와 무관하게 항상 실질적으로 중요한 결과이다 ④ p-value는 항상 정확히 0 또는 1의 값만 가진다

**36.** ReLU의 대표적인 한계인 "Dying ReLU" 문제란?
① 뉴런의 입력이 계속 음수가 되어 출력과 기울기가 항상 0이 되면서 더 이상 학습이 되지 않는 현상 ② ReLU를 사용하면 모델이 절대 수렴하지 않는 현상 ③ ReLU가 항상 출력을 1로 고정시키는 현상 ④ ReLU가 입력값을 모두 양수로 바꿔버려 정보가 사라지는 현상

**37.** RLHF의 마지막 단계인 PPO(강화학습)의 역할로 가장 적절한 것은?
① 보상 모델의 점수를 최대화하는 방향으로 언어모델(정책)의 파라미터를 업데이트한다 ② 학습 데이터의 정답 라벨을 새로 생성한다 ③ 이미지 인코더를 새로 학습한다 ④ 모델 크기를 줄이는 경량화를 수행한다

**38.** Transformer가 RNN 기반 Seq2Seq를 대체하게 된 주된 이유는?
① Self-Attention을 통해 순차 계산 없이 병렬화가 가능하고 장거리 의존성을 더 잘 포착하기 때문 ② Transformer는 항상 파라미터 수가 더 적기 때문 ③ Transformer는 어텐션을 전혀 사용하지 않기 때문 ④ RNN은 병렬화가 항상 더 쉽기 때문

**39.** Temperature와 Top-K/Top-P 샘플링의 관계에 대한 설명으로 옳은 것은?
① Temperature는 확률 분포 자체의 모양(뾰족함/평평함)을 조절하고, Top-K/Top-P는 그 분포에서 후보를 얼마나 남길지를 조절하는 별개의 장치다 ② Temperature와 Top-K는 완전히 동일한 하이퍼파라미터다 ③ Top-P를 사용하면 Temperature는 절대 적용할 수 없다 ④ Temperature는 후보 개수를 직접 지정하는 값이다

**40.** 폐쇄형 LLM의 일반적인 비용 구조에 대한 설명으로 옳은 것은?
① API 호출 시 입력·출력 토큰 수에 비례해 비용이 발생한다 ② 한 번 구매하면 이후 호출 비용이 전혀 발생하지 않는다 ③ 비용은 항상 모델 크기와 무관하게 고정이다 ④ 무조건 무료로 무제한 사용할 수 있다
