1 선형회귀 · 로지스틱회귀

1차시 · 지도학습의 기초. 회귀와 분류의 출발점.

1-1. 단순선형회귀

정의: 입력과 출력의 관계를 직선 형태로 근사하여 예측하는 통계적 방법. 지도학습의 가장 기초적 접근.

$$Y=\beta_0+\beta_1X+\varepsilon$$
$\beta_0$절편 ($X=0$일 때 $Y$) $\beta_1$기울기 ($X$가 1 증가할 때 $Y$의 평균 증가량) $\varepsilon$관측 오차(=모델이 설명 못하는 부분, 잔차와는 다른 개념)

최소제곱법 (Least Squares)

실제값-예측값 차이(잔차)를 제곱해 합한 값 RSS(잔차제곱합)을 최소화 → closed-form 해 존재.

$$e_i=y_i-\hat y_i,\qquad \mathrm{RSS}=\sum_{i=1}^n e_i^2=\sum_{i=1}^n(y_i-\hat\beta_0-\hat\beta_1x_i)^2$$ $$\hat\beta_1=\frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2}\qquad \hat\beta_0=\bar y-\hat\beta_1\bar x$$
잔차 $e_i=y_i-\hat y_i$ (실제값 − 예측값), RSS = 잔차 제곱의 합. $R^2 = 1-\mathrm{RSS/TSS}$이며 TSS는 "평균만으로 예측했을 때"의 오차. $R^2$가 1에 가까울수록 설명력이 좋다.

1-2. 다중선형회귀

$$Y=\beta_0+\beta_1X_1+\cdots+\beta_pX_p+\varepsilon$$

여러 독립변수를 동시에 고려. 해석: 다른 변수를 고정한 채 $X_j$가 1 증가하면 $Y$가 평균적으로 $\beta_j$만큼 변화.

행렬 표현: $\mathbf y=\mathbf X\boldsymbol\beta+\boldsymbol\epsilon$
$$\text{정규방정식(closed-form 해)}\quad \hat{\boldsymbol\beta}=(\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y$$
RSS를 $\hat\beta$로 미분해 0으로 놓으면 $-2X^\top y+2X^\top X\hat\beta=0$ → 위 정규방정식이 유도됨.

회귀 주의사항

  • 다중공선성(multicollinearity): 독립변수들이 서로 강하게 상관 → 계수 추정이 불안정해지고 해석에 혼동 발생.
  • 상관 ≠ 인과: "아이스크림 소비량 ↑ ↔ 상어에 물리는 사건 ↑" (숨은 변수 = 기온). 관찰 데이터의 상관관계로 인과관계를 주장하면 안 됨.
  • 훈련 성능만으로 평가 시 → 테스트 성능을 과소평가(=일반화 성능을 과대평가)하는 문제. 검증/교차검증 필요.

1-3. 로지스틱 회귀 (분류)

분류(Classification): 정해진 범주 중 하나로 지정. 순서 없는 범주형 변수를 다룸.

분류 문제에 선형회귀를 그대로 쓰면? → 예측값이 0~1 범위를 벗어날 수 있어(확률로 부적절) 사용 불가.

시그모이드 함수로 0~1 확률 범위 보장:

$$y=\frac{1}{1+e^{-z}}\ \ (0\le y\le1)\qquad p(X;\boldsymbol\beta)=\frac{1}{1+e^{-(\beta_0+\beta_1x)}}$$

오즈(Odds) · 로짓(logit)

$$\text{odds}=\frac{p(y=1|x)}{1-p(y=1|x)}\qquad \mathrm{logit}(p)=\log(\text{odds})=\beta_0+\beta_1x$$
로지스틱 모형 = 선형 모형 + 시그모이드. 로짓 변환을 하면 다시 선형 모형이 된다. 이 대응관계는 시험에 자주 나옴.

MLE (최대우도추정)

확률 함수의 적합도는 우도(Likelihood)로 평가 (선형회귀의 MSE에 대응). log는 단조증가함수라 log-likelihood를 최대화해도 같은 $\hat\beta$를 얻는다(계산 편의를 위해 로그 취함, 곱셈→덧셈).

$$\log\mathcal L(\boldsymbol\beta)=\sum_i\big[y_i\log p(x_i;\beta)+(1-y_i)\log(1-p(x_i;\beta))\big]$$
balance 계수가 양수 → balance가 증가할수록 연체의 로짓(log-odds)이 증가. 확률 자체는 선형이 아니다(입력을 2배 늘려도 확률은 97배 뛸 수 있음 예시).

확인문제로 보는 포인트

Q. 잔차(residual) $e_i$의 정의?
A. $e_i=y_i-\hat y_i$ (실제값−예측값)
Q. 다중선형회귀 정규방정식(closed-form)?
A. $\hat\beta=(X^\top X)^{-1}X^\top y$
Q. 로지스틱 회귀 모수 추정에 쓰이는 방법?
A. 최대우도추정(MLE)

2 신경망 모델 & 신경망 적합(학습)

3~4차시 · Shallow/Deep 네트워크 구조, 손실함수, 경사하강법, 역전파.

2-1. Shallow 네트워크

입력층 - 은닉층 1개 - 출력층으로 구성. 단순 선형모델 대비 비선형 패턴 학습 가능.

$$y=\phi_0+\phi_1\mathrm a[\theta_{10}+\theta_{11}x]+\phi_2\mathrm a[\theta_{20}+\theta_{21}x]+\phi_3\mathrm a[\theta_{30}+\theta_{31}x]$$ $$h_d=\mathrm a[\theta_{d0}+\theta_{d1}x]\qquad \mathrm{ReLU}[z]=\max(0,z)$$
보편적 근사 정리(Universal Approximation Theorem): Hidden unit을 충분히 많이 가지면, 얕은(Shallow) 신경망도 임의의 연속함수를 임의의 정밀도로 근사할 수 있다.

2-2. Deep 네트워크 — "접기(folding)"

여러 네트워크를 합성(x→y→y')하면 훨씬 많은 조각별 선형 구역을 만든다. 층을 쌓는 것 = 공간을 접는 것. 같은 파라미터 수로 Deep이 Shallow보다 훨씬 많은 선형 구역을 표현(예: 파라미터 20개 Deep → 16구역, 19개 Shallow → 7구역).

일반 $K$층: $$\mathbf y=\boldsymbol\beta_K+\boldsymbol\Omega_K\,\mathrm a[\boldsymbol\beta_{K-1}+\boldsymbol\Omega_{K-1}\mathrm a[\cdots \mathrm a[\boldsymbol\beta_0+\boldsymbol\Omega_0\mathbf x]\cdots]]$$
가중치 행렬 $\boldsymbol\Omega_k$의 크기 규칙 = (다음 층 노드 수) × (현재 층 노드 수). 시험에 "행렬 크기 규칙" 문제로 자주 나옴.

2-3. 손실함수 & 학습

$$L[\boldsymbol\phi]=\sum_{i=1}^I(\mathrm f[x_i,\boldsymbol\phi]-y_i)^2 \qquad \hat{\boldsymbol\phi}=\underset{\boldsymbol\phi}{\operatorname{argmin}}\,L[\boldsymbol\phi]$$

손실함수 = 모델이 얼마나 잘못 예측하는지 측정. 값이 작을수록 좋다. 학습 = 손실함수를 최소화하는 파라미터를 찾는 과정.

2-4. 경사하강법 (Gradient Descent)

$$\boldsymbol\phi\leftarrow\boldsymbol\phi-\alpha\frac{\partial L}{\partial\boldsymbol\phi}\qquad(\alpha=\text{학습률})$$

기울기(=손실이 가장 빠르게 증가하는 방향)의 반대 방향으로 이동.

ConvexNon-convex
모양U자, 아래로 볼록봉우리·골짜기·안장점(saddle) 혼재
최적화전역 최소값 유일 → 쉬움지역 최소값 여러 개 → 시작점에 따라 결과 달라짐

확률적 경사하강법 (SGD)

$$\phi_{t+1}\leftarrow\phi_t-\alpha\sum_{i\in\mathcal B_t}\frac{\partial \ell_i[\phi_t]}{\partial\phi}$$
  • 전체 데이터 대신 무작위 미니배치 사용 → 스텝당 계산량↓
  • 노이즈가 있지만 평균적으로 올바른 방향 → local minima/saddle point 탈출에 유리
  • GD처럼 매끈하지 않고 지그재그(진동)하며 수렴
SGD의 장점 이유는 "계산량 감소"뿐 아니라 노이즈로 인한 지역 최소점 탈출 용이도 함께 기억할 것.

2-5. 역전파 (Backpropagation)

출력 오차를 기준으로 그래프를 거꾸로 따라가며 연쇄법칙(chain rule)으로 각 노드(파라미터)의 미분값을 계산.

$$\frac{\partial\ell_i}{\partial\boldsymbol\Omega_k}=\frac{\partial\ell_i}{\partial\mathbf f_k}\mathbf h_k^\top\qquad \frac{\partial\ell_i}{\partial\boldsymbol\beta_k}=\frac{\partial\ell_i}{\partial\mathbf f_k} $$

순서: ① 순전파(forward)로 각 층 값 계산 → ② 역전파(backward)로 출력 손실에 대한 각 층 미분 계산 → ③ 파라미터에 대한 미분 계산.

한 장 요약

선형회귀(직선, RSS 최소화, closed-form) → 다중선형회귀(초평면, 다중공선성 주의) → 로지스틱회귀(시그모이드로 확률, MLE로 추정) → Shallow 신경망(ReLU 조각별 선형, 보편적 근사) → Deep 신경망(접기, 같은 파라미터로 표현력↑) → 학습(손실 최소화 = argmin L, 경사하강 = 반대방향 이동, SGD = 미니배치, 역전파 = 연쇄법칙으로 뒤에서부터 미분).

분류 평가지표

예측 0예측 1
실제 0TNFP (과검출)
실제 1FN (미검출)TP
$$\text{Accuracy}=\frac{TP+TN}{TP+TN+FP+FN}\qquad\text{Precision}=\frac{TP}{TP+FP}\qquad\text{Recall}=\frac{TP}{TP+FN}$$ $$F_1=2\cdot\frac{P\cdot R}{P+R}$$

Precision=1이라 예측한 것 중 진짜 1 비율(과검출 FP에 민감) / Recall=진짜 1 중 찾아낸 비율(미검출 FN에 민감) / F1=조화평균, 클래스 불균형에서 accuracy보다 신뢰.

불균형 데이터에서 accuracy만 보면 소수 클래스를 다 틀려도 높게 나올 수 있음 → F1/ROC-AUC 병행 필요.

ROC-AUC

$\text{TPR}=\text{Recall}$, $\text{FPR}=FP/(FP+TN)$의 곡선. AUC: 0.5=무작위, 1.0=완벽. 임계값을 정하지 않고 모델의 순위 매기기 능력을 평가.

회귀 평가지표

$$\text{RMSE}=\sqrt{\tfrac1n\sum(y_i-\hat y_i)^2}\qquad \text{MAE}=\tfrac1n\sum|y_i-\hat y_i|\qquad R^2=1-\frac{\sum(y_i-\hat y_i)^2}{\sum(y_i-\bar y)^2}$$

RMSE: 큰 오차(이상치)에 민감 / MAE: 이상치에 덜 민감 / $R^2$: 설명력, 평균 예측보다 나쁘면 음수도 가능(무단위).

4 CNN 완전정리

FCN의 한계 → 합성곱 기초 → AlexNet → VGGNet → ResNet → MobileNet.

4-1. FCN vs CNN

FCN(이미지를 1차원으로 Flatten)의 3가지 문제: ① 파라미터 폭발(224×224 이미지 첫층만 150만개↑) ② 공간 구조 파괴(이웃 픽셀 관계 소실) ③ 위치 의존(객체 위치 바뀌면 다른 입력으로 인식)

합성곱(Convolution): 입력을 3차원 구조 그대로 유지하며 필터와 내적 반복 → 특징맵(feature map) 생성. 필터 깊이는 항상 입력 채널 수와 동일. 같은 필터를 전체 이미지에 재사용 = 파라미터 공유(weight sharing).

4-2. 핵심 공식 (★ 반드시 암기)

항목공식
출력 해상도$W'=\dfrac{W-K+2P}{S}+1$
출력 채널 수= 필터(커널) 개수 $C_{out}$
파라미터 수$C_{out}\times C_{in}\times K^2 + C_{out}$(바이어스)
메모리(활성)$C_{out}\times H'\times W'\times4$Byte
FLOPs$(H'\times W')\times(C_{in}\times K^2\times C_{out})$
same 패딩$P=(K-1)/2$ (홀수 커널)
예) AlexNet Conv1: 입력 227, K=11, S=4, P=0 → $W'=\frac{227-11}{4}+1=55$. 파라미터 $96\times3\times11^2+96=34{,}944$.

세 그래프가 말하는 것: 메모리는 초기(고해상도) 레이어에 집중, 파라미터는 FC 레이어에 집중, FLOPs는 합성곱에서 주로 발생.

4-3. 비선형 & 수용영역 & 다운샘플링

Conv만 계속 쌓고 ReLU 없으면 $W_{all}=W_3W_2W_1$로 뭉개져 결국 하나의 선형 변환과 같아짐 → 표현력이 늘지 않음. 반드시 Conv→ReLU 쌍으로 쌓아야 깊이가 의미를 가짐.

수용영역(Receptive Field) = 출력 한 칸이 원본 입력에서 참조하는 영역(네트워크의 시야). 층이 깊을수록 넓어짐.

$$j_k=j_{k-1}\cdot S_k,\qquad R_k=R_{k-1}+(K_k-1)j_{k-1}\quad(R_0=1,j_0=1)$$ 3×3 stride1을 $n$번 쌓으면 $R=2n+1$
방법학습 파라미터정보 손실비고
Max/Avg Pooling없음상대적으로 큼단순·빠름, 위치 강건성
Strided Conv있음(커널 학습)적음풀링+합성곱을 한 레이어로

맥스풀링: 영역 내 최댓값 선택, 학습 파라미터 없음. 해상도↓ → 연산량↓, 위치변화 강건성↑.

AlexNet (2012)

5개 Conv + 3개 FC = 8계층. 입력 227×227×3 → 227→55→27→13→6→9216→4096→4096→1000(Softmax). Overlapping Pooling(3×3, stride2) 사용.

VGGNet (2014) — 디자인 룰 3줄

  1. 3×3 합성곱 / 스트라이드1 / 패딩1 반복
  2. 맥스풀링(2×2)으로 크기 축소
  3. 풀링 후 채널 크기 2배
3×3 두 개 vs 5×5 하나: 수용영역 동일하지만 파라미터 $18C^2$ vs $25C^2$(28% 절감), ReLU는 2번(표현력↑). VGG는 AlexNet보다 메모리·파라미터·연산량 모두 크지만 Top-5 에러는 더 낮음(성능은 더 좋음).

ResNet (2015)

Degradation Problem: 층을 깊게(56층)했더니 훈련 오차까지 20층보다 나빠지는 현상 → 과적합이 아니라 최적화 실패.
$$\text{Output}=F(x)+x\qquad \frac{\partial y}{\partial x}=\frac{\partial F(x)}{\partial x}+1$$

학습이 안 되면 $F(x)\approx0$ → 출력=입력(최소 성능 보장). "+1"이 곱셈 사슬 중에도 보존되어 152층 학습 가능.

보틀넥 구조: 1×1(채널 축소, 4C→C) → 3×3(C→C) → 1×1(채널 복원, C→4C). FLOPs $17HWC^2$ (일반 잔차블록 $18HWC^2$보다 적음). 전역평균풀링(GAP)이 FC 대체 → 파라미터 대폭 감소(ResNet-50이 VGG-16보다 깊은데 파라미터는 1/5).

MobileNet — 경량화

공간(H×W)과 채널(C)을 분리 처리: 깊이별 합성곱(Depthwise, 채널별 독립 3×3) + 화소별 합성곱(Pointwise, 1×1로 채널 조합).

$$\text{절감 비율}=\frac{9C^2HW}{9CHW+C^2HW}=\frac{9C}{9+C}\xrightarrow[C\to\infty]{}9\ (=K^2)$$

5 RNN · LSTM · 어텐션 · ViT

CNN의 한계(순서 무시, 장거리 의존성) → RNN → LSTM → Attention → ViT.

CNN의 두 가지 한계: ① 순서 무시(텍스트·음성처럼 순서가 의미를 바꾸는 데이터 반영 못함) ② 긴 거리 의존성 부족(수용영역을 깊이 쌓아야 겨우 반영).

5-1. RNN

$$h_t=f_W(h_{t-1},x_t)\qquad h_t=\tanh(W_{hh}h_{t-1}+W_{xh}x_t)\qquad y_t=W_{hy}h_t$$

모든 시점에서 동일한 가중치 $W$ 재사용(파라미터 효율 + 가변 길이 입력 처리가 진짜 이유).

구조예시
One-to-One이미지 분류
One-to-Many이미지 캡셔닝
Many-to-One감정 분류
Many-to-Many기계번역
기울기 소실/폭발: 역전파 시 같은 가중치 $W$가 시퀀스 길이만큼 반복 곱해짐. $|W|$ 특이값 <1 → 소실, >1 → 폭발. Clipping은 폭발만 완화하는 임시방편이며 소실 문제는 해결 못함 → LSTM 필요.

5-2. LSTM (1997)

셀 상태(Cell State, $c_t$)=장기정보 / 은닉 상태(Hidden State, $h_t$)=단기정보.

$$f_t=\sigma(W_f[h_{t-1},x_t]+b_f)\quad\text{(forget)}\qquad i_t=\sigma(W_i[h_{t-1},x_t]+b_i)\quad\text{(input)}$$ $$c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t\qquad h_t=o_t\odot\tanh(c_t)$$
게이트역할
입력 게이트(i)새 정보를 얼마나 저장할지
망각 게이트(f)과거 정보를 얼마나 버릴지
출력 게이트(o)셀 상태를 얼마나 은닉상태로 낼지
$c_t=f\odot c_{t-1}+i\odot g$의 덧셈 경로가 기울기를 장기 보존하는 핵심(곱셈만 있으면 소실).

5-3. 어텐션 메커니즘

$$q=xW_q,\ k=xW_k,\ v=xW_v\qquad a_{ij}=\mathrm{softmax}(q_i\cdot k_j/\sqrt D)\qquad y_j=\sum_i a_{ij}v_i$$ $$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

교차 어텐션(Cross-Attention): 이종 데이터 간(예: 이미지-텍스트) Q/K/V를 각각 다른 소스에서 정의.

5-4. Vision Transformer (ViT)

이미지를 패치로 분할 → 위치 인코딩 추가 → 토큰 시퀀스로 변환 → (정규화 → 다중헤드어텐션 → 정규화 → MLP)를 12개 이상 반복.

CNN은 수용영역을 넓혀가며 전역을 이해 / ViT는 어텐션 한 번으로 전역 맥락 이해(수용영역 확장 불필요).
강점약점
CNN지역적 특성장거리 맥락 어려움, 순서 반영 불가
RNN순서 반영장거리 맥락 학습 어려움(기울기 소실/폭발)
LSTM순서+장거리 맥락정보 희석 문제
Attention장거리 맥락 탁월순서 정보 없음→위치인코딩 필요
ViT는 CNN 같은 귀납적 편향(inductive bias)이 없어 정규화·데이터 증강이 매우 중요. 데이터가 적으면 CNN보다 성능이 떨어질 수 있음(항상 CNN보다 좋은 것 아님).

트렌드: Swin Transformer(윈도우 단위 어텐션), DINOv2(자기지도 백본), ViT-22B, EVA-CLIP, InternImage-H.

7 자연어처리 (1) — 임베딩부터 Seq2Seq까지

7-1. 원-핫 인코딩 vs 워드 임베딩

원-핫 벡터는 서로 다른 단어끼리 항상 직교(내적=0) → 유사도 측정 불가. 차원의 저주(희소·고차원) + 의미 정보 부족.

워드 임베딩: 단어를 밀집(dense)·연속·분산 벡터로 표현, 의미적으로 가까운 단어가 공간상 가깝게 위치. Distributional hypothesis: "You shall know a word by the company it keeps."

Word2Vec (Google, 2013)

예측 방향장점한계
Skip-gram중심 단어 → 주변 단어들적은 데이터에도 동작, 희귀 단어에 강함학습 느림
CBOW주변 단어들 → 중심 단어학습 빠름, 빈출 단어에 강함희귀 단어에 약함
같은 문장에서 CBOW는 학습 예시 1개, Skip-gram은 여러 개(윈도우만큼) 생성 — 이게 속도 vs 희귀단어 트레이드오프의 원인.

7-2. 순차적 데이터 & RNN

순차 데이터 3특징: 순서 중요 / 장기 의존성 / 가변 길이. MLP/CNN(고정 길이 입력)으로는 처리 부적합 → RNN 필요.

7-3. 언어모델 & N-gram

$$p(w_1,\dots,w_N)=p(w_1)p(w_2|w_1)\cdots p(w_N|w_1,\dots,w_{N-1})$$

4-gram 예: $P(w\mid\text{students opened their})=\dfrac{count(\text{students opened their }w)}{count(\text{students opened their})}$

$n$을 키우면 정교해지지만 본 적 없는 조합이 급증(희소성 문제) → 저장공간도 지수적 증가. 이 한계가 신경망 언어모델의 등장 배경.

SMT(통계적 기계번역): $\operatorname{argmax}_y P(x|y)P(y)$ = 번역모델×언어모델(베이즈 규칙). 구조 복잡·수작업多 → NMT로 대체.

7-4. Seq2Seq

2014년 NMT 등장. 두 개의 RNN(Encoder-Decoder): Encoder는 입력을 고정차원 벡터로 요약, Decoder는 그 벡터로부터 출력 시퀀스 생성. 입력·출력 길이가 달라도 처리 가능.

Teacher Forcing: 학습 시 디코더 입력에 모델 예측 대신 정답 토큰을 강제로 넣음(안정적·빠른 학습). 단, 추론 시엔 자기 예측을 입력으로 쓰므로 학습-추론 불일치(exposure bias) 발생 가능.

7-5. Attention (Seq2Seq)

Bottleneck Problem: 인코더 마지막 hidden state 하나에 문장 전체 의미를 압축 → 정보 손실. Attention이 이를 해결: 디코더가 매 스텝 인코더 전체 hidden state 중 필요한 부분에 직접 접근.
$$a_t=\sum_i\alpha_i^t h_i$$

효과: ① NMT 성능향상 ② Bottleneck 해결 ③ 기울기소실 완화(먼 단어도 직접 연결) ④ 해석가능성(정렬/alignment).

Score 계산: Dot product $h^Ts$ / Multiplicative $h^TWs$ / Additive $v^T\tanh(W_hh+W_ss)$.

8-1. RNN의 두 한계 & Self-Attention

8-3. Transformer 구조 (Vaswani et al., 2017)

Multi-Head Attention: 단일 head는 한 관점만 파악 → 여러 head로 문법적 관계/시제/명사 등 다양한 관점 동시 파악. 단, head 수 늘리면 head당 차원($d/h$)이 줄어드는 트레이드오프 존재 — 무한정 늘린다고 좋아지지 않음(중복 헤드 발생).
$$\text{Scaled Dot Product: } \mathrm{softmax}\!\left(\frac{XQK^TX^T}{\sqrt{d/h}}\right)XV$$

스케일링 이유: Q·K 차원 커지면 내적값도 커져 softmax가 지나치게 뾰족해짐(gradient vanishing 위험) → $\sqrt{d_k}$로 나눠 분포를 완만하게.

Residual Connection: $X^{(i)}=X^{(i-1)}+\text{Layer}(X^{(i-1)})$, 깊은 층 학습 안정화. Layer Normalization: 층별 값 정규화.

블록구성특징
EncoderSelf-Attention(마스킹 없음) → Add&Norm → FFN → Add&Norm양방향 문맥
DecoderMasked Self-Attention → Cross-Attention → FFN (각각 Add&Norm)단방향 문맥(언어모델처럼)

Cross-Attention: Query는 디코더, Key·Value는 인코더에서.

Transformer의 결과: NMT 최고성능 + 가장 효율적 학습(같은/더 나은 BLEU를 훨씬 적은 FLOPs로 달성) → 병렬처리 능력 덕분에 대규모 사전학습의 표준 아키텍처로 자리잡음.

9 사전학습 기반 언어 모델

Encoder(BERT) · Encoder-Decoder(T5) · Decoder(GPT) · In-Context Learning.

사전학습(Pretraining): 대규모 데이터로 일반적 표현을 학습하는 과정 = 자기지도학습(self-supervised). "다음 단어 예측"은 정답이 있지만(형식상 지도학습과 동일) 그 정답을 사람 개입 없이 데이터에서 공짜로 만들 수 있어 비지도로 분류.

워드 임베딩은 임베딩층만 사전학습(그 위는 무작위 초기화) vs 언어모델은 모델 전체를 함께 사전학습.

9-1. Encoder — BERT (2018)

Masked Language Model(MLM): 입력 토큰의 15% 무작위 선택 → 그중 [MASK] 80% / 랜덤토큰 10% / 그대로 10%(단, 셋 다 예측 대상).

80/10/10 규칙의 이유: 100% [MASK]로만 하면 실제 사용(파인튜닝)때 [MASK]가 없어 문제(pretrain-finetune discrepancy). 10% 랜덤/10% 그대로 두어 모델이 항상 문맥을 반영하게 만듦.

NSP(Next Sentence Prediction): 두 번째 문장이 첫 문장의 실제 다음 문장인지 예측. 입력 = Token+Segment+Position Embeddings.

[CLS]→NSP/분류용, 나머지 토큰→MLM/토큰레벨용. BERT의 한계: 생성 태스크에 부적합(양방향이라 autoregressive 생성이 자연스럽지 않음).

9-2. Encoder-Decoder — T5 (2019)

모든 태스크를 Text-to-Text로 통일. 학습 방법 = Span Corruption: 연속된 토큰(span)을 무작위 제거 → placeholder(⟨X⟩,⟨Y⟩) 치환 → 디코더가 원래 span 복원.

BERT는 단어 하나씩 마스킹 vs T5는 연속 구간(span)을 통째로 제거 → 더 긴 문맥·구 단위 의미 필요, 출력 길이도 가변적(언제 멈출지도 학습) = 생성 능력.

결과: Encoder-decoder + Denoising(Span Corruption) 조합이 Language model 구조보다 일관되게 우수.

9-3. Decoder — GPT

GPT-1: Decoder 12개 블록, Autoregressive LM(다음 단어 예측)으로 사전학습. 분류 태스크는 [START]/[DELIM]/[EXTRACT] 특수토큰으로 입력을 한 줄로 이어붙여 처리.

같은 시기 BERT(82.1)가 GPT-1(75.1)보다 GLUE 점수 높았음에도 오늘날 큰 모델은 대부분 Decoder-only인 이유: 모든 태스크를 "다음 단어 예측" 하나의 형식으로 표현 가능 + 사전학습=사용 방식 동일(파인튜닝 불필요) + In-Context Learning 창발.

9-4. In-Context Learning (GPT-3, 2020)

175B로 파라미터를 키우자 파인튜닝 없이 프롬프트의 예시만으로 새 태스크 수행 가능해짐(가중치 갱신 없음).

방식구성
Zero-shot태스크 설명만
One-shot설명+예시 1개
Few-shot설명+예시 여러 개

모델이 클수록(175B) 효과 뚜렷, 작은 모델(1.3B)은 거의 발현 안 됨 → 창발성의 예.

Chain-of-Thought (CoT)

예시에 추론 과정도 포함 → 정확도 대폭 상승. 모델이 클수록 CoT 효과가 커짐(PaLM 540B: standard 18% → CoT 57%).

Zero-shot CoT: "Let's think step by step." 한 문장 추가만으로 예시 없이도 추론 성능 향상(MultiArith 17.7%→78.7%). 이 능력도 모델 크기 임계점을 넘어야 나타남.

11-2. CLIP (2021, OpenAI)

대조 학습(Contrastive Pre-training) 기반. 4억 개 이미지-텍스트 쌍. 텍스트 인코더=Transformer, 이미지 인코더=ViT-B(또는 ResNet50).

$$L_{CLIP}=-\frac1N\sum_i\log\frac{e^{s_{ii}/\tau}}{\sum_j e^{s_{ij}/\tau}}\ (\text{Image→Text})\ +\ -\frac1N\sum_j\log\frac{e^{s_{ij}/\tau}}{\sum_i e^{s_{ij}/\tau}}\ (\text{Text→Image}) $$

목표 이미지(앵커)를 대응 텍스트(양성)와 가깝게, 무관한 텍스트(음성)와 멀게. 제로샷 이미지 인식: 텍스트 카테고리를 임베딩→쿼리 이미지와 비교→최고점 카테고리 반환.

SigLIP (2023)

CLIP(Softmax 대조학습) 한계: 이미 먼 음성쌍도 계속 거리를 벌리려 해 비효율. SigLIP은 Sigmoid 기반 손실로 음성쌍 영향을 제한적으로 만듦 → 특히 노이즈 많은 데이터에서 CLIP보다 압도적 성능.

멀티모달 정합(Alignment) 손실: CLIP loss(사전학습된 CLIP 활용, 코사인 유사도 직접 비교) vs SDS loss(diffusion U-Net 활용, Text-to-3D 등).

11-3. VLM (Vision-Language Model)

LLaVA(2023): Vision Encoder→Projection W→언어모델. 2단계 학습(①Projection layer만 학습 ②필요 부분 파인튜닝). Qwen-VL: 3단계 파이프라인(Pretraining→Multi-task Pretraining→SFT), M-RoPE(1D텍스트/2D시각/3D비디오 위치정보 통합).

도메인 특화: MedCLIP·LLaVA-Med(의료), AnomalyGPT(제조업), 3D-LLM(3D).

Small VLM: SmolVLM(SigLIP+SmolLM2), Moondream 0.5B(양자화로 경량화), Gemini Nano(온디바이스). 한국어: HyperCLOVAX(NAVER), Kanana(Kakao).

11-4. 세그멘테이션 & 탐지

SAM(2023)/SAM2(2024): 클릭/박스/텍스트 등 다양한 입력으로 마스크 추출, 1100만개 이미지(10억개 마스크) 학습. Grounding DINO: 텍스트로 물체 탐지. Grounded SAM=Grounding DINO+SAM 결합(탐지+분할 동시). SAMURAI: SAM2 기반 비주얼 트래킹.

11-5. 이미지/3D/비디오 생성

Diffusion Model: Forward(노이즈 추가) / Backward(노이즈 제거, 노이즈 예측 문제로 학습). LDM(Latent Diffusion Model, Stable Diffusion): 저차원 latent에서 diffusion 수행 → 효율+품질↑.

11-6. Fine-tuning & PEFT

Fine-tuning사전학습 모델을 소규모 데이터로 추가 학습(가중치 변경)

Learning Rate: 너무 낮으면 local minimum에 갇힘, 너무 높으면 global minimum 근처에서 못 맞춤. 파인튜닝은 작은 LR부터 보수적으로.

Prompt Tuning(2021): 가상 토큰(virtual token)의 임베딩만 학습, 본체는 고정(freeze) → 지식 손실 없음. Adapter: 레이어마다 작은 학습가능 모듈 삽입. DreamBooth: 소수(3~5장) 이미지+고유식별자([V])로 개인화 T2I 모델 학습.

11-7. 합성 데이터

Knowledge Distillation: Teacher(고성능 무거운 모델)의 soft-label을 Student(가벼운 모델)가 모방. InstructPix2Pix: GPT-3로 지시+캡션 45만개 생성 → Stable Diffusion+Prompt2Prompt로 이미지쌍 생성 → 명령 기반 이미지 편집 모델 학습.

합성데이터 유의점: 라벨 품질 불일치(같은 객체도 표현이 다를 수 있음), 할루시네이션(존재하지 않는 객체/특징 생성).

11-8. AGI를 향해서

인지(Cognition)=지각(Perception)∪고차인지. RAG: 유연성(최신정보)+개인화+정확성(환각 감소). Visual Programming(VISPROG): GPT-3가 자연어→프로그램(코드) 생성→인터프리터가 실제 실행(Loc/Seg/VQA 등 Python API 조합).
