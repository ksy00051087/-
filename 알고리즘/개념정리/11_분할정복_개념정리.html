1-2분할 정복의 예시 — 거듭 제곱 (Exponentiation)


  • 반복(Iterative) 알고리즘: Cⁿ = C × C × … × C → O(n)
  • 분할 정복 기반의 알고리즘: Cⁿ = C^(n/2) × C^(n/2) (n이 짝수), C^((n-1)/2) × C^((n-1)/2) × C (n이 홀수) → O(log n)
Recursive_Power(x, n)
    IF n == 1 : RETURN x
    IF n is even
        y ← Recursive_Power(x, n/2)
        RETURN y * y
    ELSE
        y ← Recursive_Power(x, (n-1)/2)
        RETURN y * y * x

2-1병합 정렬이란?


  • 여러 개의 정렬된 자료의 집합을 병합하여 한 개의 정렬된 집합으로 만드는 방식
  • 분할 정복 알고리즘 활용 — 자료를 최소 단위의 문제까지 나눈 후에 차례대로 정렬하여 최종 결과를 얻어냄
  • top-down 방식
  • 시간 복잡도: O(n log n)
병합 정렬 과정 — {69, 10, 30, 2, 16, 8, 31, 22}를 병합 정렬하는 과정
분할 단계 : 전체 자료 집합에 대하여, 최소 크기의 부분집합이 될 때까지 분할 작업을 계속한다.
[69 10 30 2 16 8 31 22]
[69 10 30 2] [16 8 31 22]
[69 10] [30 2] [16 8] [31 22]
[69] [10] [30] [2] [16] [8] [31] [22]

병합 단계 : 2개의 부분집합을 정렬하면서 하나의 집합으로 병합한다. 8개의 부분집합이 1개로 병합될 때까지 반복
[10 69] [2 30] [8 16] [22 31]
[2 10 30 69] [8 16 22 31]
[2 8 10 16 22 30 31 69]






2-2병합 정렬 알고리즘


merge_sort(LIST m)
    IF length(m) == 1 : RETURN m
    LIST left, right
    middle ← length(m) / 2
    FOR x in m before middle : add x to left
    FOR x in m after or equal middle : add x to right
    left ← merge_sort(left)
    right ← merge_sort(right)
    RETURN merge(left, right)

merge(LIST left, LIST right)
    LIST result
    WHILE length(left) > 0 OR length(right) > 0
        IF length(left) > 0 AND length(right) > 0
            IF first(left) <= first(right)
                append popfirst(left) to result
            ELSE
                append popfirst(right) to result
        ELIF length(left) > 0
            append popfirst(left) to result
        ELIF length(right) > 0
            append popfirst(right) to result
    RETURN result
pop(0)은 O(n)이므로 실제 구현에서는 인덱스(i, j)를 움직이며 병합합니다. 병합 정렬은 병합할 때 임시 배열을 사용합니다 → 추가 메모리 필요(제자리 정렬이 아님).

퀵 정렬 (Quick Sort)
개념 · 병합 정렬과의 차이 · Pivot · 파티셔닝 과정 · Hoare · Lomuto · 시간 복잡도

  




3-1퀵 정렬이란?


  • 주어진 배열을 두 개로 분할하고, 각각을 정렬한다.
  • 병합 정렬과 다른 점 — ① 병합 정렬은 그냥 두 부분으로 나누는 반면에, 퀵 정렬은 분할할 때, 기준 아이템(pivot item) 중심으로, 이보다 작은 것은 왼편, 큰 것은 오른편에 위치시킨다. ② 각 부분 정렬이 끝난 후, 병합 정렬은 "병합"이란 후처리 작업이 필요하나, 퀵 정렬은 필요로 하지 않는다.
Pivot을 기준으로 파티셔닝
  • 작업 영역을 정하고, 작업 영역 중 가장 왼쪽에 있는 수를 Pivot이라고 하자.
  • 파티셔닝 — Pivot을 기준으로 왼쪽에는 Pivot 보다 작은 수를 배치, 오른쪽에는 Pivot 보다 큰 수를 배치합니다.
  • 파티셔닝이 끝나면 Pivot의 위치는 확정(Fix)된다 — 즉, 정렬이 다 되었을 때에도 Pivot의 위치는 지금 위치 그대로 배정됩니다.
  • 한 번의 파티셔닝 이후, 왼쪽과 오른쪽 부분 배열에 대해 재귀적으로 파티셔닝을 반복하여 정렬을 진행합니다.
  • 작업 영역에 혼자이면 해당 값이 Fix가 되고 바로 파티셔닝이 종료된다.






3-2Pivot 선택 방법과 파티션 알고리즘


  • 왼쪽 끝 / 오른쪽 끝 / 임의의 값 / 왼쪽 끝·오른쪽 끝·가운데 세 값 중에 중간 값(median of three)을 선택하는 경우
  • 대표적인 파티셔닝 방법: Hoare-Partition 알고리즘, Lomuto-Partition 알고리즘
Hoare-Partition(A[], l, r)
    p ← A[l]       // p: 피봇 값
    i ← l, j ← r
    WHILE i <= j
        WHILE i <= j and A[i] <= p : i++
        WHILE i <= j and A[j] >= p : j--
        IF i < j : swap(A[i], A[j])
    swap(A[l], A[j])
    RETURN j

Lomuto-Partition(A[], l, r)
    p ← A[r]
    i ← l - 1
    FOR j in range(l, r)
        IF A[j] <= p
            i++, swap(A[i], A[j])
    swap(A[i+1], A[r])
    RETURN i+1

4-2이진 검색


  • 자료의 가운데에 있는 항목의 키 값과 비교하여 다음 검색의 위치를 결정하고 검색을 계속 진행하는 방법 — 목적 키를 찾을 때까지 이진 검색을 순환적으로 반복 수행함으로써 검색 범위를 반으로 줄여가면서 보다 빠르게 검색을 수행함
  • 이진 검색을 하기 위해서는 자료가 정렬된 상태여야 한다.
  • 검색 과정: 자료의 중앙에 있는 원소를 고른다 → 중앙 원소의 값과 찾고자 하는 목표 값을 비교한다 → 목표 값이 중앙 원소의 값보다 작으면 자료의 왼쪽 반에 대해서 새로 검색을 수행하고, 크다면 자료의 오른쪽 반에 대해서 새로 검색을 수행한다 → 찾고자 하는 값을 찾을 때까지 반복한다.
  • 재귀 호출이 끝나는 조건: 중간값이 찾는 값과 같거나(성공) 시작 인덱스가 끝 인덱스보다 큰 경우(low > high, 탐색 실패)

4-4분할 정복의 활용


  • 병합 정렬은 외부 정렬(External Sort)의 기본이 되는 정렬 알고리즘 입니다. (메모리에 다 올릴 수 없는 매우 큰 데이터를 나눠서 정렬 후 병합)
  • 멀티코어(Multi-Core) CPU나 다수의 프로세서에서 정렬 알고리즘을 병렬화 하기 위해 병합 정렬 알고리즘이 활용됩니다.
  • 퀵 정렬은 매우 큰 입력 데이터에 대해서 좋은 성능을 보이는 알고리즘입니다.
  • 이진 검색은 정렬된 데이터에서 값을 찾는 것뿐 아니라, 답의 범위를 반씩 줄이는 매개 변수 탐색에도 활용됩니다.

11. 이진 검색에서 low > high 가 되면?
정답: 탐색 실패 (찾는 값 없음) — 탐색 범위가 역전되면 탐색 대상이 사라졌음을 의미합니다.
12. 병합 정렬에 대한 설명으로 틀린 것은?
  1. O(n log n)이다
  2. 분할 정복이다
  3. 안정 정렬이다
  4. 제자리 정렬이다
정답: 제자리 정렬이다 — 병합 정렬은 추가 배열을 사용하므로 제자리(in-place) 정렬이 아닙니다.

핵심 키워드


키워드설명
분할 정복분할(Divide) → 정복(Conquer) → 통합(Combine)
거듭 제곱Cⁿ = C^(n/2) · C^(n/2) — O(log n)
병합 정렬반으로 나누고, 정렬하며 병합 — 항상 O(n log n), 임시 배열 필요, 외부 정렬의 기본
퀵 정렬피봇 기준으로 작은 값/큰 값 분할, 병합 불필요 — 평균 O(n log n), 최악 O(n²)
Hoare · Lomuto 파티션양쪽에서 좁혀오며 교환 / 한쪽에서 작은 값을 앞으로 모음
이진 검색정렬된 자료에서 중간값과 비교해 범위를 반씩 — O(log n)






이 문서의 큰 줄기


  • 큰 문제를 같은 모양의 작은 문제로 쪼갤 수 있으면 분할 정복을 떠올린다.
  • 병합 정렬은 "나누기는 쉽고 합치기가 일", 퀵 정렬은 "나누기가 일이고 합칠 필요 없음".
  • 절반씩 줄이면 log n — 거듭 제곱, 이진 검색, 가짜 동전 찾기가 모두 같은 원리.
