그래프 기본

정의 · 최대 간선 수 · 유형 · 인접 · 경로 · 사이클

1-1그래프

  • 그래프는 아이템(사물 또는 추상적 개념)들과 이들 사이의 연결 관계를 표현한다.
  • 정점(Vertex)들의 집합과 이들을 연결하는 간선(Edge)들의 집합으로 구성된 자료 구조 — |V| : 정점의 개수, |E| : 그래프에 포함된 간선의 개수
  • |V| 개의 정점을 가지는 그래프는 최대 |V|(|V| - 1) / 2개의 간선을 가질 수 있습니다. 예) 5개 정점이 있는 그래프의 최대 간선 수는 10(= 5*4/2)개 입니다.
  • 선형 자료구조나 트리 자료구조로 표현하기 어려운 N:N 관계를 가지는 원소들을 표현하기에 용이하다.

1-2그래프 유형

유형설명
무향 그래프 (Undirected Graph)간선에 방향이 없음
유향 그래프 (Directed Graph)간선에 방향이 있음
가중치 그래프 (Weighted Graph)간선에 비용(가중치)이 있음
사이클 없는 방향 그래프 (DAG, Directed Acyclic Graph)방향성 비순환 그래프
완전 그래프정점들에 대해 가능한 모든 간선들을 가진 그래프
부분 그래프원래 그래프에서 일부의 정점이나 간선을 제외한 그래프

1-3인접 (Adjacency) · 경로 · 사이클

  • 두 개의 정점에 간선이 존재(연결됨)하면 서로 인접해 있다고 한다.
  • 완전 그래프에 속한 임의의 두 정점들은 모두 인접해 있다.
  • 경로란 간선들을 순서대로 나열한 것 — 간선들: (0, 2), (2, 4), (4, 6) / 정점들: 0 - 2 - 4 - 6
  • 경로 중 한 정점을 최대한 한번만 지나는 경로를 단순경로라 한다.
  • 시작한 정점에서 끝나는 경로를 사이클(Cycle)이라고 한다. 예) 1 - 3 - 5 - 1

그래프 표현

인접 행렬 · 인접 리스트 · 간선 배열 · 장단점

2-1그래프 표현 방법

  • 간선의 정보를 저장하는 방식, 메모리나 성능을 고려해서 결정
  • 인접 행렬 (Adjacent matrix): |V| × |V| 크기의 2차원 배열을 이용해서 간선 정보를 저장 — 배열의 배열(포인터 배열). 두 정점을 연결하는 간선의 유무를 행렬로 표현: 행 번호와 열 번호는 그래프의 정점에 대응, 두 정점이 인접되어 있으면 1, 그렇지 않으면 0으로 표현. 무향 그래프: i번째 행의 합 = i번째 열의 합 = Vi의 차수. 유향 그래프: 행 i의 합 = Vi의 진출 차수, 열 i의 합 = Vi의 진입 차수
  • 인접 리스트 (Adjacent List): 각 정점마다 해당 정점으로 나가는 간선의 정보를 저장 — 각 정점에 대한 인접 정점들을 순차적으로 표현. 하나의 정점에 대한 인접 정점들을 각각 노드로 하는 연결 리스트로 저장. 무향 그래프의 인접 리스트 노드 수 = 간선의 수 × 2
  • 간선의 배열: 간선(시작 정점, 끝 정점)을 배열에 연속적으로 저장
인접 행렬인접 리스트
메모리O(V²) — 희소 그래프일 경우 불필요한 메모리 낭비가 발생O(V + E) — 메모리 효율적
두 정점 간선 유무 확인O(1) — 빠르다O(정점 차수)
한 정점의 인접 정점 모두 찾기O(V)O(차수)

3-1그래프 순회(탐색)


  • 그래프 순회는 비선형구조인 그래프로 표현된 모든 자료(정점)를 빠짐없이 탐색하는 것을 의미한다.
  • 두 가지 방법: 깊이 우선 탐색(Depth First Search, DFS), 너비 우선 탐색(Breadth First Search, BFS)

서로소 집합 (Disjoint-sets)
개념 · 대표자 · 연산 · 연결 리스트 표현 · 트리 표현 · 문제점 · 경로 압축 · rank

  




4-1서로소 집합


  • 서로소 또는 상호배타 집합들은 서로 중복 포함된 원소가 없는 집합들이다. 다시 말해 교집합이 없다.
  • 집합에 속한 하나의 특정 멤버를 통해 각 집합들을 구분한다. 이를 대표자(representative)라 한다.
  • 상호배타 집합을 표현하는 방법: 연결 리스트, 트리
  • 하나의 집합(a disjoint set)을 하나의 트리로 표현함 — 자식 노드가 부모 노드를 가리키며 루트 노드가 대표자가 된다.
연산설명
Make-Set(x)유일한 멤버 x를 포함하는 새로운 집합을 생성하는 연산
Find-Set(x)x를 포함하는 집합을 찾는 연산 (대표자 반환)
Union(x, y)x와 y를 포함하는 두 집합을 통합하는 연산






4-2연결 리스트 · 트리 표현


  • 연결 리스트: 같은 집합의 원소들은 하나의 연결리스트로 관리한다. 연결리스트의 맨 앞의 원소를 집합의 대표 원소로 삼는다. 각 원소는 집합의 대표원소를 가리키는 링크를 갖는다.
  • 트리: 하나의 집합을 하나의 트리로 표현. 자식 노드가 부모 노드를 가리키며 루트 노드가 대표자. 배열 p[x]에 부모를 저장
Make-Set(x)
    p[x] ← x

Find-Set(x)
    IF x == p[x] : RETURN x
    ELSE : RETURN Find-Set(p[x])

Find-Set(x)   // 반복
    while x != p[x]
        x = p[x]
    return x

Union(x, y)
    p[Find-Set(y)] ← Find-Set(x)






4-3문제점과 효율을 높이는 방법


  • 문제점: 편향 트리가 되는 경우 Find_Set()에 시간이 오래 걸림 (O(n))
  • Rank를 이용한 Union: 각 노드는 자신을 루트로 하는 subtree의 높이를 랭크(Rank)라는 이름으로 저장한다. 두 집합을 합칠 때 rank가 낮은 집합을 rank가 높은 집합에 붙인다.
  • Path compression (경로 압축): Find-Set을 행하는 과정에서 만나는 모든 노드들이 직접 root를 가리키도록 포인터를 바꿔줍니다. — Find_set() 에서 찾아진 대표 원소로 각 원소의 대표 원소를 바꾸면 경로가 단축됨. Find_set 연산은 특정 노드에서 루트까지의 경로를 찾아가면서 노드의 부모 정보를 갱신한다.
Make_Set(x)
    p[x] ← x
    rank[x] ← 0

Find_Set(x)
    IF x != p[x]            // x가 루트가 아닌 경우
        p[x] ← Find_Set(p[x])   // 경로 압축
    RETURN p[x]

Union(x, y)
    Link(Find_Set(x), Find_Set(y))

Link(x, y)
    IF rank[x] > rank[y]    // rank는 트리의 높이
        p[y] ← x
    ELSE
        p[x] ← y
        IF rank[x] == rank[y]
            rank[y]++

그래프 기본과 탐색 확인문제


1. 그래프(Graph)의 구성 요소로 옳지 않은 것은?
  1. 정점(Vertex)
  2. 간선(Edge)
  3. 루트(Root)
  4. 가중치(Weight)
정답: 루트(Root) — 루트(Root)는 트리 자료구조에서만 사용하는 용어입니다.
2. 인접 행렬(Adjacency Matrix) 방식의 단점으로 옳은 것은?
  1. 희소 그래프일 경우 불필요한 메모리 낭비가 발생
  2. 정점의 차수를 쉽게 계산할 수 없음
  3. 간선 유무 확인이 느림
  4. 구현이 어렵다
정답: 희소 그래프일 경우 불필요한 메모리 낭비가 발생 — 인접 행렬은 간선이 적은 경우에도 모든 정점 쌍의 정보를 저장합니다.
3. DFS 탐색 중, 방문하지 않은 정점이 더 이상 없을 때 어떻게 하나요?
  1. 탐색을 처음부터 다시 시작한다
  2. 마지막에 방문했던 정점으로 되돌아간다.
  3. 전체 탐색을 중지한다.
  4. 인접한 모든 정점을 다시 방문한다
정답: 마지막에 방문했던 정점으로 되돌아간다. — 스택에서 이전 정점을 꺼내 되돌아갑니다.
4. 두 정점 간의 연결 여부를 2차원 배열로 표현한 그래프 저장 방식은 무엇인가요? (단답형)
정답: 인접 행렬 (Adjacency Matrix)
5. Union-Find에서 Find 연산을 최적화하기 위한 방법으로 옳은 것은?
  1. Sorting
  2. Path Compression
  3. Hashing
  4. Binary Search
정답: Path Compression — 경로 압축은 트리 높이를 줄여 탐색 속도를 빠르게 합니다.
6. 인접 행렬과 인접 리스트의 차이를 설명하시오. (서술형)
인접 행렬: 2차원 배열로 간선 정보를 저장 → 메모리 소모 큼, 간선 유무 확인 O(1)
인접 리스트: 연결 리스트로 간선 저장 → 메모리 효율적, 특정 간선 확인은 O(정점 차수)
7. 그래프에서 특정 정점과 직접 연결된 모든 정점을 무엇이라 하나요? (단답형)
정답: 인접 정점 (Adjacent vertices)
8. 다음 중 인접 행렬(Adjacency Matrix) 방식의 특징으로 옳은 것은?
  1. 희소 그래프에서 메모리를 절약할 수 있다.
  2. 인접한 정점을 찾는 데 O(1) 시간이 걸린다.
  3. 두 정점 사이 간선 유무 확인 속도가 빠르다.
  4. 간선을 추가할 때 복잡한 자료구조가 필요하다.
