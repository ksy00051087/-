2-1조합 — 서로 다른 n개의 원소 중 r개를 순서 없이 골라낸 것


  • 순열은 [A B]와 [B A]가 다르지만, 조합은 같은 것으로 본다.
  • 메모장에 모든 경우를 적으면서, 규칙을 찾아보면 — 뒤에 오는 원소는 항상 앞의 원소보다 "뒤의 인덱스"에서 고른다.
  • 그래서 코드에 start 파라미터를 추가하여 조합 소스코드를 완성한다.
def comb(cnt, start):
    if cnt == n:            # n개 다 골랐으면
        print(path)
        return
    for i in range(start, len(arr)):
        path.append(arr[i])
        comb(cnt + 1, i + 1)   # 다음은 i+1부터 고름
        path.pop()

3-1탐욕 알고리즘이란?


  • 결정을 해야 할 때마다 그 순간에 가장 좋다고 생각되는 것을 선택하면서 최종 해답에 도달하는 방법
  • 미래를 생각하지 않고, 과거의 선택을 번복하지 않는다 — "과거의 데이터를 이용하여 현재의 데이터를 만드는" DP와 다름
  • 여러 경우 중 하나를 결정해야 할 때마다 그 순간 최적이라고 생각되는 것을 선택해 나가는 방식으로 진행하여 최종적인 해답에 도달한다.
탐욕 기법이 적용 가능한 조건
조건의미
탐욕적 선택 속성 (greedy choice property)탐욕적 선택은 최적해로 갈 수 있음을 보여라 → 즉, 탐욕적 선택은 항상 안전하다.
최적 부분 구조 (optimal substructure)최적화 문제를 정형화하라 → 하나의 선택을 하면 풀어야 할 하나의 하위 문제가 남는다. 문제의 최적해가 하위 문제의 최적해로 구성되는 성질
그리디 알고리즘은 쉬워 보이나, 예외 없이 모든 경우가 맞는 규칙인지 아닌지 증명이 어렵습니다.






3-2동전 교환 문제 — 530원을 거슬러 주기 위해서 사용해야 하는 최소 동전의 수는?


  • 동전 교환 문제를 완전탐색으로 해결한다면? — 0원이 될 때까지 모든 경우를 다 구한다. (느리다)

  • 10, 50, 100, 500 처럼 모든 동전이 배수 관계인 경우 Greedy 적용 가능
  • 10, 50, 70 처럼 모든 동전이 배수 관계가 아닌 경우 Greedy 적용 불가 — 100원: Greedy는 70+10+10+10 = 4개, 최적은 50+50 = 2개

4-2Knapsack (배낭) 문제



도둑이 보물들이 있는 창고에 침입하였다. 도둑은 최대 30kg까지 짐을 담아갈 수 있다. 물건의 개수(N) 그리고 물건 별 무게(W)와 가격(P)이 주어질 때, 어떤 물건을 담아야 도둑이 최대 이득을 볼 수 있을지 구하시오.
물건무게가격kg당 가격
물건15kg50만원10만원
물건210kg60만원6만원
물건320kg140만원7만원
  • 0-1 Knapsack: 물건을 통째로 담거나 안 담거나. [도전] 이 문제를 Greedy로 접근해보자 — "kg당 가치가 높은 것"을 선택: 물건1(5) + 물건3(20) = 190만원, 25kg. 하지만 정답은 물건2, 3을 선택하는 것(200만원)이다 → kg당 가치가 높은 것을 선택하면 안되는 예시. 완전 탐색 혹은 DP로 접근해야 한다.
  • Fractional Knapsack: 0-1 Knapsack과 달리, 물건을 원하는 만큼 자를 수 있는 문제. kg당 가격이 가장 높은 물건부터 최대한 담으면 된다 → 물건1 전체(50) + 두 번째로 kg당 금액이 높은 물건3 전체(140) + 세 번째 물건2 나머지 5kg(30) = 220만원.

1. Greedy 알고리즘이 유효하기 위한 조건은?
  1. 입력이 정렬되어 있어야 한다.
  2. 재귀를 사용해야 한다.
  3. 최적 부분 구조와 탐욕 선택 속성이 있어야 한다.
  4. 입력 크기가 작아야 한다.
정답: 최적 부분 구조와 탐욕 선택 속성이 있어야 한다.
2. 부분집합을 구하는 가장 일반적인 방법은? (단답형)
정답: Binary Counting — 부분집합을 구하기 위해서 Binary Counting을 사용하는 것이 가장 일반적입니다. 학습용으로 완전 탐색을 선택할 수도 있습니다.
3. 다음 중 Greedy 알고리즘으로 풀 수 없는 문제는?
  1. 배수 관계 동전 거스름돈
  2. Fractional Knapsack
  3. 0-1 Knapsack
  4. 회의실 배정
정답: 0-1 Knapsack — Greedy로 접근하면 안되는 예외 케이스가 존재하기 때문입니다. 동전 거스름돈 문제는 모든 동전이 배수 관계가 성립하면 Greedy 알고리즘으로 접근 가능합니다.
4. def is_valid(start, end, current_end): return start >= current_end 에서 is_valid(5, 7, 4) 의 결과는?
정답: True — 회의실 배정 문제에서 다음 회의를 선택할 수 있는지 판단하는 함수입니다. start(5)가 current_end(4)보다 크거나 같으므로 회의를 배정할 수 있습니다.
5. 아이템 (무게, 가치)가 (10, 60), (20, 100), (30, 120)일 때, Fractional Knapsack에서 가장 먼저 선택되는 아이템은?
정답: (10, 60) — 각 아이템의 단위 무게당 가치는 [6.0, 5.0, 4.0]이고, 가장 높은 6.0을 가진 아이템이 먼저 선택됩니다.
6. Fractional Knapsack 문제의 정렬 기준은?
정답: 단위 무게당 가치 순 (내림차순)
7. 회의실 배정 문제의 정렬 기준은?
정답: 회의 종료 시간 오름차순
8. 단위 무게당 가치를 val 리스트에 저장할 때, (10, 60)의 값은? (실수로 표현)
정답: 6.0
9. 5원, 50원, 70원 단위 동전으로 100원 거슬러주기를 Greedy로 풀면?
정답: 최적이 아니다 — 모든 동전이 배수 관계가 성립하지 않기 때문에 Greedy로 풀 수 없습니다. 최소가 되기 위한 답은 50원 동전 2개이지만, Greedy를 활용하면 70원 1개와 5원 6개(7개)가 됩니다.
10. [3, 7, 2, 6]에서 탐욕적으로 가장 큰 값 2개를 선택하여 합한 값은?
정답: 13 — 7 + 6 = 13
11. 동전 [4, 3, 1]으로 6원을 거슬러 주는 Greedy 코드에서 cnt의 값은? 이는 최적해인가?
정답: 3, 최적해가 아니다 — 6 // 4 = 1, 남은 2 // 1 = 2로 3이 답입니다. 그러나 최적의 해는 3 + 3 = 6으로 2개를 사용하는 것입니다. 따라서 그리디가 항상 정답이 아님을 보여주는 예시입니다.
12. Binary Counting을 통해 집합 {A, B, C}의 부분집합 중 101에 해당하는 것은?
  1. {A, B}
  2. {A, C}
  3. {B, C}
  4. {C}
정답: {A, C} — 비트를 오른쪽(0번)부터 A, B, C에 대응시키면 101 → A와 C 포함.
