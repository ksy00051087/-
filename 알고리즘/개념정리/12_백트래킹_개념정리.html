백트래킹 (Backtracking)

개념 · 동작 · DFS와의 차이 · 상태 공간 트리 · 유망성 · 절차

1-1백트래킹이란?

  • 여러 가지 선택지(옵션)들이 존재하는 상황에서 한가지를 선택한다.
  • 선택이 이루어지면 새로운 선택지들의 집합이 생성된다.
  • 이런 선택을 반복하면서 최종 상태에 도달함 — 올바른 선택을 계속하면 목표 상태(goal state)에 도달합니다.
  • 막히면(조건에 맞지 않으면) 직전의 선택지로 돌아가서 다른 선택을 함 — 더 이상 선택지가 없다면 찾는 답이 없음

1-2백트래킹과 깊이 우선 탐색과의 차이

  • 어떤 노드에서 출발하는 경로가 해결책으로 이어질 것 같지 않으면 더 이상 그 경로를 따라가지 않음으로써 시도의 횟수를 줄임 (Prunning 가지치기)
  • 깊이 우선 탐색이 모든 경로를 추적하는데 비해 백트래킹은 불필요한 경로를 조기에 차단
  • 깊이 우선 탐색을 가하기에는 경우의 수가 너무나 많음 — 즉, N! 가지의 경우의 수를 가진 문제에 대해 깊이 우선 탐색을 가하면 당연히 처리 불가능한 문제가 됨
  • 백트래킹 알고리즘을 적용하면 일반적으로 경우의 수가 줄어들지만, 이 역시 최악의 경우에는 여전히 지수함수 시간(Exponential Time)을 요하므로 처리 불가능함

1-3상태 공간 트리 · 유망성

  • 상태 공간 트리: 각 노드가 현재까지의 선택 상태를 나타내는 트리. 가능한 모든 선택 경로를 구조화하여 탐색할 수 있게 한다.
  • 어떤 노드를 방문하였을 때 그 노드를 포함한 경로가 해답이 될 수 없으면 그 노드는 유망하지 않다(non-promising)고 하며, 반대로 해답의 가능성이 있으면 유망하다(promising)고 함
  • 백트래킹 기법: 상태 공간 트리의 깊이 우선 검색을 실시한다 → 각 노드가 유망한지를 점검한다 → 만일 그 노드가 유망하지 않으면, 그 노드의 부모 노드로 되돌아가서 검색을 계속한다.

N-Queen 문제

문제 · 4-Queen 상태 공간 트리 · 유망성 검사 · 구현 · 가지치기 효과

2-1N-Queen

  • N×N 서양 장기판에서 배치한 Queen들이 서로 위협하지 않도록 N개의 Queen을 배치하는 문제 — 어떤 두 Queen도 서로를 위협하지 않아야 한다. Queen을 배치한 N개의 위치는?
  • 8-Queen: 퀸 8개를 8×8 크기의 체스판 안에 서로를 공격할 수 없도록 배치하는 모든 경우를 구하는 문제
  • Queen은 같은 행·열·대각선에 있는 말을 공격할 수 있다 → 한 행에 하나씩 놓으며, 같은 열/대각선이면 유망하지 않다.
  • 퀸의 위치를 각 행마다 정하는 방식은 상태공간트리로 표현 가능합니다.
def recur(row):
    if row == N:           # 모든 행에 놓았으면 → 해 발견
        answer += 1
        return
    for col in range(N):
        if check(row, col) is False:   # 유망하지 않으면 가지치기
            continue
        visited[row] = col
        recur(row + 1)
        visited[row] = -1

트리 (복습)
정의 · 용어 · 이진 트리 · 포화/완전 이진 트리 · 배열 표현

  




4-1트리


  • 트리는 싸이클이 없는 무향 연결 그래프임 — 두 노드(정점) 사이에는 유일한 경로가 존재합니다. 각 노드는 최대 하나의 부모 노드가 존재할 수 있습니다. 각 노드는 자식 노드가 없거나 하나 이상이 존재할 수 있습니다.
  • 비선형 구조 — 원소들 간에 1:n 관계를 가지는 자료구조, 원소들 간에 계층관계를 가지는 계층형 자료구조
  • 한 개 이상의 노드로 이루어진 유한 집합이며 다음 조건을 만족함: 노드 중 최상위 노드를 루트(root)라 합니다. 나머지 노드들은 n(>=0)개의 분리 집합 T1, …, TN으로 분리될 수 있습니다. 이들 T1, …, TN은 각각 하나의 트리가 되며(재귀적 정의) 루트의 부 트리(subtree)라 합니다.
용어의미
간선(edge)부모 노드와 자식 노드를 연결합니다.
형제 노드(sibling node)같은 부모 노드의 자식 노드들
조상 노드간선을 따라 루트 노드까지 이르는 경로에 있는 모든 노드들
노드의 차수노드에 연결된 자식 노드의 수
트리의 차수트리에 있는 노드의 차수 중에서 가장 큰 값
단말 노드(리프 노드)차수가 0인 노드. 자식 노드가 없는 노드
노드의 높이루트에서 노드에 이르는 간선의 수. 노드의 레벨
트리의 높이트리에 있는 노드의 높이 중에서 가장 큰 값. 최대 레벨






4-2이진 트리 · 배열 표현


  • 모든 노드들이 최대 2개의 서브트리를 갖는 특별한 형태의 트리 — 각 노드가 자식 노드를 최대한 2개 까지만 가질 수 있는 트리
  • 레벨 i에서의 노드의 최대 개수는 2ⁱ개
  • 포화 이진 트리: 모든 레벨에 노드가 포화상태로 차 있는 이진 트리 — 높이가 h일 때, 최대의 노드의 개수인 (2ʰ⁺¹-1)의 노드를 가진 이진 트리. 루트를 1번으로 하여 2ʰ⁺¹-1까지 정해진 위치에 대한 노드 번호를 가짐
  • 완전 이진 트리: 높이가 h이고 노드 수가 n개일 때 (단, 2ʰ ≤ n ≤ 2ʰ⁺¹-1), 포화 이진 트리의 노드 번호 1번부터 n번까지 빈 자리가 없는 이진 트리
  • 배열 표현 — 루트의 번호를 1로 함. 레벨 n에 있는 노드에 대하여 왼쪽부터 오른쪽으로 2ⁿ 부터 2ⁿ⁺¹-1 까지 번호를 차례로 부여
  • 노드 번호가 i인 노드의 부모 노드 번호? i // 2 / 왼쪽 자식 노드 번호? 2 * i / 오른쪽 자식 노드 번호? 2 * i + 1
  • 배열 표현의 단점 보완을 위해 연결리스트를 이용하여 트리를 표현할 수 있다.

5-1트리 순회


  • 트리의 노드들을 체계적으로 방문하는 것
  • 전위 순회(preorder, VLR): 자손 노드보다 현재 노드를 먼저 방문한다.
  • 중위 순회(inorder, LVR): 왼쪽 자손 노드, 현재 노드, 오른쪽 자손 노드 순으로 방문한다.
  • 후위 순회(postorder, LRV): 현재 노드보다 자손 노드를 먼저 방문한다.

5-2이진 탐색 트리


  • 탐색 작업을 효율적으로 하기 위한 자료구조
  • key(왼쪽 서브트리) < key(루트 노드) < key(오른쪽 서브트리)
  • 왼쪽 서브트리와 오른쪽 서브트리도 이진탐색트리
  • 중위 순회하면 오름차순으로 정렬된 값을 얻을 수 있다.
  • 탐색 연산: 루트에서 시작한다. 탐색할 키 값 x를 루트 노드의 키 값과 비교한다 — 같으면 성공, 작으면 왼쪽 서브트리, 크면 오른쪽 서브트리에 대해서 순환적으로 탐색 연산을 반복한다. 탐색 수행할 서브 트리가 없으면 탐색 실패
  • 삽입 연산: 먼저 탐색 연산을 수행 → 탐색 실패한 위치에 원소를 삽입한다.
  • 탐색(searching), 삽입(insertion), 삭제(deletion) 시간은 트리의 높이만큼 시간이 걸린다 — 평균 O(log n) (이진 트리가 균형적으로 생성되어 있는 경우), 최악 O(n) (한쪽으로 치우친 경사 이진 트리)

5-3힙 (Heap)


  • 완전 이진 트리에 있는 노드 중에서 키 값이 가장 큰 노드나 키 값이 가장 작은 노드를 찾기 위해서 만든 자료구조
  • 최대 힙(max heap): 키 값이 가장 큰 노드를 찾기 위한 힙 — 부모 노드의 키 값 > 자식 노드의 키 값, 루트 노드는 키 값이 가장 큰 노드
  • 최소 힙(min heap): 키 값이 가장 작은 노드를 찾기 위한 힙 — 부모 노드의 키 값 < 자식 노드의 키 값, 루트 노드는 키 값이 가장 작은 노드
  • 힙 연산 — 삽입: 완전 이진 트리 형태를 유지하며 마지막에 넣고 부모와 비교하며 올린다 / 삭제: 힙에서는 루트 노드의 원소만을 삭제할 수 있다.
  • 힙은 배열로 구현 — n번 노드의 자식은 2n 과 2n+1 번에 저장합니다. 완전 이진 트리 특성에 의해 추가/삭제의 위치는 자료의 시작과 끝 인덱스로 제한된다.
  • 힙 정렬: 힙에서 순차적(오름차순)으로 값을 하나씩 제거 — n개의 노드 삽입 연산 + n개의 노드 삭제 연산이 필요, 전체 O(n log n). 배열에 저장된 자료를 정렬하기에 유용하다.

백트래킹 확인문제


1. 백트래킹 알고리즘의 핵심 개념은?
  1. 이전 값을 저장해두고 다시 사용한다.
  2. 조건을 만족하지 않으면 이전 단계로 되돌아간다.
  3. 모든 경우를 무작위로 선택한다
  4. 탐색 전에 항상 정렬을 수행한다
정답: 조건을 만족하지 않으면 이전 단계로 되돌아간다. — 이전 단계로 돌아가며 다른 경우를 탐색합니다.
2. 다음 중 대표적인 백트래킹 문제로 알려진 것은?
  1. 평균값 계산
  2. 버블 정렬
  3. N-Queen 문제
  4. 최소값 찾기
정답: N-Queen 문제 — 조건에 따라 탐색 경로를 제한하는 백트래킹이 적합합니다.
3. 상태 공간 트리에서 노드는 무엇을 나타내는가?
  1. 전체 입력값
  2. 선택 가능한 모든 원소
  3. 현재까지의 선택 상태
  4. 모든 결과의 평균
정답: 현재까지의 선택 상태
4. 다음 중 가지치기에 해당하는 것은?
  1. 모든 경우를 끝까지 탐색
  2. 이미 선택한 값을 다시 사용하는 것
  3. 유망하지 않은 경로는 탐색하지 않음
  4. 모든 경로를 반복문으로 처리
정답: 유망하지 않은 경로는 탐색하지 않음 — 조건을 만족하지 않는 경로를 미리 제외하는 전략입니다.
5. 순열 생성 시 백트래킹의 특징으로 옳은 것은?
  1. 중복 선택이 가능
  2. 이미 선택한 원소는 다시 선택하지 않음
  3. 무작위로 선택
  4. 한 번만 선택
정답: 이미 선택한 원소는 다시 선택하지 않음
6. 순열과 조합에 대한 설명으로 옳은 것은?
  1. 조합은 순서를 고려하지 않는다
  2. 순열은 일부만 선택한다.
  3. 조합은 중복을 허용한다
  4. 순열은 항상 2개씩 짝짓는다
정답: 조합은 순서를 고려하지 않는다.
7. 상태 공간 트리로 표현하기 적절한 것은?
정답: 퀸의 위치를 각 행마다 정하는 방식 — N-Queen은 상태공간트리로 표현 가능합니다.
8. 백트래킹에서 재귀함수의 역할은?
정답: 이전 상태로 돌아가도록 호출을 반복 — 재귀를 통해 현재 상태에서 다음 상태로 이동하고, 실패 시 다시 돌아갈 수 있습니다.
9. 백트래킹에서 탐색을 중단해야 하는 시점은?
정답: 현재 경로가 문제의 조건을 만족하지 않았을 때 — 해당 경로의 탐색을 중단해야 합니다(가지치기).
10. {1, 2, 3}에서 2개를 고르는 조합 중 1을 포함하는 것은?
정답: [1, 2], [1, 3] — 조합은 순서를 고려하지 않고 일부 원소를 선택하는 것입니다.
11. 하나의 해만 구하면 되는 문제에서 백트래킹은 언제 멈추는가?
정답: 하나의 가능한 해를 완성했을 때 탐색을 멈춘다.

핵심 키워드


키워드설명
백트래킹여러 경로를 탐색하다가 조건에 맞지 않으면 다시 돌아가는 방식
가지치기 (Pruning)탐색 중에 가능성이 없는 경우를 미리 제외하는 과정
상태 공간 트리각 노드 = 현재까지의 선택 상태
유망성 (promising)그 노드를 포함한 경로가 해답이 될 가능성이 있는가
N-Queen한 행에 하나씩, 같은 열·대각선 검사로 가지치기
트리 · BST · 힙순회(VLR/LVR/LRV), 왼쪽 < 루트 < 오른쪽, 루트가 최대/최소






이 문서의 큰 줄기


  • 백트래킹 = DFS + 유망성 검사(가지치기). 최악은 여전히 지수 시간이지만 실제 탐색 노드는 크게 줄어든다.
  • "놓고 → 들어가고 → 되돌린다" 구조는 완전탐색(순열·조합·부분집합)과 같다. 차이는 들어가기 전에 검사하느냐.
  • 가지치기 조건은 두 종류: 이미 조건 위반(합 > 목표, 같은 열), 앞으로도 불가능(남은 합 부족, 현재 비용 ≥ 최소).
