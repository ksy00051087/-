스택(Stack)의 개념과 특성
선형구조 · 비선형구조 · LIFO · 자료구조와 연산 · top

  




1-1스택의 개념


구조설명
선형구조자료 간의 관계가 1:1의 관계를 갖는다. (예: 배열, 리스트)
비선형구조자료 간의 관계가 1:N의 관계를 갖는다. (예: 트리, 그래프)
스택은 물건을 쌓아 올리듯 자료를 쌓아 올린 형태의 자료구조입니다. 스택에 저장된 자료는 선형 구조를 갖습니다.






1-2스택의 특성 — 후입선출 (LIFO, Last-In-First-Out)



가장 마지막에 넣은 자료가 가장 먼저 나오는 것. 예를 들어, 스택에 1, 2, 3을 차례대로 넣으면 꺼낼 때는 3, 2, 1 순서로 나오게 됩니다.
  • 스택에 자료를 삽입하거나 스택에서 자료를 꺼낼 수 있습니다.
  • 마지막에 삽입한 자료를 가장 먼저 꺼냅니다.






1-3스택을 프로그램에서 구현하기 위해서 필요한 자료구조와 연산


  • 자료구조: 자료를 선형으로 저장할 저장소 — 파이썬에서는 리스트를 사용해 구현할 수 있습니다. (C언어에서는 배열을 사용할 수 있습니다.)
  • 저장소 자체를 스택이라 부르기도 합니다. 용도에 따라 메모리의 일부를 스택으로 부릅니다.
  • 스택에서 마지막 삽입된 원소의 위치를 top이라 부릅니다 — 스택 포인터(stack pointer)로 부르며 데이터를 넣거나 뺄 때 기준이 되는 위치입니다.






1-4스택의 연산


연산설명
push (삽입)저장소에 자료를 저장하는 연산
pop (삭제)저장소에서 삽입한 자료의 역순으로 꺼내는 연산
isEmpty스택이 공백인지 아닌지를 확인하는 연산 — 스택이 비어 있으면 True, 아니면 False를 반환
peek스택의 top에 있는 item(원소)을 반환하는 연산 — 삭제는 하지 않습니다
push(A) → [A]          top=0
push(B) → [A, B]       top=1
push(C) → [A, B, C]    top=2
pop()   → [A, B]  반환 C

2-1push — append 메서드를 통해 리스트의 마지막에 데이터를 삽입


def push(item):
    s.append(item)
인덱스 연산으로 구현하면 크기가 정해진 리스트에서 top을 증가시킨 뒤 저장하며, top == size-1이면 overflow입니다.






2-2pop — 가장 늦게 저장된 데이터를 삭제하는 연산


def pop():
    if len(s) == 0:
        # underflow
        return
    else:
        return s.pop()    # 리스트 s의 마지막 원소 삭제 후 반환
인덱스 연산을 이용한 pop: top == -1 이면 Underflow, 아니면 top을 1 감소시키고 stack[top+1] 반환.

괄호의 조건 · 알고리즘 개요 · 구현

  




3-1괄호 검사 — 괄호의 종류: 대괄호 ([, ]), 중괄호 ({, }), 소괄호 ((, ))


조건
  1. 왼쪽 괄호의 개수와 오른쪽 괄호의 개수가 같아야 한다.
  2. 같은 괄호에서 왼쪽 괄호는 오른쪽 괄호보다 먼저 나와야 한다.
  3. 괄호 사이에는 포함 관계만 존재한다.
잘못된 괄호 사용의 예
(a(b)        → 조건 1 위반
a(b)c)       → 조건 1 위반
a{b(c[d]e}f) → 조건 3 위반






3-2스택을 이용한 괄호 검사 알고리즘 개요


  • 문자열에 있는 괄호를 차례대로 조사하면서 왼쪽 괄호를 만나면 스택에 삽입하고, 오른쪽 괄호를 만나면 스택에서 top 괄호를 삭제한 후 오른쪽 괄호와 짝이 맞는지를 검사한다.
  • 이 때, 스택이 비어 있으면 조건 1 또는 조건 2에 위배되고 괄호의 짝이 맞지 않으면 조건 3에 위배된다.
  • 문자열 끝까지 조사한 후에도 스택에 괄호가 남아 있으면 조건 1에 위배된다.

4-1Function call — 프로그램에서의 함수 호출과 복귀에 따른 수행 순서를 관리


  • 가장 마지막에 호출된 함수가 가장 먼저 실행을 완료하고 복귀하는 후입선출 구조이므로, 후입선출 구조의 스택을 이용하여 수행순서 관리
  • 함수 호출이 발생하면 호출한 함수 수행에 필요한 지역변수, 매개변수 및 수행 후 복귀할 주소 등의 정보를 스택 프레임(stack frame)에 저장하여 시스템 스택에 삽입
  • 함수의 실행이 끝나면 시스템 스택의 top 원소(스택 프레임)를 삭제(pop)하면서 프레임에 저장되어 있던 복귀주소를 확인하고 복귀
  • 함수 호출과 복귀에 따라 이 과정을 반복하여 전체 프로그램 수행이 종료되면 시스템 스택은 공백 스택이 된다.

F_2() 종료·복귀    → [main, F_1]
F_1() 종료·복귀    → [main]
main() 종료        → []

5-1재귀호출 (Recursive Call)


  • 자기 자신을 호출하여 순환 수행되는 것
  • 함수에서 실행해야 하는 작업의 특성에 따라 일반적인 호출방식보다 재귀호출방식을 사용하여 함수를 만들면 프로그램의 크기를 줄이고 간단하게 작성
  • 재귀 호출의 예) factorial — n에 대한 factorial: 1부터 n까지의 모든 자연수를 곱하여 구하는 연산
n! = n × (n-1)!
    (n-1)! = (n-1) × (n-2)!
    (n-2)! = (n-2) × (n-3)!
    ...
    2! = 2 × 1!
    1! = 1
마지막에 구한 하위 값을 이용하여 상위 값을 구하는 작업을 반복합니다.

          fact(3) → 3 * fact(2)
                    fact(2) → 2 * fact(1)
                              fact(1) → return 1
                    return 2

6-2알고리즘 최적화: 메모이제이션 기법



메모이제이션(Memoization)은 컴퓨터 프로그램을 실행할 때 이전에 계산한 값을 메모리에 저장해서 매번 다시 계산하지 않도록 하여 전체적인 실행 속도를 빠르게 하는 기술입니다. 동적 계획법의 핵심이 되는 기술입니다.


'memoization'은 글자 그대로 해석하면 '메모리에 넣기(to put in memory)'라는 의미이며 '기억되어야 할 것'이라는 뜻의 라틴어 memorandum에서 파생되었습니다. 흔히 '기억하기', '암기하기'라는 뜻의 memorization과 혼동하지만, 정확한 단어는 memoization입니다.

7-1그래프 탐색


  • 비선형구조인 그래프 구조는 그래프로 표현된 모든 자료를 빠짐없이 검색하는 것이 중요합니다.
  • 탐색하는 방법에는 다음의 두 가지 방법이 사용됩니다: 깊이 우선 탐색(Depth First Search, DFS), 너비 우선 탐색(Breadth First Search, BFS)






7-2DFS — 깊이 우선 탐색


  • 시작 정점의 한 방향으로 갈 수 있는 경로가 있는 곳까지 깊이 탐색해 가다가 더 이상 갈 곳이 없게 되면, 가장 마지막에 만났던 갈림길 간선이 있는 정점으로 되돌아와서 다른 방향의 정점으로 탐색을 계속 반복하여 결국 모든 정점을 방문하는 순회방법
  • 가장 마지막에 만났던 갈림길의 정점으로 되돌아가서 다시 깊이 우선 탐색을 반복해야 하므로 후입선출 구조의 스택 사용






7-3DFS 알고리즘


  1. 시작 정점 v를 결정하여 방문한다.
  2. 정점 v에 인접한 정점 중에서 — ① 방문하지 않은 정점 w가 있으면, 정점 v를 스택에 push하고 정점 w를 방문한다. 그리고 w를 v로 하여 다시 ②를 반복한다. ② 방문하지 않은 정점이 없으면, 탐색의 방향을 바꾸기 위해서 스택을 pop하여 받은 가장 마지막 방문 정점을 v로 하여 다시 ②를 반복한다.
  3. 스택이 공백이 될 때까지 ②를 반복한다.
visited[], stack[] 초기화
DFS(v)
    시작점 v 방문;
    visited[v] ← true;
    while {
        if (v의 인접 정점 중 방문 안 한 정점 w가 있으면)
            push(v);
            v ← w;  (w에 방문)
            visited[w] ← true;
        else
            if (스택이 비어 있지 않으면)
                v ← pop(stack);
            else
                break
    }
end DFS()






7-4DFS 예시 진행 (정점 A~G, 오름차순으로 선택)


초기 상태) 배열 visited를 False로 초기화하고, 공백 스택을 생성
1) 정점 A를 시작으로 깊이 우선 탐색을 시작              visited[A]←True
2) A에 방문하지 않은 인접 정점 B, C → A를 push, B 선택   visited[B]←True  stack=[A]
3) B에 방문하지 않은 인접 정점 D, E → B를 push, D 선택   visited[D]←True  stack=[A,B]
4) D에 방문하지 않은 인접 정점 F → D를 push, F 선택       visited[F]←True  stack=[A,B,D]
5) F에 방문하지 않은 인접 정점 E, G → F를 push, E 선택   visited[E]←True  stack=[A,B,D,F]
6) E에 방문하지 않은 인접 정점 C → E를 push, C 선택       visited[C]←True  stack=[A,B,D,F,E]
7) C에 방문하지 않은 인접 정점이 없음 → pop → E
8) E에 방문하지 않은 인접 정점 없음 → pop → F
9) F에 방문하지 않은 인접 정점 G → F를 push, G 선택      visited[G]←True
10) G 없음 → pop F → F 없음 → pop D → … → pop A
11) 스택이 공백이므로 깊이 우선 탐색을 종료한다.
방문 순서: A B D F E C G

이 문서의 큰 줄기


  • 스택은 "나중에 넣은 것을 먼저" 꺼내야 하는 모든 상황 — 괄호 짝, 함수 복귀, 되돌아가기(DFS)의 공통 구조다.
  • 재귀는 시스템 스택을 쓰는 반복이다 → 기저 조건이 없으면 끝나지 않고, 깊으면 스택이 넘친다.
  • 피보나치 재귀의 중복 호출(≈2ⁿ)을 memo로 O(n), 반복 DP로 오버헤드까지 제거한다.
  • DFS = 스택(또는 재귀) + visited.
