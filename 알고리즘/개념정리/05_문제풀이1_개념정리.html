20551. 증가하는 사탕 수열

문제 · 입력 · 해결 아이디어 · 구현

1-1문제

세현이는 세 개의 상자를 나란히 세워 놓았다. 첫 번째 상자에는 사탕 A개, 두 번째 상자에는 사탕 B개, 세 번째 상자에는 사탕 C개가 들어 있다. 세현이는 상자에 들어 있는 사탕의 개수가 순증가하기를 원한다. 즉, 두 번째 상자에 들어 있는 사탕의 개수가 첫 번째 상자에 들어 있는 사탕의 개수보다 더 많기를 원하고, 세 번째 상자에 들어 있는 사탕의 개수가 두 번째 상자에 들어 있는 사탕의 개수보다 더 많기를 원한다. 또한, 세현이는 모든 상자가 비어 있지 않기를 원한다. 즉, 모든 상자에 1개 이상의 사탕이 들어 있기를 원한다.

세현이는 이 조건을 만족시키기 위해 사탕을 먹을 수 있다. 조건을 만족하기 위해 먹어야 하는 최소 사탕 개수를 구하라. 불가능하면 -1.

입력: 첫 번째 줄에 테스트 케이스의 수 T. 각 테스트 케이스는 한 개의 줄로 이루어지며, 세 개의 자연수 A, B, C (1 ≤ A, B, C ≤ 3000)가 공백 하나를 사이로 두고 주어진다.

1-2해결 아이디어 — 뒤에서부터 탐욕적으로

  • 사탕은 먹을(줄일) 수만 있다 → C는 그대로 두는 것이 최선.
  • B가 C 이상이면 B를 C-1까지 줄인다 (가장 적게 먹는 방법).
  • A가 (새) B 이상이면 A를 B-1까지 줄인다.
  • 줄인 결과 A나 B가 1보다 작아지면 조건(모든 상자 1개 이상)을 만족할 수 없으므로 -1.

10580. 전봇대
문제 · 입력 · 교차 조건 · 구현

  




2-1문제



현우는 길을 가다가 전선들이 복잡하게 꼬여 있는 전봇대 두 개를 보았다. 두 전봇대는 높이가 매우 높으며, N개의 팽팽한 전선으로 연결되어 있었다. 두 전선의 끝점이 같은 경우는 없으나, 교차하는 경우는 있다. 세 개 이상의 전선이 하나의 점에서 만나지 않는다고 가정하자. 이 전봇대에는 총 몇 개의 교차점이 있을까? (예: 전선 3개, 교차점 2개)


입력: 첫 번째 줄에 테스트 케이스의 수 T. 각 테스트 케이스의 첫 번째 줄에 전선의 개수 N (1 ≤ N ≤ 1000). 이후 N개의 줄에 두 양의 정수 Aᵢ, Bᵢ (1 ≤ Aᵢ, Bᵢ ≤ 10000) — i번째 전선이 첫 번째 전봇대의 Aᵢ 고도, 두 번째 전봇대의 Bᵢ 고도에 걸려 있음. 모든 Aᵢ는 서로 다르고, 모든 Bᵢ도 서로 다르다.






2-2교차점이 발생하는 경우는 두 가지


경우조건
①새로운 선의 시작점이 기존 선의 시작점보다 높으며, 새로운 선의 도착점이 기존 선의 도착점보다 낮은 경우
②새로운 선의 시작점이 기존 선의 시작점보다 낮으며, 새로운 선의 도착점이 기존 선의 도착점보다 높은 경우
즉 두 전선 i, j에 대해 (Aᵢ - Aⱼ) × (Bᵢ - Bⱼ) < 0 이면 교차. 모든 쌍을 확인하는 완전 탐색 O(N²) — N ≤ 1000이면 약 50만 번.

1953. [모의 SW 역량테스트] 탈주범 검거
문제 · 터널 구조물 7종 · 제약 · 해결 아이디어(BFS) · 구현

  




3-1문제



교도소로 이송 중이던 흉악범이 탈출하는 사건이 발생하여 수색에 나섰다. 탈주범은 탈출한 지 한 시간 뒤, 맨홀 뚜껑을 통해 지하터널의 어느 한 지점으로 들어갔으며, 지하 터널 어딘가에서 은신 중인 것으로 추정된다. 터널끼리 연결이 되어 있는 경우 이동이 가능하므로 탈주범이 있을 수 있는 위치의 개수를 계산하여야 한다.


탈주범은 시간당 1의 거리를 움직일 수 있다. 지하 터널은 총 7 종류의 터널 구조물로 구성되어 있다. 예) 세로 5, 가로 6, 맨홀 (2, 1), 탈출 후 소요된 시간 3 → 1시간 후 맨홀 위치 1곳, 2시간 후 3곳, 3시간 후 총 5개의 지점에 있을 수 있다.






3-2터널 구조물 타입 (1~7, 0은 터널 없음)


타입연결 방향
1상 · 하 · 좌 · 우
2상 · 하
3좌 · 우
4상 · 우
5하 · 우
6하 · 좌
7상 · 좌
제약: 세로 N, 가로 M은 각각 5 이상 50 이하. 맨홀 뚜껑의 세로 위치 R은 0 이상 N-1이하, 가로 위치 C는 0 이상 M-1이하. 탈출 후 소요된 시간 L은 1 이상 20 이하. 지도에는 반드시 1개 이상의 터널이 있음. 맨홀 뚜껑은 항상 터널이 있는 위치에 존재한다.






3-3해결 아이디어


  • 현재 지점으로부터 갈 수 있는 지점은 연결된 파이프 1칸이다.
  • 현재 칸에서 d 방향으로 나갈 수 있고, 다음 칸이 반대 방향(d+2)%4로 열려 있어야 실제로 이동 가능하다.
  • 탐색 시 걸린 시간도 함께 기록하면서 진행한다 → BFS, 시간 L 이하인 칸의 개수가 답.

5656. [모의 SW 역량테스트] 벽돌 깨기
규칙 · 예제 · 해결 아이디어(중복순열 + BFS + 중력) · 구현

  




4-1문제 규칙


  1. 구슬은 좌, 우로만 움직일 수 있어서 항상 맨 위에 있는 벽돌만 깨트릴 수 있다.
  2. 벽돌은 숫자 1 ~ 9로 표현되며, 구슬이 명중한 벽돌은 상하좌우로 (벽돌에 적힌 숫자 - 1)칸 만큼 같이 제거된다.
  3. 제거되는 범위 내에 있는 벽돌은 동시에 제거된다. (연쇄 반응)
  4. 빈 공간이 있을 경우 벽돌은 밑으로 떨어지게 된다.
N개의 구슬을 쏘아 벽돌을 최대한 많이 제거하였을 때, 남은 벽돌의 개수를 구하라. (1 ≤ N ≤ 4, 2 ≤ W ≤ 12, 2 ≤ H ≤ 15)






4-2해결 아이디어


  • 구슬을 쏠 위치는 매번 W가지 → W^N가지 중복순열 (최대 12⁴ = 20,736) — 완전 탐색 가능.
  • 새로운 자리에 구슬을 쏠 때는 쏘기 전 기준으로 초기화한다 → 맵을 복사해서 재귀에 넘긴다.
  • 명중한 벽돌부터 범위 안의 벽돌을 큐(BFS)/스택으로 연쇄 제거 → 벽돌을 지우고 지운 개수를 늘린다.
  • 지워진 자리는 위에서 내려온 벽돌로 메꾼다 — 열마다 아래(H-1)에서부터 0이 아닌 벽돌만 차곡차곡 내린다. (i는 항상 감소, idx는 arr[i][j]가 0이 아닐 때만 감소)
for j in range(W):
    idx = H - 1
    for i in range(H - 1, -1, -1):
        if dest[i][j]:
            dest[idx][j] = dest[i][j]
            idx -= 1
    for i in range(idx, -1, -1):
        dest[i][j] = 0

문제풀이 1 확인문제


1. 원래 수열의 일부 원소들을 순서대로 그대로 가져와 만든 새로운 수열을 무엇이라고 하나요? (단답형)
정답: 부분 수열 — 원래 수열의 원소들을 건너뛰며 선택할 수는 있지만, 선택한 원소들의 순서는 유지해야 합니다.
2. 다음 중 BFS(너비 우선 탐색)의 특징으로 옳은 것은?
  1. 한 경로 끝까지 탐색한 뒤 이동
  2. 가까운 노드부터 차례로 탐색
  3. 모든 경우의 수를 탐색
  4. 무작위로 탐색
정답: 가까운 노드부터 차례로 탐색
3. DFS 탐색 시 탐색의 진행 방식은 어떻게 이루어지나요? (단답형)
정답: 한 경로를 끝까지 탐색한 뒤 다른 경로로 이동한다 — 깊게 파고든 후, 막히면 돌아와 다른 경로를 탐색합니다.
4. 완전 탐색(Brute Force)에 대한 설명으로 옳지 않은 것은?
  1. 가능한 모든 경우를 탐색해 해답을 찾는다
  2. 계산 비용이 크다
  3. 실제 환경을 코드로 재현한다
  4. 경우의 수가 적을 때 유리하다
정답: 실제 환경을 코드로 재현한다 — 이는 시뮬레이션에 대한 설명입니다.
5. 다음 중 그래프/트리 탐색과 직접적인 관련이 없는 것은?
  1. BFS
  2. DFS
  3. 시뮬레이션
  4. 백트래킹
정답: 시뮬레이션 — 시뮬레이션은 상태 변화를 모사하는 기법으로 그래프 탐색과는 성격이 다릅니다.
6. BFS를 사용할 때 가장 일반적으로 활용하는 자료구조는? (단답형)
정답: 큐 — BFS는 먼저 들어온 노드를 먼저 탐색하기 때문에 FIFO 구조인 큐를 사용합니다.
7. DFS를 사용할 때 가장 일반적으로 활용하는 자료구조는? (단답형)
정답: 스택(Stack) 또는 재귀(Recursion) — 깊게 들어갔다가 다시 돌아오기 때문에 후입선출 구조를 씁니다.
8. 다음 중 완전 탐색이 적합하지 않은 경우는?
  1. 입력 크기가 작을 때
  2. 최적해를 반드시 찾아야 할 때
  3. 경우의 수가 매우 큰 빅데이터 상황
  4. 수열의 모든 조합을 확인할 때
정답: 경우의 수가 매우 큰 빅데이터 상황 — 계산량이 폭발적으로 늘어납니다.

  2. 미로에서 출구 찾기(경로 따라가기)
  3. 레벨 순회
  4. 대기열 처리
정답: 미로에서 출구 찾기(경로 따라가기)
10. 다음 중 시뮬레이션 기법의 장점으로 옳은 것은?
  1. 항상 최적해를 보장한다

  4. 코드가 항상 짧다
정답: 복잡한 실제 상황을 재현할 수 있다 — 최적해 보장보다는 실제 환경을 재현해 분석하는 것이 목적입니다.
11. 다음 중 BFS와 DFS의 차이로 옳지 않은 것은?
  1. BFS는 큐, DFS는 스택을 사용한다
  2. BFS는 최단 거리 탐색에 유리하다
  3. DFS는 경우의 수 탐색에 적합하다
  4. 둘 다 항상 최적해를 보장한다
정답: 둘 다 항상 최적해를 보장한다
12. 다음 중 완전 탐색으로 풀기 어려운 것은?

키워드설명
부분 수열 · 증가 패턴순서를 유지하며 일부 원소를 고른 수열 — 사탕 수열은 뒤에서부터 줄이는 탐욕
완전 탐색 (쌍 비교)모든 쌍을 비교 O(N²) — 전봇대 교차 (Aᵢ-Aⱼ)(Bᵢ-Bⱼ) < 0
이차원 배열 탐색과 방향 제어행과 열로 이루어진 데이터를 상하좌우로 이동하며 탐색 — 예: 미로 탐색에서 상-하-좌-우 이동

이 문서의 큰 줄기


  • 문제를 보면 입력 크기 → 가능한 경우의 수부터 계산한다: 3개 상자(상수), 1000쌍(50만), 12⁴(2만) — 모두 완전 탐색/시뮬레이션 가능.
