연산표기설명
부정 (Negation)~p, ¬pp가 명제일 때, 명제의 진릿값이 반대가 됩니다. "not p" 또는 p의 부정으로 읽습니다.

1-5조건 명제의 역, 이, 대우


명제형태
원래 명제p → q
역 (converse)q → p
이 (inverse)~p → ~q
대우 (contrapositive)~q → ~p
원래 명제와 대우는 항상 진릿값이 같습니다 (위 진리표에서 확인). 역과 이는 서로 대우 관계이므로 둘의 진릿값이 같습니다.
문제 3: 다음 명제의 역, 이, 대우를 쓰시오
"만약 2가 홀수라면, 미국에서 2080년 월드컵이 열린다."
  • 역: 만약 미국에서 2080년 월드컵이 열린다면, 2가 홀수이다.
  • 이: 만약 2가 짝수라면, 미국에서 2080년 월드컵이 열리지 않는다.
  • 대우: 만약 미국에서 2080년 월드컵이 열리지 않는다면, 2는 짝수이다.
원래 명제는 가정(2가 홀수)이 거짓이므로 결론의 참/거짓에 상관없이 참입니다. 대우 명제식도 참입니다.






1-6문제 1: 다음을 명제식 형태로 쓰고 참인지 거짓인지 판단하시오


  • "2가 홀수이면 4는 짝수이다" — 명제식: p → q. p 명제가 거짓이므로, q 명제의 참/거짓에 상관없이 해당 명제식은 참이다.
  • "4가 짝수이면 2가 홀수이다" — p 참, q 거짓 → 거짓. (p → q가 거짓이기 위해선 p 참, q 거짓인 경우이다.)

직접 증명 · 대우 증명 · 경우를 나누어 증명 · 공허한 증명 · 귀류법

  




3-1직접 증명 (Direct Proof)



p → q 를 증명할 때 p가 참이라 가정하고, 정의·이미 증명된 사실로 q가 참임을 보입니다.
  • 문제 6: n이 짝수이면 3n+5는 홀수임을 증명하라 — n = 2k 이면 3n+5 = 6k+5 = 2(3k+2)+1 이므로 홀수.
  • 문제 7: n이 홀수이면 n²+n은 짝수임을 증명하라 — n = 2k+1 이면 n²+n = (2k+1)(2k+2) = 2(2k+1)(k+1) 이므로 짝수.
  • 문제 8: m이 짝수이고 n이 홀수이면 2m+3n은 홀수 — m=2a, n=2b+1 → 2m+3n = 4a+6b+3 = 2(2a+3b+1)+1.
  • 참고 — 항상 참인 술어: 4x³+6x²+12 = 2(2x³+3x²+6) 이므로 4x³+6x²+12는 짝수이다. 그러므로 P(x)는 항상 참.
  • 공허한 증명(Vacuous Proof): ∀x, P(x) → Q(x)를 증명하려는데, P(x)가 항상 거짓인 경우 — 4x³+6x²+11 = 2(2x³+3x²+5)+1 이므로 항상 홀수 → "4x³+6x²+11이 짝수이면 Q(x)" 는 가정이 항상 거짓이므로 참.






3-2대우를 증명 (Proof by Contraposition)



p → q 대신 동치인 ~q → ~p 를 직접 증명합니다.
  • 문제 9: 자연수 n에 대해, n²+5가 홀수이면 n은 짝수 — 대우명제는 "n이 홀수이면 n²+5는 짝수이다." n = 2k+1 → n²+5 = 4k²+4k+6 = 2(2k²+2k+3) → 짝수. 대우 명제가 참이므로, 본 명제 또한 참이다.
  • 문제 10: n²이 짝수이면 n은 짝수임을 증명하라 — 대우명제는 "n이 홀수이면 n²이 홀수이다." n = 2k+1 → n² = 2(2k²+2k)+1 → 홀수. 대우 명제가 참이므로, 본 명제 또한 참이다.






3-3경우를 나누어 증명 (Proof by Cases)


  • 문제 11: 자연수 n에 대해 n²+5n+3은 항상 홀수임을 증명하라 — n이 짝수(=2k)인 경우와 홀수(=2k+1)인 경우로 나눔. 짝수: 4k²+10k+3 = 2(2k²+5k+1)+1 홀수. 홀수: 4k²+4k+1+10k+5+3 = 2(2k²+7k+4)+1 홀수.
  • 문제 12: n²이 3의 배수이면 n은 3의 배수임을 증명 — 대우: n = 3k+1 또는 3k+2 인 경우로 나누면 n² = 3(3k²+2k)+1, 3(3k²+4k+1)+1 → 3의 배수가 아님.

3-4귀류법 (Proof by Contradiction)



한 명제가 참인 것을 증명하려고 할 때에, 그 명제의 부정(否定)을 참이라고 가정(假定)하여 거기에서 나타나는 모순·불합리성을 증명함으로써 원래의 명제가 참인 것을 보여 주는 증명법. 또는 (~p → F)를 증명하는 방법.
  • 문제 4: 귀류법을 이용하여 (A − B) ∩ (B − A) = ∅ 임을 증명하라 — x ∈ (A−B) 이고 x ∈ (B−A) 인 원소 x가 존재한다고 가정하자. x ∈ (A−B) 이므로 x ∉ B 이고, x ∈ (B−A) 이므로 x ∈ B 이다. 이는 모순이므로 그러한 원소 x는 존재하지 않는다.
  • √2가 무리수임의 증명도 대표적인 귀류법 — √2 = a/b (기약분수)라 가정하면 a, b가 모두 짝수가 되어 모순.

수학적 귀납법 · 재귀 함수의 정확성 · 종료 · 병합 정렬 · 특이한 정렬(stooge) 증명

  




4-1수학적 귀납법


  1. 기본 단계(basis): P(1)(또는 P(0))이 참임을 보인다.
  2. 귀납 단계(inductive step): 임의의 k에 대해 P(k)가 참이라고 가정하고(귀납 가정), P(k+1)이 참임을 보인다.
  3. 그러면 모든 자연수 n에 대하여 P(n)이 성립한다.
재귀 함수는 귀납법과 똑같은 구조입니다 — 기저 조건 = 기본 단계, 재귀 호출 = 귀납 가정.






4-2재귀 함수의 정확성 증명 — sum(x)는 1에서 x까지의 합을 리턴한다


def sum(x):
    if (x <= 0):
        return 0
    return x + sum(x-1)
  • 기본: x ≤ 0 일 때 0을 리턴 — 참.
  • 귀납: 어떤 k에 대해 P(k)가 참이라고 가정한다: sum(k)가 1+2+…+k를 리턴.
  • sum(k+1)은 k+1 + sum(k) = (k+1) + (1+…+k) 를 리턴 → P(k+1) 참.
  • 따라서 sum(x)는 1에서 x까지의 합을 리턴한다.
그런데 def abc(x): return abc(x) 는 "abc(x)는 abc(x)를 리턴한다"는 식으로 아무것도 증명되지 않고, 이 함수는 안 끝남. 귀납법이 성립하려면 매 호출이 기저 조건을 향해 작아져야(종료해야) 합니다. 이런 이유로 문제가 해결되는 것은 아니고, 실제로 프로그램이 끝나는지도 증명해야 합니다.

  • k = 1, 2, …, n 에서 Merge Sort가 배열을 소팅한다고 가정하면 k = n+1 일 때 Merge Sort가 배열을 소팅함을 코드를 확인해서 증명할 수 있다. (merge 알고리즘의 정확성을 사용함)
  • 따라서 모든 범위 k에서 Merge Sort가 성립함을 알 수 있다.






4-4문제 3: 다음 소팅 알고리즘이 실제로 소팅에 항상 성공한다는 것을 증명하라 (Stooge Sort)


StoogeSort(A, n):
    if n == 2 and A[0] > A[1]:
        swap(A[0], A[1])
    else if n > 2:
        m = ceil(2n/3)
        StoogeSort(A[0 .. m-1], m)      // (1) 앞 2/3 정렬
        StoogeSort(A[n-m .. n-1], m)    // (2) 뒤 2/3 정렬
        StoogeSort(A[0 .. m-1], m)      // (3) 앞 2/3 다시 정렬
  • 배열을 A(앞 1/3), B(가운데 1/3), C(뒤 1/3) 구간이라고 할 때, 위의 소팅 방법은 원소의 개수가 2부터 n-1 까지 소팅이 성립한다고 가정할 때 개수가 n일 때의 소팅이 성립함을 보이는 귀납적 방법으로 증명할 수 있다.
  • n = 2일 때는 위의 구문에 의해 A[0]과 A[1]이 정렬됨을 알 수 있다.
  • 핵심: 최종적으로 C구간에 있어야 하는 원소 x가 (2) 연산 이후 C에 반드시 들어간다는 것을 보이면 된다 — 귀류법으로, (2) 이후에도 x가 C가 아닌 곳에 있다고 가정하면 원소 개수 조건에서 모순이 생긴다. 그 뒤 (3)이 앞의 2/3을 정렬하면 전체가 정렬된다.

4-5문제 4: 문제 3 소팅 알고리즘에서 수행하는 swap의 횟수는 최대 몇 번인가?


힌트: 이 알고리즘의 swap은 항상 이웃한 두 원소를 바꾸므로 한 번에 역순 쌍(inversion)을 정확히 1개 없앱니다. 따라서 swap 횟수 = 처음 배열의 역순 쌍의 개수이고 — 서로 다른 원소 쌍의 개수 n(n-1)/2 번이 최대입니다. (역순으로 정렬된 배열에서 위 실험: n=9 → 36 = 9·8/2)

6-2문제 1: 피보나치 수열 — F(n) = F(n-1) + F(n-2), F(1) = F(2) = 1



힌트: 계산되는 값이 n 가지 밖에 없으므로 이 값들을 저장할 수 있는 배열을 만들어 두고 재귀 호출에 들어가기 전에 확인한다.
Fibonacci(n):
    if n == 0 or n == 1: return n          // base case
    if memoization[n] == null
        memoization[n] = Fibonacci(n-1) + Fibonacci(n-2)
    return memoization[n]
위의 코드에서 n이 0 또는 1일 경우, base case 처리가 된다. n의 값이 0 또는 1 이외의 값이면 Fibonacci(n-1), Fibonacci(n-2)의 결과를 활용해 그 값을 계산하고 이를 저장하는 것을 확인할 수 있다. 수학적 귀납법으로 모든 자연수 n에 대하여 F(n)을 올바르게 계산함을 증명할 수 있다.
